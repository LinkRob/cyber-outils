'''0.0.15a''' (Multiplayer Test 5) was a version of [[Java Edition Classic]] released on June 3, 2009,<ref name="WON">https://web.archive.org/web/20090610225322/http://notch.tumblr.com/post/117491883/some-multiplayer-progress</ref> at 19:50 UTC.<ref name="T">[[#logs|IRC logs]]: "''[13:49] <@Notch> ok, I need to restart the server!!''" [...] "''[13:50] <@Notch> try pressing t''"</ref> It was available via some players on [[IRC]].

== Additions ==
* Added [[chat]].<ref>[[#logs|IRC logs]]: "''[13:53] <ZomBuster> yay ingame chat''" </ref>
** Accessed by pressing {{key|T}}.<ref name="T"/>

== Bugs ==
* Chat can be used in singleplayer, although sending a message will cause a crash.
* The screen goes black when a server is shut down.<ref>[[#logs|IRC logs]]: "''[13:49] <@Notch> ok, I need to restart the server!!''" [...] "''[13:49] <Nalok> OH MY GOD THE SCREEN WENT DARK''" [...] "''[13:49] <Rosetta> BLACK''", "''[13:49] <Zolyx> BLACK!''" [...] "''[13:49] <ZomBuster> screen went white''" [...] "''[13:49] <Nalok> Mine went black''" [...] "''[13:50] <vdgmprgrmr> Screen black! ::(''" (19:49 to 19:50 UTC)</ref>
