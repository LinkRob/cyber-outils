Broadcasts a narrative message about yourself.

== Syntax ==

* '''Java Edition'''
: <code>me <action></code>

* '''Bedrock Edition'''
: <code>me <message: message></code>

== Arguments ==

{{argument|action|message|reason: message|CommandMessage}}
: Specifies the message to display.
: {{arg desc|je=message|be=CommandMessage}}

== Example ==

* '''Java Edition'''
: <code>/me was eaten by a grue</code>

will output your name followed by the string "was eaten by a grue" - if your name is Steve: ''"Steve was eaten by a grue"''
