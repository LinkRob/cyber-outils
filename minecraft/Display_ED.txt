Text Display:
<div class="treeview">
* {{nbt|compound}} root tag
** {{nbt inherit/entity}}
** {{nbt inherit/display entity}}
** {{nbt|string|alignment}}: Text alignment direction. Can be <code>center</code>, <code>left</code>, and <code>right</code>. Defaults to <code>center</code>.
** {{nbt|int|background}}: The background color, arranged by ARGB. Since pixel with an alpha channel less than 0.1 are discarded when rendering in vanilla [[shader]], the background becomes fully transparent when A is less than 26 (0x1A). Defaults to 1073741824 (0x40000000). Interpolated.
** {{nbt|bool|default_background}}: If true, rendering uses default text background color (same as in chat), which overrides {{nbt|int|background}}. Defaults to <code>false</code>.
** {{nbt|int|line_width}}: Maximum line width used to split lines (note: new line can be also added with {{cd|\n}} characters). Defaults to 200.
** {{nbt|bool|see_through}}: Whether the text be visible through blocks. Defaults to <code>false</code>.
** {{nbt|bool|shadow}}: Whether the text is displayed with shadow. Defaults to <code>false</code>.
** {{nbt|string|text}}: The text to be displayed in the format of [[raw JSON text]], which are resolved with the context of the display entity.
** {{nbt|byte|text_opacity}}: Alpha value of rendered text. Alpha value is from 0 to 255. Since there are no unsigned bytes in NBT, values greater than 127 need to be replaced with <code>''alpha''-256</code>. So, the value is from -128 to 127. Similar to the background, the text rendering is discarded when it is less than 26. Defaults to -1, which represents 255 and is completely opaque. Interpolated.
</div><noinclude>
