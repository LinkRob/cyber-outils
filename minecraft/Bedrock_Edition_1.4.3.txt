'''1.4.3''' is a minor update to {{el|be}} released only for iOS on June 5, 2018,<ref>{{tweet|Mega_Spud|1004037582731132928|Minecraft update for iOS users is rolling out, details here:|June 5, 2018}}</ref> which fixes an account issue.<ref name=1.4.3>{{cite|url=https://feedback.minecraft.net/hc/en-us/articles/360004506952-Minecraft-1-4-3-iOS-Only-|title=Minecraft - 1.4.3 (iOS Only)|date=June 5, 2018}}</ref> It is compatible with devices running [[Bedrock Edition 1.4.2|1.4.2]]. This update didn't bring any code changes.<ref>[[HelenAngel]], on Minecraft Wiki EN's Discord: "FYI - The iOS update today had no code changes whatsoever. We just revved the version number so I could publish patch notes to iOS players to tell them about the free map for a month."</ref>

== Additions ==
=== General ===
; [[Marketplace]]
* New map called Kingdom Survival from Blockceptions.
** Can be downloaded for free for a limited time only (1 month) starting from June 5, 2018.<ref name=1.4.3/>

== Fixes ==
* Fixed an issue with kid accounts being unable to play over LAN.<ref>https://www.reddit.com/r/MCPE/comments/8owtn2/two_new_changelogs_ios_143_and_nintendo_3ds_15/</ref></onlyinclude>
