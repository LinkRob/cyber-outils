A version of '''[[Minecraft Infdev]]''' released on '''June 27, 2010'''.

== Changes ==

=== General ===
* Mob [[spawners]] given a unique tile entity ID, as they previously shared their IDs with [[signs]] which lead to various problems.<ref>[[wordofnotch:741367473|Sorry I broke the signs, here's the fix]] – The Word of Notch, June 27, 2010</ref>
* Passive [[mob]] spawning drastically reduced.
* [[Tree]] density reduced.

; [[Debug screen]]
* Changed Free memory to Used memory.
** Now displays MB in parentheses right next to the percentage.

== Fixes ==
;2 bugs fixed
* Fixed the [[minecart]] rotating bug.</onlyinclude>
* Fixed game crashing when signs are placed.
