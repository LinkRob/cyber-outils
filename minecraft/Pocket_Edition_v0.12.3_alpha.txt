'''v0.12.3 alpha'''<ref>https://bugs.mojang.com/browse/MCPE/fixforversion/15393</ref> was released to fix some bugs.

== Additions ==
; [[Skin/Skin pack|Skin packs]]
* {{Version exclusive}}: [[Skin/Skin pack#Halloween Costumes Skin Pack|Halloween Costumes Skin Pack]].

== Changes ==
*Description for LAN option changed from ''Local Server Multiplayer'' to ''Broadcast to LAN.''

== Fixes ==
{{Fixes|project=MCPE|fixedin=0.12.3|otherissuescount=7
|;From released versions before 0.12.0
|7829|Multiplayer minecart reverses course.
|8998|Dungeons appear with an empty spawner and an invisible chest.
|;From 0.12.0
|9985|Item tooltips incorrectly function on certain touch devices.
|10253|Unable to visually crouch/stand in 1st person view.
|;From 0.12.1 development versions
|9633|Invulnerable Pigs.
|9722|Breaking blocks in survival instantly.
|9902|Items not in hand while sneaking.
|10260|Second skin layer does not show up correctly while crouching.
|10281|Enchantments on items disappear.
|;From 0.12.1
|10512|Flickering inventory tags.
}}
;Other
* Tooltip position was incorrect, and visibility time was too short.
* Fixed so controller doesn’t lose its functionality on the death screen.
* Prevented Mojang logo from appearing sideways on iPhone 6 Plus.
* Stopped mining strength passively growing, allowing one-hit block breaks.
* Item from 1st slot of hotbar got duplicated when placed on different hotbar slot from inventory.
* Controller tooltip (“[X] Tab”) doesn’t overlap in the hotbar in the inventory menu.
* Player couldn’t use controller’s D-pad to navigate through the inventory menu.</onlyinclude>
