{{BlockSprite|prismarine}} '''Prismarine''' is a type of stone that appears underwater in [[ruin]]s and [[ocean monument]]s. It periodically changes color between blue and green.<br>

{{BlockSprite|prismarine-bricks}} '''Prismarine bricks''' are cyan bricks with chiseled patterns. <br>

{{BlockSprite|dark-prismarine}} '''Dark prismarine''' is dark cyan, with a tight grid pattern.

== Obtaining ==

=== Breaking ===
Prismarine only drops itself when mined with a pickaxe. If mined by any other [[tool]], it [[drops]] nothing.
{{breaking row|horizontal=1|Prismarine;Dark Prismarine;Prismarine Bricks|Pickaxe;Pickaxe;Pickaxe|Wood;Wood;Wood}}

=== Natural generation ===

All types of prismarine naturally generate as the main blocks making up [[ocean monument]]s. Normal prismarine and prismarine bricks are found in large amounts due to the size of the structure. Prismarine bricks make up the 23 pillars below the monument, and appear decoratively throughout the structure. Dark prismarine encases the 8 [[gold block|gold blocks]] of the dungeon, and appears in fewer decorative features. Normal prismarine can also be found in [[underwater ruins]].

=== Crafting ===

Each type of prismarine can be crafted using varying amounts of [[prismarine shard]]s (and an [[ink sac]]{{only|bedrock|education}} or [[black dye]] in the case of dark prismarine). All of these resources can be obtained from underwater mobs.

== Usage ==

[[File:Prismarine.gif|125px|thumb|right|The color change of prismarine]]
Prismarine can be used for decoration or as a high blast resistance building block.

The normal prismarine is uniquely useful for decoration as it has an animated texture. The cracks in prismarine slowly cycle in color through light blue, green, purple, and dark blue. The full animation for the prismarine texture changes color 22 times in an irregular sequence before the whole pattern repeats; this takes 5 minutes and 30 seconds.

=== Conduit power ===
{{main|Conduit}}
Prismarine, dark prismarine and prismarine bricks can be used to activate a conduit by building a structure around it. By doing this, the [[conduit]] emits the "Conduit Power" effect in a certain radius, depending on how many blocks are used to power it. [[Sea lantern]]s can also be used for this purpose.
