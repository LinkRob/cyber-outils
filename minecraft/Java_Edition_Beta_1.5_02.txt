== Fixes ==
;2 bugs fixed
* The game no longer crashes from "internal server error" created by bugs in [[Java Edition Beta 1.5_01|Beta 1.5_01]] server in [[multiplayer]].
* The [[player]] no longer get the Saving Chunks screen when taking something out of a [[crafting table]].
