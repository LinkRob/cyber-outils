'''Alpha v1.0.10'''<ref>{{ytl|5GoKanrNkiE|Minecraft - Fancy door tutorial|hipjipp|July 22, 2010}}</ref> is the version that added initial support for [[multiplayer]].<ref>[[wordofnotch:846133399|First over-the-internet test of Survival Mode Multiplayer]] – The Word of Notch, July 22, 2010</ref>

== Additions ==

* Initial survival multiplayer support.
** The only server is [[Mojang]]'s [[server]].
** Accessible through a private invite only.

== Changes ==

=== General ===
* Button "Single player" renamed to "Singleplayer".
* Button "Multi player" renamed to "Multiplayer".</onlyinclude>

== Bugs ==

* Graphical glitch with mob in spawner block.
* When the player dies, the death screen now displays "Score: &e0". This bug remained in the game until [[Java Edition 1.0.0]].
