Several decorative block variants have names which describe them as '''chiseled'''. Each of these blocks shows a complex design, either abstract or a mob face. They share parallel crafting recipes which seem to "combine two slabs back into a full block" for each eligible stone type.

* {{BlockLink|Chiseled Deepslate}}, which shows an old design of the [[warden]].
* {{BlockLink|Chiseled Nether Bricks}}, which shows a [[wither skeleton]].
* {{BlockLink|Chiseled Polished Blackstone}}, which shows a [[piglin]] snout.
* {{BlockLink|Chiseled Quartz Block}}, which shows an [[Elder Guardian]].
* {{BlockLink|Chiseled Red Sandstone}}, which shows a [[wither]].
* {{BlockLink|Chiseled Sandstone}}, which shows a [[creeper]].
* {{BlockLink|Chiseled Resin Bricks}}, which shows a [[creaking]].
* {{BlockLink|Chiseled Tuff}}, which shows a [[Wind Charged]] spiral effect, symbolizing the [[Breeze]].
* {{BlockLink|Chiseled Sulfur}}, which shows a [[sulfur cube]].
* {{BlockLink|Chiseled Cinnabar}}, which shows a [[cave spider|spider]].
