'''v0.15.6''' was released to enable a massive suite of VR-specific features and fix some of the bugs and crashes in [[Pocket Edition v0.15.4 alpha|v0.15.4]].<ref>[http://www.mojang.com/2016/08/fixes-faqs-and-a-changelog-for-156/ "Fixes, FAQs and a changelog for 0.15.6"] - Mojang, August 18, 2016,</ref> While it wasn’t the last update to v0.15.0, it was the last one before the builds of v0.16.0 started.

== Additions ==
* Windows 10 Edition Beta now supports Oculus Rift.

== Changes ==
* Better keyboard and mouse support when Oculus Rift is enabled.
* Tweaked Windows 10 UI when in Oculus Rift mode for better usability.

* Audio now plays through the user’s selected audio device.
* The {{key|C}} button on the keyboard can now switch between television mode and immersive mode.
