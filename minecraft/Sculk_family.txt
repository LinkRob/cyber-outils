The '''sculk family''' is a set of "alien-looking blocks with unique properties".<ref>https://www.minecraft.net/en-us/article/meet-warden</ref> These bioluminescent blocks appear exclusively within the [[deep dark]]. With the exception of sculk veins, all sculk blocks drop only [[experience]] when broken with a tool that is not enchanted with [[Silk Touch]].

=== Blocks ===
* [[File:Sculk.gif|64px]] [[Sculk]], a bioluminescent block found abundantly in the deep dark. Drops 1 experience.
* [[File:Sculk Catalyst.png|64px]] [[Sculk Catalyst]], a block that converts blocks around it to blocks in the sculk family (except for more sculk catalysts) when a mob that drops [[experience]] dies nearby. Drops 5 experience.
* [[File:Sculk Sensor.gif|64px]] [[Sculk Sensor]], a block that detects vibrations and outputs a [[Redstone Dust|redstone]] signal as well as triggering nearby sculk shriekers. Drops 5 experience.
** [[File:Calibrated Sculk Sensor.gif|64px]] [[Calibrated Sculk Sensor]], a variant of the sculk sensor that can be set to react to only a specific type of vibration.
* [[File:Sculk Shrieker.gif|64px]] [[Sculk Shrieker]], a block that "shrieks" if a player stands on it or triggers a nearby sculk sensor, which if the sculk shrieker in question was created at world generation, may cause the emergence of a warden. Drops 5 experience.
* [[File:Sculk Vein.gif|64px]] [[Sculk Vein]], a non-solid block found in the deep dark, and the only one that does not drop experience when broken.

=== Mobs ===
* [[File:Warden.png|64px]] [[Warden]], a hostile mob that emerges with the fourth activation of a natural sculk shrieker. Has the highest [[health]] and melee [[damage]] of all mobs, and can attack with ranged piercing sonic boom attacks if necessary, but is completely blind and relies on vibrations and smell to identify players and mobs to attack.

=== Mechanics ===
* [[Sculk Growth]], a mechanic that allows sculk catalyst to create more sculk family blocks.
