'''Tuff''' is a decorative [[rock|rocky]] [[block]] that generates underground, usually in [[ore (feature)|ore blob]]s below Y=16. This can be used to make tuff variants blocks and bricks.

== Obtaining ==

=== Natural generation ===
{{see also|Ore (feature)}}
Tuff can generate in [[the Overworld]] in the form of [[ore (feature)|ore blob]]s. Tuff attempts to generate 2 times per chunk in blobs of size 0-864, from elevations -64 to 0, in all [[biome]]s. Tuff can replace stone, andesite, diorite, granite, polished andesite‌{{only|be|short=1}}, polished diorite‌{{only|be|short=1}}, polished granite‌{{only|be|short=1}}, and deepslate. Any [[ore]] that generates in tuff becomes its deepslate variety.

Additionally, tuff can generate in an [[ore vein]] that consists of [[iron ore]] below Y=0.

=== Breaking ===
Tuff drops as an item if mined using any [[pickaxe]]. If mined without a pickaxe, it drops nothing.
{{Breaking row|Tuff|Pickaxe|Wood|horizontal=1}}

== Usage ==
Tuff is mainly used for construction and decoration; however, it can also be used to craft its [[slab]], [[stairs]], and [[wall]] variants, as well as [[polished tuff]], which can further be crafted into [[chiseled tuff]] and [[tuff bricks]]. Tuff can be stonecut into all of the [[Tuff (disambiguation)|tuff]] blocks.

== Trivia ==
* In real life, [[wikipedia:Tuff|tuff]] is a strong type of igneous rock which forms from compressed ash resulting from volcanic eruptions, which sees extensive use in Armenian architecture. Tuff in ''Minecraft'' is somewhat similar, with the texture representing that of a rough, uneven surface which appears to be the result of volcanic ash formation.
