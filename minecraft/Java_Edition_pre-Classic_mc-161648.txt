'''mc-161648''' is a [[pre-Classic]] version of ''[[Minecraft]]'' released on May 16, 2009, at 16:48 UTC,<ref>TigIRC logs: "''(12:48:58) notch: dock, fartron, Jrsquee: I've uploaded a new version that fixed the mouse lag for me. You might have to restart your browser to avoid applet cache issues. Could you see if it works now? =)''"</ref> which fixes mouse look issues.<ref>TigIRC logs: "''(12:34:01) notch: ok, thank you. I need to fix this mouse look thing, I think. ;)''"</ref>

== Trivia ==
* This version was the last unnumbered version of early ''Minecraft'', as a version number was added from the next update, [[0.0.2a]].<ref>TigIRC logs: "''(12:49:34) fartron: put in a build count or something so i can tell if it loaded the new one''", "''(12:49:56) notch: good idea. I'll add from the next version and up. =)''"</ref>
* As the next version was "0.0.2a", this version may be referred to as "0.0.1a", although this is unofficial usage.
** 0.0.1a may also refer to the whole [[pre-classic]] phase, or simply the versions named Minecraft.
* This was the last version of pre-Classic ''Minecraft''.
