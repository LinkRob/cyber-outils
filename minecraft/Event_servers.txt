'''Event servers''', known officially by the name '''Live Event''', were public event servers hosted by [[Mojang Studios]] for a limited amount of time on the main menu on {{Edition|bedrock}}. Players have to login to a Microsoft/Xbox Live account in order to join the Live Event server<ref name="btfaq">{{Mcnet|better-together-faq|Better Together FAQ|July 31, 2017}}</ref> and all devices including consoles can join them just like [[featured servers]].

When a Live Event is announced and opened, a dedicated button appears on the main menu. Upon clicking the button, the player is shown a screen with the server key art, a description, a button that redirects to a web page, and a button to join the event server.

==Safety==
[https://www.xbox.com/live/minecraft/sign-up Xbox Live] is a social network for gamers, and servers require the player to have an [https://www.xbox.com/live/minecraft/sign-up Xbox Live]/[https://signup.live.com/ Microsoft account].<ref name="safety">{{Mcnet|minecraft-multiplayer-server-safety|How to Stay Safe Online|July 28, 2017}}</ref> All of the event servers have the chat turned off.
