'''1.7.7''' is a minor update to ''[[Minecraft]]'' (''Java Edition'') released on April 9, 2014,<ref>{{cite|url=https://www.mojang.com/2014/04/minecraft-1-7-6/|archive-url=https://web.archive.org/web/0/https://www.mojang.com/2014/04/minecraft-1-7-6/|title=Minecraft 1.7.8|author=Searge|website=Mojang.com|date=April 9, 2014}}</ref> to fix some crashes from [[Java Edition 1.7.6|1.7.6]]. It is compatible with 1.7.6 servers.

== Fixes ==
* Fixed some crashes for some multiplayer servers.<ref>{{tweet|SeargeDP|453921942320734210|We updated Minecraft to 1.7.7 to fix some nasty crashes.|April 9, 2014}}</ref>

== Reupload ==
1.7.7 was reuploaded a day later on April 10, 2014, to remove the message <code>Outdated server! pretending to be 1.7.7</code>.</onlyinclude>
