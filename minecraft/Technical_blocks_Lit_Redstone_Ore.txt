{{History|java alpha}}
{{History||v1.0.1|Lit redstone ore has an unobtainable item form corresponding to its block ID. It can be obtained via inventory editors with numeric item ID 74.}}
{{History|java beta}}
{{History||1.6|snap=Test Build 3|Lit redstone ore items can be obtained from the newly added debug chests, mainly from the 16th slot of the 3rd chest from the left, and the 27th slot of the 5th chest from the left.}}
{{History|||snap=release|Debug chests no longer spawn, preventing lit redstone ore items from being obtained this way.}}
{{History|java}}
{{History||1.0.0|snap=Beta 1.9 Prerelease 4|Lit redstone ore can be obtained with the [[Silk Touch]] enchantment by breaking a block with an appropriate tool enchanted with it.}}
{{History|||snap=Beta 1.9 Prerelease 5|Lit redstone ore can no longer be obtained via Silk Touch.}}
{{History||1.3.1|snap=12w16a|Lit redstone ore can now be obtained as an item in singleplayer worlds via the {{cmd|give}} command using the respective numeric ID.}}
{{History||1.7.2|snap=13w37a|The direct item form of lit redstone ore has been removed from the game. It can no longer exist as an item in any way, only as a placed block.}}
{{History|pocket alpha}}
{{History||?|Lit redstone ore exists as an item.}}
