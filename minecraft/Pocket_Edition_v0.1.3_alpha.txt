'''v0.1.3 alpha''' was a Pocket Edition version added various minor changes and bug fixes.<ref name=":0">{{cite|url=https://www.mojang.com/2011/12/minecraft-pocket-edition-0-1-3-android/|archive-url=http://web.archive.org/web/20190710073515/https://www.mojang.com/2011/12/minecraft-pocket-edition-0-1-3-android/|title=Minecraft - ''Pocket Edition'' 0.1.3 (Android)|website=Mojang.com|date=December 3, 2011}}</ref>

== Android ==

=== Additions ===
* Added an "Update game!" block used as placeholder for not yet supported block types.

=== Changes ===
* Better tablet support.
* Less oversized in game UI elements.
* Performance improvements, especially in Non-Fancy graphics mode.
* Added [[cacti]] to [[desert]]s.
* Added Turn Sensitivity setting.
* Improved network [[chunk]] loading.

=== Fixes ===
* Fixed a crash when connecting to some iOS server maps.
* Fixed blocks that were placed on [[snow]] were added incorrectly in multiplayer.

== Internal version ==

* There are two different revisions. Their differences only appear to be in version number.
** Version: 0.1.3(1035), Size: 1.58 MB
** Version: 0.1.3(1036), Size: 1.58 MB

== iOS ==

=== Additions ===
* Added an "Update game!" block used as placeholder for not yet supported block types.

=== Fixes ===
* Improved network chunk loading.
* Fixed bug with opening dialogs after closing the options menu.

[[File:Pocket Edition v0.1.3j alpha.png|thumb|An image of the j-version of v0.1.3 alpha]]

== J-version ==
'''v0.1.3j alpha''' was released to the {{abbr|Android Market|now known as Google Play}} on an unknown release date, providing support for older Android devices,<ref name=":0" /> and added more sounds. The internal version is 0.1.3(1033) and has a size of 2.00 MB.

== Demo ==
A free "lite" demo version of v0.1.3 alpha was released to the Android Market on December 3, 2011.<ref>http://web.archive.org/web/20120121164604/https://market.android.com/details?id=com.mojang.minecraftpe.demo</ref> In mid-2014, it was removed from the Play/App stores.<ref>https://www.youtube.com/watch?v=Rkd65MFCtsk</ref> The internal version is not currently known.

== J-version demo ==
A free J-version "lite" demo of v0.1.3 alpha was released to the Android Market on an unknown release date. In mid-2014, it was removed from the Play/App stores.<ref>https://www.youtube.com/watch?v=Q7LwcjKb_Qo</ref> The internal version is not currently known.</onlyinclude>
