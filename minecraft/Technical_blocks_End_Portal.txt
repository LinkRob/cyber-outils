{{History||1.0.0|snap=Beta 1.9 Prerelease 3-1|slink=Java Edition Beta 1.9 Prerelease 3|End portals have an unobtainable item form corresponding to its block ID, which has interesting model behavior. It can be obtained via inventory editors with numeric item ID 119.
|In this version, players would immediately start out with this item upon generating a world or when respawning.
|If an end portal item already existed in the hotbar, using pick block on an existing end portal block would switch the hotbar to select that block like with any other item.
|It can be placed in [[the Nether]].}}
{{History|||snap=Beta 1.9 Prerelease 3-2|slink=Java Edition Beta 1.9 Prerelease 3|The player no longer starts out with this item on world generation or when respawning.}}
{{History|||snap=Beta 1.9 Prerelease 4|When attempted to be placed in the Nether or End, placement will fail but the placement sound and hand animation will still play. Replaceable blocks such as fluids, grasses and vines are deleted, and the item is also consumed in survival mode.}}
{{History||1.2.5|snap=pre|End portal items can now be obtained via pick block in Creative.}}
{{History||1.3.1|snap=12w16a|End portal items can now be obtained in singleplayer worlds via the {{cmd|give}} command using the respective numeric ID.}}
{{History|||snap=12w17a|End portal items can no longer be obtained via pick block in Creative.}}
{{History|||snap=12w18a|Likely due to a client-server desync, end portal blocks placed with the item in the Nether/End will render the block for a frame.}}
{{History||1.8|snap=14w25a|The direct item form of end portals has been removed from the game. It can no longer exist as an item in any way, only as a placed block.}}
{{History|bedrock}}
{{History||?|End portals exist as an item.}}
{{History||?|It is possible to obtain end portals as an item simply by replacing them with water using a bucket.<ref>https://youtu.be/BzCkjqN9P7Y?t=55s</ref>}}
{{History||?|End portals can no longer be obtained through replacement by water.}}
{{History||1.9.0|snap=?|It is possible to obtain end portals as an item by using {{cmd|setblock ~ ~ ~ air 0 destroy}} when standing above an activated end portal block.<ref>{{bug|MCPE-42991}}</ref>}}
{{History||1.11.0|snap=?|The above method no longer works.}}
