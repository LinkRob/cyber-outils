'''Beta 1.6.6''' is a version of [[Java Edition Beta]] released on May 31, 2011,<ref>{{Word of Notch|6035819427|Minecraft Beta 1.6.6|May 31, 2011}}</ref> which contains minor changes and fixes some of the bugs and crashes in [[Beta 1.6.5]].

==Additions==
===General===
; [[Option]]s
* Video Settings
** Added a Performance section.  
** Can be set to Max FPS, Balanced or Power saver.

==Changes==
===Blocks===
; [[File:Glowstone JE1.png|32px]] [[Glowstone]]
* Changed the material from "glass" to "stone". 
** This means the player would need a [[pickaxe]] to get resources from it. 
** This also means the player can now place [[redstone]], [[torch]]es, [[lever]]s, etc. on the block.
* Made glowstone drop more loot (2–4 [[glowstone dust]]).
* Made the recipe sizes for creating glowstone smaller (2&times;2 [[glowstone dust]] items instead of 3&times;3).
; {{animate|White Wool JE1 BE1.png|32px}} [[Wool]]
* Made the recipe sizes for creating wool smaller (2&times;2 [[string]]s instead of 3&times;3).

===Items===
; [[File:Bone Meal JE1 BE1.png|32px]] [[Bone meal]] 
* Can grow grass and flowers on grass blocks.

===Non-mob entities===
; [[File:Oak Boat JE1.png|32px]] [[Boat]]s
* Boats float up to the surface quicker.
* Boats falling down into water lose their vertical momentum much faster.
* Crashing into soul sand on a boat now kills the player, but keeps the boat intact.

== Fixes ==
;3 bugs fixed
* Fixed [[bed]]s not working very well in [[Survival#Survival multiplayer (SMP)|Multiplayer]].
* Destroying a [[boat]] will no longer spawn the player too low, causing them to sometimes fall through the ground.
* {{key|Shift}}+ clicking a [[Tools|tool]] into a chest no longer restores it to new.

== Trivia ==
*The first version of [[Legacy Console Edition]] is equivalent to this version.
**Same thing with the first [[MinecraftEdu]] version.
*This is the first Java Edition update to have "Removed [[Herobrine]]" featured on the official patch notes.

*This is the first Java Edition update to have a prototype of the [[Sky dimension|Sky Dimension]] in the game's code, meaning it was only playable by editing a binary file in the game's jar. The Sky Dimension was announced then confirmed by Notch on X a bit before the release of Beta 1.6.<ref>{{tweet|notch|71249283520802817|And because PC Gamer made such a big deal of the sky dimension, I guess I'll have to finish it. Consider it confirmed.|May 19, 2011}}</ref>
