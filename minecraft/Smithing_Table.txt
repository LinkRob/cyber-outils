A '''smithing table''' is a utility [[block]] used to alter [[tools]] and [[armor]] at the cost of a [[Smithing Template|smithing template]] and the appropriate material, a process that keeps all [[Enchanting|enchantments]]. This is the only way to obtain trimmed armor or upgrade diamond equipment with [[Netherite Ingot|netherite]]. It also serves as a [[Villager#Professions|toolsmith]]'s [[Villager#Job site blocks|job site block]].

== Obtaining ==
Smithing tables can be obtained from a [[village]] or [[crafting]].

=== Natural generation ===
Smithing tables can spawn naturally inside toolsmith houses in [[village]]s. They can also spawn in [[trail ruins]].

=== Breaking ===

Smithing tables can be broken using any tool or by hand, but an [[axe]] is fastest.

== Usage ==
=== Upgrading diamond gear to netherite gear ===
[[File:Smithing Table GUI 1.20.png|thumb|upright|176px|The GUI for the smithing table.]]

While upgrading, the newly crafted netherite gear retains the [[enchantments]], [[Anvil mechanics#Prior work penalty|prior work penalty]] and number of [[durability]] points lost (instead of the remaining durability) from the [[diamond]] gear.

Upgrading gear does not remove incompatible [[Enchanting|enchantments]], such as multiple different [[Protection]] enchantments.

Unlike [[anvils]], using a smithing table to upgrade diamond gear to netherite gear costs no [[experience]] and does not increase the prior work penalty.

Smithing table recipes use the [[data pack]] system.

=== Changing profession ===
If a [[village]] contains a smithing table that has not been claimed by a [[villager]], any villager who hasn't already chosen a [[job site]] block has a chance to change their profession to toolsmith. If a villager with this profession has already been traded with, it cannot change jobs.

===Armor trimming===
Trimming requires an armor piece, a [[smithing template]] and the mineral/crystal for the color the player desires (listed below).
* {{ItemLink|Amethyst Shard}}
* {{ItemLink|Copper Ingot}}
* {{ItemLink|Diamond}}
* {{ItemLink|Emerald}}
* {{ItemLink|Gold Ingot}}
* {{ItemLink|Iron Ingot}}
* {{ItemLink|Lapis Lazuli}}
* {{ItemLink|Nether Quartz}}
* {{ItemLink|Netherite Ingot}}
* {{ItemLink|Redstone Dust}}
* {{ItemLink|Resin Brick}}

After trimming, the armor will have the pattern according to the smithing templates. The color of the pattern is determined by the materials color.

=== Fuel ===
Smithing tables can be used as [[fuel]] in [[furnace]]s, smelting 1.5 [[item]]s per [[block]].

=== Note Blocks ===
Smithing tables can be placed under [[note block]]s to produce "bass" sounds.
