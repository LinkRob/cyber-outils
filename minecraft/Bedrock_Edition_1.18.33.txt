'''1.18.33''' is a minor update to {{BE}} released only for the Nintendo Switch on May 13, 2022, which fixes bugs.<ref>{{cite|url=https://feedback.minecraft.net/hc/en-us/articles/6213367123597|title=Minecraft - 1.18.33 (Switch)|website=feedback.minecraft.net|date=May 13, 2022}}</ref> This version is compatible with all Bedrock platforms running on [[Bedrock Edition 1.18.30|1.18.30]] until [[Bedrock Edition 1.18.32|1.18.32]].

== Additions ==
=== General ===
; [[Options]]
* Added "Clear Marketplace Cache" button to the storage settings.
** Used to clear local cache data but not delete save game data.

== Fixes ==
* Enabled configuration changes of some back-end services.
