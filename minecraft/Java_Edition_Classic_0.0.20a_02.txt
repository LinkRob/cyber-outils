'''0.0.20a_02'''<ref>{{ytl|n4cRiFGrwJc|Minecraft - Mein Secret Hideout|L4DWonton|June 24, 2009}}</ref> is a version of [[Classic]] released on June 20, 2009, at 21:39 UTC to fix 2 bugs affecting the game.<ref>[[#june 21 logs|June 21 IRC logs]]: "''A9:52:15 <Quatroking> we're currently running on 20a_2 already :P''" (14:52 UTC)</ref>

== Fixes ==
;2 bugs fixed
*Fixed water transparency bug from the previous version.
*Usernames are no longer hard to read.

== Bugs ==
*If the player aims at a certain angle while placing a block it will appear to go inside an existing block, due to a bug caused by using OpenGL picking.
**Specifically, looking at [[glass]] or [[leaves]] will cause this bug to happen.
