'''.name''' (AKA the '''Fire Placeholder Block''') is a [[Block]] that was added in [[Update 0.3.3]].

==Obtaining==
Currently, it is only obtainable through Inventory Editing in {{mc|mc=<includeonly>{{#invoke:Loops|mc}}</includeonly><noinclude>
This template is to be used when referring to the general page describing the page of [[Minecraft]] with the proper formatting as is wanted on this Wiki.

Typical usage is simply <code><nowiki>{{mc}}</nowiki></code> which produces: {{mc}}, or if you need to be specify which version please combine with parameters like in <code><nowiki>{{mc|java|console}}</nowiki></code> which produces: {{mc|java|console}}.

Known abbreviations includes: java, console, bedrock, ios, android, vr, win10.

To attach a version number to a given non-bedrock version, please combine with [[Template:supjoin]] template, like in <code><nowiki>{{mc|console}}{{supjoin|&amp;nbsp;|TU43}}</nowiki></code>, which produces: {{mc|console}}{{supjoin|&nbsp;|TU43}}.</noinclude>}}.

==Usage==
The .name Block served as a placeholder for [[Fire]] till [[Update 0.6.1]], as in [[Update 0.7.0]], Fire was re-added to the game.

==Trivia ==
*The old texture was a [[Stone]] block.
*Some [[Player]]s have seen it as a block with all items, including unimplemented ones.
*In [[Update 0.15.0]], the .name block's texture was changed to the Info update's texture.
