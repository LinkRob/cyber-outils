{{History|java beta}}
{{History||1.3|Beds have an extra item form corresponding to its block ID, which can be obtained via inventory editors with numeric item ID 26. It is not intended to be obtained in conventional gameplay.
|Picking block changes the currently selected slot to any containing this otherwise-unobtainable bed item, but does not allow it to be obtained if not already in the hotbar.}}
{{History||1.6|snap=Test Build 3|Bed items can be obtained from the newly added debug chests, mainly from the 26th slot of the 1st chest from the left, and the 10th slot of the 5th chest from the left.}}
{{History|||snap=release|Debug chests no longer spawn, preventing bed items from being obtained this way.}}
{{History|java}}
{{History||1.2.5|snap=pre|Pick Block now returns the actually obtainable bed item.}}
{{History||1.3.1|snap=12w16a|Bed items can be obtained in singleplayer worlds via the {{cmd|give}} command using the respective numeric ID.}}
{{History||1.7.2|snap=13w37a|The direct item form of the bed block has been removed from the game. It no longer exists as an item in any way, only as a placed block.}}
