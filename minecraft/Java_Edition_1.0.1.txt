'''1.0.1''' was a server update for ''Minecraft'' ({{el|je}}) released on November 24, 2011,<ref>{{tweet|jeb|139688276922613761|The minecraft_server.jar has been updated to 1.0.1, fixing the login key problem and a null pointer exception|24 Nov 2011}}</ref> to fix some bugs and crashes in [[Java Edition 1.0.0|1.0.0]] servers. As a server-only update, 1.0.0 remained the current client version.

== Fixes ==
;2 bugs fixed
* {{code|Invalid server key}} error fixed when attempting to log into servers.
* {{code|Null pointer exception}} error fixed when logging into servers.

== Trivia ==
* 1.0.1 is the last server-only version of ''Java Edition''.
* This is the final version of Minecraft released in 2011.
