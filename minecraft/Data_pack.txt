The '''data pack''' system provides a way for players to further customize their ''Minecraft'' experience. Data packs can be used to override or add new [[Advancement/JSON format|advancement]]s, [[Custom dimension|dimension]]s, [[Function (Java Edition)|function]]s, [[loot table]]s, [[predicate]]s, [[Item modifier|item modifiers]], [[recipe]]s, [[Structure block file format|structure]]s, [[tag]]s, [[damage type]]s, [[Custom world generation|world generation settings]], and [[biomes]] without any code modification.

== Usage ==

Data packs can be placed in the {{code|[[.minecraft]]/saves/(world)/datapacks}} folder of a world. Each data pack is either a sub-folder or a [[wikipedia:Zip (file format)|{{code|.zip}} file]] within the {{code|datapacks}} folder. After it is in the folder, a data pack is enabled for that world when the world is [[Commands/reload|reloaded]] or loaded.

Data packs load their data based on the load order. This order can be seen and altered by using the {{cmd|datapack}} command and is stored in the [[Java Edition level format#level.dat_format|{{cd|level.dat}} file]].

The player can also select data packs at the world creation screen by clicking the '''Data Packs''' button and dragging-and-dropping their data pack folders/zip-files there. This is similar to the [[resource pack]] selection screen, and allows the player to enable data packs before the world is generated, and easily customize the load order too.

=== {{code|pack.mcmeta}} ===

A data pack is identified by ''Minecraft'' based on the presence of the {{code|pack.mcmeta}} file in the root directory of the data pack, which contains data in [[wikipedia:JSON|JSON]] format.

<div class="treeview">
* {{nbt|compound}} The root object.
**{{nbt|compound|pack}}: Holds the data pack information.
***{{nbt|string}}{{nbt|list}}{{nbt|compound|description}}: A [[Raw_JSON_text_format|JSON text]] that appears when hovering over the data pack's name in the list given by the {{code|/datapack list}} command, or when viewing the pack in the Create World screen.
*** {{nbt|int|pack_format}}: Pack version. If this number does not match the current required number, the data pack displays a warning and requires additional confirmation to load the pack. See [[#Pack format]] for a full list of pack format numbers.
** {{nbt|compound|filter}}: Section for filtering out files from data packs applied below this one. Any file that matches one of the patterns inside {{mono|block}} will be treated as if it was not present in the pack at all.
*** {{nbt|list|block}}: List of patterns
****{{nbt|compound}}
*****{{nbt|string|namespace}}: A [https://en.wikipedia.org/wiki/Regular_expression regular expression] for the namespace of files to be filtered out. If unspecified, it applies to every namespace.
*****{{nbt|string|path}}: A [https://en.wikipedia.org/wiki/Regular_expression regular expression] for the paths of files to be filtered out. If unspecified, it applies to every file.
</div>

{{code|pack.mcmeta}}, as used by the "vanilla" data pack in [[Java Edition 1.19|1.19]], as found in the [[client.jar|client]] and [https://minecraft.net/download/server official server] jars:
<div class="collapsible collapsetoggle-inline" data-expandtext="show" data-collapsetext="hide">
<syntaxhighlight lang="json">
{
    "pack": {
        "pack_format": 10,
        "description": "The default data for Minecraft"
    }
}
</syntaxhighlight>
</div>

=== {{code|data}} ===

{{see also|Resource location#Namespaces}}

This folder contains all the data under one or multiple [[namespace]]s. It can contain {{code|advancements}}, {{code|dimension}}, {{code|dimension_type}}, {{code|functions}}, {{code|loot_tables}}, {{code|predicates}}, {{code|recipes}}, {{code|structures}}, {{code|tags}}, {{code|chat_type}}, {{code|damage_type}}, and/or {{code|worldgen}} folders. The {{code|worldgen}} folder can contain {{code|biome}}, {{code|configured_carver}}, {{code|configured_feature}}, {{code|density_function}}, {{code|flat_level_generator_preset}}, {{code|noise}}, {{code|noise_settings}}, {{code|placed_feature}}, {{code|processor_list}}, {{code|structure}}, {{code|structure_set}}, {{code|template_pool}} and {{code|world_preset}} folders.

The {{code|dimension}}, {{code|dimension_type}} and {{code|worldgen}} folders are currently experimental features.

Each advancement, function, loot table, predicate, structure, recipe and [[Tag|tag file]] can be placed directly in their respective folder but sub-folders are also allowed.
