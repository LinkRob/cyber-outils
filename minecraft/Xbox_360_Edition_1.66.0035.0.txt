'''Build 0035''' is a development version of {{edition|xbox 360}}. This version is based off [[Java Edition Beta 1.6.6]].

== Removals ==
* Removed the option to refresh the online games list in the world menu as it crashed the game when pressed.

== Fixes ==
* Fixed the gamma slider being stuck at 0.
* Fixed for the blocks randomly appearing after destroying it.

== Trivia ==

* This version is internally referred to as "Minecraft" instead of "Minecraft: Xbox 360 Edition" like the released version of the port.
