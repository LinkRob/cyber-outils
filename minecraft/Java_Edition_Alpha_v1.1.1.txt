'''Alpha v1.1.1''',<ref name="hg">{{ytl|X0eap0KWn5c|Minecraft 003- Into the Abyss|SuperClassicGaming|September 19, 2010}}</ref> also known as '''Seecret Saturday''',<ref name="seecret"/> is the tenth and final [[seecret update]], and is also the only Seecret Update released on Saturday, which added [[sneaking]], new [[painting]]s and [[fishing rod]]s. It was released with [[Alpha server 0.2.1|server 0.2.1]] on September 18, 2010, and is the only Seecret Saturday update; all other nine seecret updates were released on Fridays.

This version is notable for the gray screen bug. This code would set the display's gamma and contrast values to zero, resulting in the screen going completely gray.<ref>[[wordofnotch:1145841495|Regarding the Grayscreen issue]] – The Word of Notch, September 19, 2010</ref> It was available for just 205 minutes before Alpha v1.1.2 released, fixing the gray screen bug.<ref>https://youtu.be/VjZii8fhV1g?t=188</ref>

This version also took a very long time to download, due to a large influx of users downloading the game at the same time. As a result, not many players got the chance to play this version, due to how quickly it was replaced with Alpha v1.1.2.

== Additions ==

=== Items ===
;[[File:Fishing Rod JE1 BE1.png|24px]] [[Fishing rod]]s
* Have no use.
* Are stackable.

=== Non-mob entities ===

; [[Paintings]]:
* Added 5 new paintings:
* [[File:Graham Painting JE1 BE1.png|32px]] "Graham"
* [[File:Creebet Painting JE1 BE1.png|64px]] "Creebet"
* [[File:Donkey Kong Painting JE1 BE1.png|128px]] "Donkey Kong"
* [[File:Skeleton Painting JE1 BE1.png|128px]] "Skeleton"
* [[File:Pigscene Painting JE1 BE1.png|128px]] "Pigscene"

=== Gameplay ===
* [[File:Sneaking Steve.png|32px]][[Sneaking]]

=== General ===
* Added the ability to change mouse sensitivity
* Added sliders to change volume of sound and music

== Changes ==

=== Non-mob entities ===
; [[Painting]]s
* Two paintings have had their textures changed to their modern versions.
** Changed Sea painting from [[File:Sea Painting JE1.png|64px]] to [[File:Sea Painting JE2 BE1.png|64px]]
** Changed Stage painting from [[File:Stage Painting JE1.png|64px]] to [[File:Stage Painting JE2 BE1.png|64px]]

=== General ===
* Option to toggle the debug menu in the [[options]] has been replaced with the {{key|F3}} key. {{key|F3}} + {{key|S}} reloads all web-loaded resources.
* Smoother day-to-night and night-to-day transitions.

== Fixes ==
; 2 bugs fixed
* Infinite [[snowball]] exploit fixed where [[snow block]]s (requiring 4 snowballs) would be crafted then broken, producing 4–6 snowballs back.
* Solid snow blocks now only drop four snowballs.</onlyinclude>

== Trivia ==
* Despite this version being available for three hours and 25 minutes, considerably longer than other archived versions such as pre-reuploads of Beta 1.1, there were no known archives of it. An archived copy was not found until June 25, 2021, when Twitter user LunaSorcery provided an archived jar file.<ref>https://kotaku.com/minecraft-alpha-1-1-1-an-extremely-rare-version-was-f-1847179654</ref>
* There was a bug with crouching that caused the outer layer of custom skins render as if the player wasn't crouching.<ref>[https://youtu.be/VjZii8fhV1g they FOUND Minecraft Alpha 1.1.1?!] – [https://www.youtube.com/channel/UCK376qNDlNZZDNHsnaWuTeg AntVenom] on YouTube, July 2, 2021</ref>
* This version is identical to [[Java Edition Alpha v1.1.2|Alpha v1.1.2]], with the exception of the gray screen bug. The gray screen was caused by one line of code, or contrast and gamma, which was removed in Alpha v1.1.2.
* There is a common misconception that calm4.ogg either existed in the game files, or played in this version, which is untrue.
