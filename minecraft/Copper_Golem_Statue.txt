A '''copper golem statue''' is a [[copper|copper variant]] decorative block that was added in [[The Copper Age]]. It is created when a [[copper golem]] gets fully oxidized. It also undergoes oxidation process, just like all copper blocks.

== Obtaining ==
=== Breaking ===
Copper golem statues can be broken by hand, but using any pickaxe can break it faster.
{{breaking row|horizontal=1|Copper Golem Statue|Pickaxe}}

=== Post-generation ===
Copper golem statues are created when a [[copper golem]] gets fully oxidized. It will freeze in any pose and drop any items that it holds.

== Usage ==
=== Posing ===
Copper Golem Statues can change its pose by interacting with it. It cycles through four poses:
* Standing - Normal/Default
* Sitting
* Running
* Star

=== Oxidation ===
Like most [[Copper|copper blocks]], unwaxed copper golem statues undergo 4 stages of oxidation:
* Unoxidized - Normal stage
* Exposed
* Weathered
* Oxidized
Only lightning and [[axe]]s can reverse the oxidation process. Using a [[Honeycomb|honeycomb]] on an unwaxed copper golem statue prevents the oxidation.

Using an axe on an unwaxed unoxidized copper golem statue reverts it back to a normal unwaxed unoxidized [[copper golem]].

=== Interacting by [[Redstone]] ===
[[Redstone Comparator]]s can read the state of a copper golem statue. It emits a redstone signal strength based on its pose.

* Waxed Weathered Copper Golem Statue is the longest name of a block, at 35 characters including spaces and 31 without, surpassing polished blackstone pressure plate and cracked polished blackstone bricks.
