Places a [[custom feature#Configured Feature|configured feature]], [[Custom structure#Configured Structure Feature|configured structure feature]], [[Custom structure#Structure Template|structure template]], or [[Jigsaw block|jigsaw]] if possible.

== Syntax==
:<code>/place feature <feature> [<pos>]</code> 
::Place the [[custom feature#Configured Feature|configured feature]].
:<code>/place jigsaw <pool> <target> <max_depth> [<position>]</code>
::Place the [[Jigsaw block|jigsaw]].
:<code>/place structure <structure> [<pos>]</code> 
::Place the [[Custom structure#Configured Structure Feature|configured structure feature]].
:<code>/place template <template> [<pos>] [<rotation>] [<mirror>] [<integrity>] [<seed>]</code>
::Place the [[Custom structure#Structure Template|structure template]]. (Works like using the load button in the UI for a [[structure block]].)

==Arguments==
{{argument|feature|resource_key}}
:Specifies the [[custom feature#Configured Feature|configured feature]] to place. See [[Feature]] for vanilla configured features.
:{{arg desc|je=resource_key|registry=minecraft:worldgen/configured_feature}}

{{argument|structure|resource_key}} 
:Specifies the [[Custom structure#Configured Structure Feature|configured structure feature]]. See [[Generated structures]] for vanilla structures.
:{{arg desc|je=resource_key|registry=minecraft:worldgen/structure}}

{{argument|pool|resource_key}}
:Specifies the start [[Custom structure#Structure Pool|structure pool]] to start generating a jigsaw.
:{{arg desc|je=resource_key|registry=minecraft:worldgen/template_pool}}

{{argument|target|resource_location}} 
:Specifies the [[jigsaw block]] that is connected to when generating the start structure pool.
:{{arg desc|je=resource_location}}

{{argument|max_depth|integer}}
:Specifies the max depth of the jigsaw.
:{{arg desc|je=integer|min=1|max=7}}

{{argument|template|resource_location}}
:Specifies the [[Custom structure#Structure Template|structure template]] to place.
:{{arg desc|je=resource_location}}

{{argument|pos|block_pos}} and {{argument|position|block_pos}}
:Specifies the position the placement should be tried.
:{{arg desc|je=block_pos}}

{{argument|rotation|template_rotation}}
:Specifies the rotation to apply to the placed template.
:Must be either {{cd|none}}, {{cd|clockwise_90}}, {{cd|counterclockwise_90}}, or {{cd|180}}. If omitted, defaults to {{cd|none}}.

{{argument|mirror|template_mirror}}
:Specifies the mirroring to apply to the placed template.
:Must be either {{cd|none}}, {{cd|front_back}}, or {{cd|left_right}}. If omitted, defaults to {{cd|none}}.

{{argument|integrity|float}}
:Specifies the integrity value to apply to the placed template (how complete the template that gets placed is). If omitted, defaults to 1.0.
:{{arg desc|je=float|min=0.0|max=1.0}}

{{argument|seed|integer}}
:Specifies the seed to use for randomized degradation of the placed template when integrity is less than 1. If omitted, defaults to 0.
:{{arg desc|je=integer}}
