'''Project Malmö''' is the first and only mod supported by Mojang.<ref name=sup>http://www.mojang.com/2016/07/project-malmo-uses-minecraft-to-make-ai-smarter/</ref> It allows players to view and edit the ''Minecraft'' code.

==Additions==

Project Malmö adds the ability to view and edit the ''Minecraft'' code. It uses ''Minecraft'' to experiment with AI. It can allow mobs to craft, build, and do various other things.

==Download and Running==
===Downloading===

#Visit [https://github.com/Microsoft/malmo here] or alternatively chose a different version [https://github.com/Microsoft/malmo/releases here]
#Download

===Running===

====Windows====

#Type this in the Command Prompt while in the unzipped folder of Project Malmö:
    cd minecraft <br>  
    launchClient
#Launch an agent. (for more information see [https://github.com/Microsoft/malmo#launch-an-agent here])

====Mac and Linux====

#Type this in the terminal while in the unzipped folder of Project Malmö:
    cd minecraft && ./launchClient.sh
or,
    cd minecraft
    ./launchClient.sh
#Launch an agent. (for more information see [https://github.com/Microsoft/malmo#launch-an-agent here])
