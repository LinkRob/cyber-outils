'''Chat''' is a messaging system used to communicate with other players, or to execute commands. Several of these commands are [[Controls#Configurable controls|configurable]] (the defaults are shown here).

== Usage ==
By default, players can press {{key|T}} for keyboards, [[File:Chat button.png|25px]] for touchscreens,{{only|bedrock|education|short=1}} or {{Xbutton|onedpad-right}} for controllers{{only|bedrock|short=1}} to open the chat.

=== Communication ===
The chat can be used to communicate with other players or run commands by entering text into the chat. The following types of content can be entered into the chat:

* Regular text
* [[Commands]]
* Clickable hyperlinks
**Hyperlinks can only be entered via the {{cmd|tellraw}} command

==== Notes ====

*The section symbol (<code>§</code>) allows players to change the style of the text. See [[Formatting codes|the list of formatting codes]] for further details. This will not work on vanilla clients due to the fact that the section symbol is a restricted symbol.
*On [[Bedrock Edition]], certain emojis appear as icons in-game, such as the hunger and armor icons.<ref>https://github.com/TwistedAsylumMC/bedrock-unicode-characters</ref> Other emojis and unknown characters appear as a question mark (<code>?</code>).

=== Commands ===
{{main|Commands}}

Players can also type [[commands]] into the chat. Commands are identified by the use of a forward slash ({{key|/}}) at the beginning of the message. By default, the {{key|/}} key will open the chat with a <code>/</code> already present to easily run commands.

While typing, pressing {{key|TAB}} autocompletes the first possible command or username starting with the letter(s) typed. If there are multiple usernames or commands beginning with the letter(s), a list of possibilities is displayed; pressing  {{key|TAB}}  again scrolls through the list.
*Some commands may also have additional parameters that may be auto-completed by pressing {{key|TAB}} at that point.
**Certain commands that handle blocks ({{cmd|data}}, {{cmd|fill}}, etc.) have parameters that need the x, y, and z [[coordinates]] of the target block(s). Using the {{key|TAB}} key when these coordinates are needed automatically adds the coordinates of the block the player is looking at.

==== Errors ====
If a nonexistent command is run, a command that contains syntax errors, or if the entity executing the command does not have permission to use the specified command, the command will not function. The entity that executed that command then receives an error message (only visible to them) that states why the error occurred.

=== Chat history ===
A player can access the chat history via a small scroll bar is on the side of the chat bar. The player can also scroll using the mouse wheel or {{key|PgUp}} and {{key|PgDn}}. The last 100 chat messages are stored. Holding down {{Key|LSHIFT}} or {{Key|RSHIFT}} and attempting to scroll up or down slows down scrolling. The player can view their own recently sent messages by pressing the {{key|UP}} and {{key|DOWN}} keys while typing.

{{IN|java}}, the chat can be reduced in size, the opacity may be adjusted or it may be hidden via the [[Options#Chat settings|chat settings]] in the options menu. {{IN|bedrock}}, the chat settings are found within the chat screen and include options to change the color of the chat, its font, and its size.

{{IN|bedrock}}, swear words in multiple languages are censored and appear as asterisks.
