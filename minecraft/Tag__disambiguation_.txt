'''[[Tag]]''' is a feature which allows players to group blocks, items, and functions together using JSON files. 

'''Tag''' may also refer to:

* {{Command|tag}}, a command that controls scoreboard tags
* {{ItemLink|Name tag}}, a rare item that can be used to name mobs
* {{cmd|/scoreboard players tag}}, a removed command
* [[Scoreboard]], a complex gameplay mechanic utilized through commands. Scoreboard tags are a simple list of single-word strings stored in the Tags data tag of an entity.
* [[NBT format]] (Named Binary Tag format)
* [[Tag (item)]]
