'''Beta 1.0.2'''<ref>https://youtu.be/zYqlsLmeZLM</ref> is a version of [[Beta]] released on December 21, 2010, to fix some of the bugs and crashes in [[Java Edition Beta 1.0_01|Beta 1.0_01]].{{cn}}

== Fixes ==
;1 bug fixed
* Fixed a problem where the game wouldn't run on macOS.

== Trivia ==
* This version breaks the numbering convention of [[Beta 1.0]], seeing as other patches are numbered with _0''n,'' with ''n'' being the patch number. However, Beta 1.0.2 was never called Beta 1.0_02, therefore breaking the numbering convention. 
** This is not the only Beta patch version that does this, [[Beta 1.7_01]] does too.
