<samp>'''.minecraft'''</samp> (or simply <samp>'''minecraft'''</samp> in macOS) is the folder [[Java Edition|''Minecraft: Java Edition]] creates to run from. This folder includes the <samp>[[wikipedia:JAR (file format)|.jar]]</samp> files, sound, music, resource packs, personal options, worlds, etc.

== Locating <samp>.minecraft</samp> ==

{{/path}}

Locating the <samp>.minecraft</samp> folder can be vital for installing a resource pack or locating any made screenshots.

The Windows location in the table above is just the default case. Launchers can set the <samp>.minecraft</samp> at any path.

If you're a Windows user and are unfamiliar with how to find your appdata folder, follow these steps:

# Click Start → Run. If you don't see "Run", press {{key|Windows + R}}.
# Type {{code|%APPDATA%\.minecraft}} and click "OK".

If you're a Mac user, you can open the folder through Spotlight:

# Open Finder and press {{key|Shift + Command + G}} or open the Spotlight popup through the magnifying glass icon on the right of the Menu Bar.
# Type {{code|~/Library/Application&nbsp;Support/minecraft}} and hit {{key|Enter}}.

On Linux or macOS, the {{code|~}} in the path refers to the home directory. Folders starting with a {{code|.}} are hidden by default. In most file managers, hitting Ctrl + H toggles their hidden status. In macOS specifically, since version 10.12 (Sierra), the shortcut {{key|Command + Shift + .}} toggles the hidden status of files.


If you want to change directory of the <samp>.minecraft</samp> folder, see [[Tutorials/Custom Minecraft directory]].

Use of a resource pack can be forced by naming its zip file to {{cd|resources.zip}} and placing it in the root folder of the world save.<ref>[https://web.archive.org/web/20140221073128/https://www.mojang.com/2014/02/minecraft-snapshot-14w07a/ Minecraft snapshot 14w07a] – Dinnerbone on mojang.com; February 14, 2014</ref> This feature is single-player only;<ref>{{Cite bug|MC|73716|Resources.zip doesn't work for servers (and possibly LAN worlds)|date=October 27, 2014}}</ref> however, there is another way for servers to ask or force clients to use the server resource pack.

For Windows OS and Linux, the contents of {{Cd|nativelog.txt}} and {{Cd|nativeUpdaterLog.txt}} can be found within {{Cd|launcher_log.txt}} when applicable (i.e. the contents of{{Cd|nativeUpdaterLog.txt}} will only be present in {{Cd|latest_log.txt}} after the launcher is updated / launched for the first time).
