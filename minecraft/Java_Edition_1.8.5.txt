'''1.8.5'''<ref name="blogpost">{{cite|url=https://www.mojang.com/2015/05/minecraft-1-8-5-security-release/|archive-url=https://web.archive.org/web/0/https://www.mojang.com/2015/05/minecraft-1-8-5-security-release/|title=Minecraft 1.8.5 Security Release|author=Searge|website=Mojang.com|date=May 22, 2015}}</ref> is an update to ''[[Minecraft]]'' which was released on May 22, 2015 to fix a security related issue, a scoreboard related issue and some changes to splashes.<ref>{{tweet|SeargeDP|601446274798223362|We'll release Minecraft 1.8.5 in the morning to address a security related issue and a scoreboard issue. Thanks, @CrushedPixel for your help|May 21, 2015}}</ref><ref>{{tweet|CrushedPixel|601131990902054914}}</ref> 1.8.5 is compatible with 1.8 – 1.8.4 servers.

==Additions==
===General===
; [[Splash]]es
* Added "GNU Terry Pratchett".

==Changes==
===General===
; [[Splash]]es
* Removed the following splashes:
** "Happy birthday Notch!"
** "Happy Birthday ez!"
** "Notch <3 ez!"
* Changed "Cooler than Spock!" to "Not as cool as Spock!"
