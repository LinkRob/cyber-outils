'''signs.png-atlas''' is a procedurally-generated [[texture atlas]] used to store textures for all [[sign]]s.

== Format ==
<samp>signs.png-atlas</samp> is a fixed-width 256 × 128-pixel file that store textures for all signs.
It includes: <samp>entity/signs/acacia.png</samp>, <samp>entity/signs/bamboo.png</samp>, <samp>entity/signs/birch.png</samp>, <samp>entity/signs/cherry.png</samp>, <samp>entity/signs/crimson.png</samp>, <samp>entity/signs/dark_oak.png</samp>, <samp>entity/signs/hanging/acacia.png</samp>, <samp>entity/signs/hanging/bamboo.png</samp>, <samp>entity/signs/hanging/birch.png</samp>, <samp>entity/signs/hanging/cherry.png</samp>, <samp>entity/signs/hanging/crimson.png</samp>, <samp>entity/signs/hanging/dark_oak.png</samp>, <samp>entity/signs/hanging/jungle.png</samp>, <samp>entity/signs/hanging/mangrove.png</samp>, <samp>entity/signs/hanging/oak.png</samp>, <samp>entity/signs/hanging/spruce.png</samp>, <samp>entity/signs/hanging/warped.png</samp>, <samp>entity/signs/jungle.png</samp>, <samp>entity/signs/mangrove.png</samp>, <samp>entity/signs/oak.png</samp>, <samp>entity/signs/spruce.png</samp>, <samp>entity/signs/warped.png</samp>.
