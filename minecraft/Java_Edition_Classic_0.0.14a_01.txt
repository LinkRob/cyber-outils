{{Underscore title|Java Edition Classic 0.0.14a_01}}

'''0.0.14a_01'''<ref name=":0">{{link |url=https://web.archive.org/web/20170205200632/https://notch.tumblr.com/post/113985530/0014a-is-up-at-minecraftnet|title=0.0.14a is up at minecraft.net |date=May 28, 2009 |website=The Word of Notch}}</ref> was a version of Classic released on May 27, 2009, at 22:36 UTC, to fix a bug preventing players from loading saved worlds.<ref name="_01">[[#logs|IRC logs]]: "''(00:34:45) <Testvan> cant load the saved ones''" [...] "''(00:36:35) <@notch> 0.0.14a_01 is up, fixing the level load bug''" (May 27, 2009, 22:34 to 22:36 UTC)</ref>

== Fixes ==
* Tried to fix a bug from the previous version that prevented players from loading saved worlds.<ref name="_01"/>

== Bugs ==
* The [[player]] can no longer place blocks in [[liquid]]s.<ref>[[#logs|IRC logs]]: "''(00:36:54) <Testvan> hey notch why cant i build blocks under water anymore''" [...] "''(00:40:44) <pyl> but i can't build in water anymore?''" (May 27, 2009, 22:36 to 22:40 UTC)</ref>
* This version had a problem with some players getting null pointer exception errors.<ref>[[#logs|IRC logs]]: "''(00:38:09) <pyl> java.lang.NullPointerException''" [...] "''(00:40:08) <Duke[B12]> Quick question: Who else is getting the Java.lang null pointer exception error on loadind Minecraft?''" (May 27, 2009, 22:38 to 22:40 UTC)</ref>
* Some users could not load the game and got a black or white screen instead.<ref>[[#logs|IRC logs]]: "''(00:40:04) <Super-Dot> I was getting a black screen''" [...] "''(00:40:16) <Super-Dot> And now I'm getting a white screen =/''" (May 27, 2009, 22:40 UTC)</ref>
* There was an issue with mouse control.<ref>[[#Testvan's logs|IRC logs]]: "''[16:59] <@notch> yeah, there's an issue with mouse control, pyl''" (May 27, 2009, 22:59 UTC)</ref>

== Trivia ==
* Many features erroneously said to be implemented in 0.0.14a_01<ref>{{Mcnet|block-week-leaves|Block of the Week: Leaves|August 18, 2017}}</ref> were actually added in [[Java Edition Classic 0.0.14a|0.0.14a]].
