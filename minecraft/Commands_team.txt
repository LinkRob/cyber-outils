Controls teams.

==Syntax==

: <code>team list [<team>]</code>
:: Lists all teams, with their display names and the amount of entities in them. The optional <code><team></code> can be used to specify a particular team.
: <code>team add <team> [<displayName>]</code>
:: Creates a team with the given name and optional display name. <code><displayName></code> defaults to <code><team></code> when unspecified.
: <code>team remove <team></code>
:: Deletes the specified team.
: <code>team empty <team></code>
:: Removes all members from the named team.
: <code>team join <team> [<members>]</code>
:: Assigns the specified entities to the specified team. If no entities is specified, makes the executor join the team.
: <code>team leave <members></code>
:: Makes the specified entities leave their teams.
: <code>team modify <team> <''option''> <''value''></code>
:: Modifies the options of the specified team.

==Arguments==

: Specifies the name of a team.

{{argument|team|string}} (in <code>add</code> mode)

: {{arg desc|je=string|type=word}}

{{argument|displayName|component}}
: Specifies the team name to be displayed.

{{argument|members|score_holder}}
: Specifies the entities to join or leave the team. 
: {{arg desc|je=score_holder|amount=multiple}}

<code><''option''></code>
:: A specific option to change.
:: Value must be one of the following:
::*<code>displayName</code>: Set the display name of the team.
::*<code>color</code>: Decide the color of the team and players in chat, above their head, on the Tab menu, and on the sidebar. Also changes the color of the outline of the entities caused by the [[Glowing]] effect.
::*<code>friendlyFire</code>: Enable/Disable players inflicting damage on each other when on the same team. (Note: players can still inflict status effects on each other.) Does not affect some non-player entities in a team.
::*<code>seeFriendlyInvisibles</code>: Decide players can see invisible players on their team as whether semi-transparent or completely invisible.
::*<code>nametagVisibility</code>: Decide whose name tags above their heads can be seen.
::*<code>deathMessageVisibility</code>: Control the visibility of death messages for players.
::*<code>collisionRule</code>: Controls the way the entities on the team collide with other entities.
::*<code>prefix</code>: Modifies the prefix that displays before players' names.
::*<code>suffix</code>: Modifies the suffix that displays after players' names.

<code><''value''></code>
: Specifies the value to set <code><''option''></code> to.
: Shown below are the values for each option.
:*For <code>displayName</code>:
:**{{argument|displayName|component}} - Specifies the team name to be displayed. {{arg desc|je=component}}
:*For <code>color</code>:
:** {{argument|value|color}} - {{arg desc|je=component}}
:*** Defaults to <code>reset</code>. If <code>reset</code>, names are shown in default color and formatting.
:*For <code>friendlyFire</code>:
:** {{argument|allowed|boolean}} - {{arg desc|je=component}}
:***<code>true</code> - (Default) Enable players inflicting damage on each other when in the same team.
:***<code>false</code> - Disable players inflicting damage on each other when in the same team.
:*For <code>seeFriendlyInvisibles</code>:
:** {{argument|allowed|boolean}} - {{arg desc|je=component}}
:***<code>true</code> - (Default) Can see invisible players on the same team semi-transparently.
:***<code>false</code> - Cannot see invisible players on the same team.
:*For <code>nametagVisibility</code>:
:**<code>never</code> - Name above player's head cannot be seen by any players.
:**<code>hideForOtherTeams</code> - Name above player's head can be seen only by players in the same team.
:**<code>hideForOwnTeam</code> - Name above player's head cannot be seen by all the players in the same team.
:**<code>always</code> - (Default) Name above player's head can be seen by all the players.
:*For <code>deathMessageVisibility</code>:
:**<code>never</code> - Hide death message for all the players.
:**<code>hideForOtherTeams</code> - Hide death message to all the players who are not in the same team.
:**<code>hideForOwnTeam</code> - Hide death message to players in the same team.
:**<code>always</code> - (Default) Make death message visible to all the players.
:*For <code>collisionRule</code>:
:**<code>always</code> - (Default) Normal collision.
:**<code>never</code> - No entities can push entities in this team.
:**<code>pushOtherTeams</code> - Entities in this team can be pushed only by other entities in the same team.<ref name="bug">[[bugtracker:MC-87984|MC-87984]]</ref>
:**<code>pushOwnTeam</code> - Entities in this team cannot be pushed by another entity in this team.<ref name="bug"></ref>
:*For <code>prefix</code>:
:**{{argument|prefix|component}} - Specifies the prefix to display. {{arg desc|je=component}}
:*For <code>suffix</code>:
:**{{argument|suffix|component}} - Specifies the suffix to display. {{arg desc|je=component}}
