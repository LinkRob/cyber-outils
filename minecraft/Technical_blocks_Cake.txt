{{History|java beta}}
{{History||1.2|Cake has an extra item form corresponding to its block ID, which can be obtained via inventory editors with numeric item ID 92. It is not intended to be obtained in conventional gameplay.}}
{{History||1.6|snap=Test Build 3|Cake items can be obtained from the newly added debug chests, mainly from the 7th slot of the 4th chest from the left, and the 18th slot of the 7th chest from the left.}}
{{History|||snap=release|Debug chests no longer spawn, preventing cake items from being obtained this way.}}
{{History||1.8|snap=Pre-release|Cake blocks are now available in the Creative inventory.}}
{{History|||snap=Pre-release 2 ;)|Added pick block functionality. This changes the currently selected slot to any containing this otherwise-unobtainable cake item, but does not allow it to be obtained if not already in the hotbar.}}
{{History|java}}
{{History||1.0.0|snap=Beta 1.9 Prerelease 6|Cake blocks no longer are available in the creative inventory.}}
{{History||1.2.5|snap=pre|Cake items can now be obtained via Pick Block in creative.}}
{{History||1.3.1|snap=12w15a|Cake items can no longer be obtained with pick block in Creative - the proper intended item for cake is returned instead.}}
{{History|||snap=12w16a|Cake items can now be obtained in singleplayer worlds via the {{cmd|give}} command using the respective numeric ID.}}
{{History||1.7.2|snap=13w37a|The direct item form of cake has been removed from the game. It can no longer exist as an item in any way, only as a placed block.}}
{{History|pocket alpha}}
{{History||v0.7.0|Cake exists as an item.}}
