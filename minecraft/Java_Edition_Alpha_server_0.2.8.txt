'''0.2.8''' is a server version of [[Java Edition Alpha]] released on December 3, 2010.<ref>{{tumblr|notch|2082284675|Bug update #5, and we need videos}}</ref> It was not mandatory to upgrade to this version.

== Changes ==
* [[Player]]s connecting to a [[server]] or [[respawn]]ing are invulnerable for three seconds.
* The join server page now remembers the port as well as the IP.
* Added command {{cmd|kill}} for multiplayer, which deals {{hp|1000}} [[damage]] to the [[player]].

== Fixes ==
* Fixed a bug where joining a server on a specific port caused the client to forget all keybindings.
