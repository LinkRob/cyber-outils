'''Void start platforms''' are a [[feature]] of 33×33 square of [[stone]] with a single block of [[cobblestone]] in the center. One can generate at the origin of [[Superflat]] and [[Buffet]] worlds if in [[The Void|<code>the_void</code> biome]].

== Generation ==
Void start platforms spawn from [[Coordinates#Block position|block positions]] (-8, -61, -8) to (24, -61, 24), and thus the [[player]] spawns at Y=-60. This feature is most easily accessible through "The Void" [[Superflat#Presets|preset]] but it still generates if different layers are specified, even if it gets engulfed.  Void start platforms replace any blocks such as even Bedrock when generated underground.

== Construction ==
{{main|Void Start Platform/Structure}}
Void start platforms are large platforms made up of [[stone]] and [[cobblestone]].
