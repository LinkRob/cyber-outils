'''shield_patterns.png-atlas''' is a procedurally-generated [[texture atlas]] used to store textures for all [[shield]]s and shield [[banner pattern]]s.
{{-}}
== Format ==
<samp>shield_patterns.png-atlas</samp> is a fixed-width 512 × 512-pixel file that store textures for all shields and shield banner patterns.
