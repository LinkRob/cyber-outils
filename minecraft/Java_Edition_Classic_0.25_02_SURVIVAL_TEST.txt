'''0.25_02 SURVIVAL TEST''', an implicit retroactive renaming of the second reupload of [[0.25 SURVIVAL TEST]], so therefore labeled '''0.25 SURVIVAL TEST''' in-game, was a version of [[Survival Test]] released September 3, 2009, at around 16:26 UTC.<ref name="release">[[#logs|IRC logs]]: "''A11:26:38 <08Notch> ok, I fixed the creeper craters''" [...] "''A11:26:43 <08Notch> and added a load button to the death screen''" (16:26 UTC)</ref> This version is not available in the launcher.

== Changes ==

===Mobs=== 
;[[Creeper]]
*Have the same blast radius as they did before [[Java Edition Classic 0.25 SURVIVAL TEST|0.25]].<ref name="release" />{{More info needed|What was it before?}}

===General=== 
;Game over screen
*Added a "Load Level" button to the [[death]] screen.<ref name="release" />
