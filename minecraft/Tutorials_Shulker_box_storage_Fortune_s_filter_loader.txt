== Notes ==
* The 'chest' B in the schematic must be a barrel, so that a button can be placed on it.
* Empty shulker boxes are loaded into the barrel.  The system is then primed by pressing the barrel's button.
* A single item (any item) must be placed into the top-left hopper.
* The hopper pointed into a comparator is where you [[Tutorials/Hopper#Item sorter|configure the filter]].
* The top-most hopper is part of the item input hopper line that goes through as many multiple filter/loader modules as you like.
