'''Unbreaking''' is an [[enchantment]] that gives a chance for an item to avoid [[durability]] reduction when it is used, effectively increasing the item's [[durability]].

[[File:Unbreaking Enchantment Tool Negative Binomial.png|alt=Unbreaking Enchantment Tool Negative Binomial Graph|thumb|200px|The probability of a tool breaking after a number of uses with different levels of this enchantment. Some lower durability materials may last longer than higher durability materials with some enchantment levels.]]

== Obtaining ==
Unbreaking I, Unbreaking II, and Unbreaking III can be acquired using an [[enchanting table]], by [[fishing]], finding an enchanted book in dungeon chests, and by trading with a librarian [[villager]].

== Usage ==
For most items, there is a <math>\frac{100}{\text{level}+1} \%</math> chance that using the item reduces durability. Meaning the item has a 50%/~66%/75% chance of not using any durability. On average, tools last <math>\text{level}+1</math> times as long.

For [[armor]], there is a <math>\left( 60 + \frac{40}{\text{level} + 1} \right) \%</math> chance a use reduces durability, meaning each durability hit against Unbreaking armor has a ~20%/27%/30% chance of being ignored. On average, armor lasts <math>\frac{1}{0.6+\frac{0.4}{\text{level}+1}}</math> times as long.

When durability is reduced by multiple points, as when hooking a mob with [[fishing rod]]s or getting blown up with TNT, Unbreaking is applied for each point of reduction.
