'''client_request_placeholder_block''' is an [[invisible block]] of unknown use.

== Usage ==
Its intended use is unknown, however since it acts as an opaque block while being visually transparent it allows for solid blocks adjacent to it to be seen through.<ref>https://youtu.be/pueON00AgQ4</ref> It might be used by the client when unloading a chunk/updating a block.
