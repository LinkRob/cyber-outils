The '''optimize world''' screen is a game menu that is used to upgrade the level data of a [[world]] to the latest format. If the player optimizes a world, it is no longer compatible with previous versions of the game. Also, player scoreboard from datapack( at least), player advancements is erased.

== Options ==
;Erase cached data
* Cached data for the world is erased. This includes [[light]] levels and [[biome]]s, among other things.{{info needed}}
;Create backup and load
* Creates an unoptimized backup of the world, and then proceeds with optimizing the original one.
;I know what I'm doing!
* Optimizes the world without creating a backup.
