'''shulker_boxes.png-atlas''' is a procedurally-generated [[texture atlas]] used to store textures for all [[shulker]]s and [[shulker box]]es.

== Format ==
<samp>shulker_boxes.png-atlas</samp> is a fixed-width 512 × 256-pixel file that store textures for all shulkers and shulker boxes.
