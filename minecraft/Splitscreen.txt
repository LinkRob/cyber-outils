'''Splitscreen''' is a console-exclusive feature that allows up to four players to play on one screen at the same time. It is supported on console versions of {{el|be}}. [[Realms]], and peer-to-peer online multiplayer have support for splitscreen. External servers, including the [[featured servers]], do not.

Using Splitscreen requires a screen with an output of at least 720p or higher. On television screens, this can be achieved using either an [[Wikipedia:HDMI|HDMI]] or [[Wikipedia:Component video#RGB analog component video|RGB component cable]].
