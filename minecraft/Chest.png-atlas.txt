'''chest.png-atlas''' is a procedurally-generated [[texture atlas]] used to store textures for all [[chest]]s.
{{-}}
== Format ==
<samp>chest.png-atlas</samp> is a fixed-width 256 × 256-pixel file that store textures for all chests.
