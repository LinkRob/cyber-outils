'''blocks.png-atlas''' is a [[texture atlas]] used to store all [[block]] and [[item]] textures and some [[block entity]] and [[entity]] textures.

== Format ==
<samp>blocks.png-atlas</samp> is a fixed-width 1024x512-pixel file that is split into different 16×16-pixel squares for most blocks and items. Only the top left 1024x512 corner is is actually filled with blocks and items in the base gme default textures.

The following textures are included:
* All [[block]] textures
** including [[item frame]]s, due to being handled with block models
* All [[fluid]] textures
* All [[item]] textures
* [[Conduit]] eye, closed and open<ref name="RemainderEntities">{{bug|MC-241061}}</ref>
* Conduit shell, closed and open<ref name="RemainderEntities"/>
* [[Bell]]<ref name="RemainderEntities"/>
* [[Enchanting table]] book<ref name="RemainderEntities"/>
* Block breaking animation
* [[Missing texture]]
