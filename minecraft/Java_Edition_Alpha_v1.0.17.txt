'''Alpha v1.0.17''',<ref>{{link|url=http://web.archive.org/web/20180522125714/https://forum.facepunch.com/f/games/twaf/Minecraft-V35-Ultimate-Edition/49/#postseajd|title=Minecraft V35 - Ultimate Edition!, page 49|website=Facepunch Forums|date=August 20, 2010}}</ref> also known as '''Seecret Friday 8''', was the eighth [[Seecret Update]] which added [[fence]]s and [[spider jockey]]s.

== Additions ==
=== General ===
* [[Chicken]]s, [[slime]]s<ref>http://i38.tinypic.com/svmmab.jpg{{Dead link|Image not properly archived}}</ref> and [[pig]]s added in multiplayer.
* Working [[day/night cycle]] in multiplayer.

=== Blocks ===
;[[File:Oak Fence JE1.png|32px]] [[Fence]]s
*The player starts with 64 fences in the inventory.

=== Mobs ===
; [[File:Spider Jockey a1.0.17.png|36px]] [[Spider Jockey]]s
* Skeletons can ride spiders.<ref>{{tweet|notch|21693262563|So skeleton archers riding giant jumping spiders is overpowered? Just wait until I add dragons!|August 20, 2010}}</ref><ref>https://www.neogaf.com/threads/minecraft-ot.401027/post-22924983</ref>
* The first [[Jockey|jockey]] to be added into the game.

== Changes ==
* [[Milk bucket]]s can now be emptied.
* [[Third-person view]] is now centered again.
* Right clicking on usable blocks makes the player's arm swing to match the third person animation for right clicking.
* Chickens no longer take fall damage and now slowly glide down using their wings.

[[File:Alpha 1.0.17 Fences.png|300px|thumb|A sheep surrounded by fences.|alt=]]

== Trivia ==
* Alpha v1.0.17 has the highest minor version number since Classic, at "17". The highest {{in|bedrock|lc=}} is "221", with [[Bedrock Edition 1.16.221]], and the highest in the full release of {{el|je}} is "11", with [[Java Edition 1.21.11|1.21.11]].
