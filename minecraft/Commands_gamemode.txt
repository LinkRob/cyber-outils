Sets a player's [[game mode]].

==Syntax==

* '''Java Edition'''
: <code>gamemode <gamemode> [<target>]</code>

* '''Bedrock Edition'''
: <code>gamemode <gameMode: GameMode> [player: target]</code>
: <code>gamemode <gameMode: int> [player: target]</code>

==Arguments==

{{el|je|short=1}}: {{argument|gamemode|gamemode}}<br>
{{el|be|short=1}}: {{argument|be=1|gameMode: GameMode|enum}} and {{argument|be=1|gameMode: int|int}}
: Specifies the new game mode.
:{{arg desc|je=gamemode|be=enum}}
{{argument|target|entity|player: target|CommandSelector<Player>}}
: Specifies the target(s). If not specified, defaults to the player who executes the command.
: {{arg desc|je=entity|amount=multiple|type=players|be=player}}

{{Result table|<code>gameMode: int</code> is not a valid game mode id.|N/A|fail}}
{{Result table|<code>player: target</code> is not in [[Target selectors#Player type and single type|player type]]}}
{{Result table|<code><target></code> or <code>player: target</code> fails to resolve to one or more online players|fail}}

==Examples==

* To put the executing player into Creative mode:
*: <code>/gamemode creative</code>
*: <code>/gamemode c</code>{{only|bedrock}}
*: <code>/gamemode 1</code>{{only|bedrock}}

* To put all players into Survival mode:
*: <code>gamemode survival @a</code>

==See also==

*{{cmd|defaultgamemode}} – sets the initial game mode for players joining the world.
