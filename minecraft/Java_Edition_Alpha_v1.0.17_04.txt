'''Alpha v1.0.17_04''' is a version of [[Alpha]] released on August 23, 2010,<ref>[[wordofnotch:999812927|"Minecraft Alpha v1.0.17_04"]] – The Word of Notch, August 23, 2010</ref> to fix a bug relating to the player getting stuck. This version is available in the [[Minecraft launcher|launcher]].

== Fixes ==
*Fixed some instances of the player getting stuck.{{more info}}

== Trivia ==
*The original Brocraft [[Herobrine]] livestream took place in this version. The [[world seed]] in which the Herobrine stream took place is {{code|3609313613745973624}}.
