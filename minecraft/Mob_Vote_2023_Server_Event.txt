

The '''Mob Vote 2023 Server Event''' is an [[Event servers|event server]] that was hosted as part of [[Minecraft Live 2023|''Minecraft Live'' 2023]], where players could participate in the yearly [[Mob Vote|mob vote]]. (for more detailed page go to https://minecraft.fandom.com/wiki/2023_mob-vote?veaction=edit) :3
