Sends a [[Raw JSON text format|JSON message]] to players.

==Syntax==

* '''Java Edition'''
: <code>tellraw <targets> <message></code>

* '''Bedrock Edition'''
: <code>tellraw <target: target> <raw json message: json></code>

==Arguments==

{{argument|targets|entity|target: target|CommandSelector<Player>}}
: Specifies the player(s) to send the message to.
: {{arg desc|je=entity|amount=multiple|type=players|be=player}}

{{argument|message|component|raw json message: json|Json::Value}}
: Specifies the message to send.
: {{arg desc|je=component|be=Json::Value}}

== Examples ==
* To send the message "Hello" in chat:
** <code>/tellraw @a "Hello"</code>{{only|java}}
** <code>/tellraw @a {"rawtext":[{"text":"Hello"}]}</code>{{only|bedrock}}
* To send the message "I am blue" colored blue in chat:
** <code>/tellraw @a {"text":"I am blue","color":"blue"}</code>{{only|java}}
** <code>/tellraw @a {"rawtext":[{"text":"§bI am blue"}]}</code>{{only|bedrock}}
* To send the message "Hover me!" in chat, which displays the text "Hi!" when hovered over:
** <code>/tellraw @a {"text":"Hover me!","hoverEvent":{"action":"show_text","value":"Hi!"}}</code>{{only|java}}
* Use '\n' to insert a new line:
** <code>/tellraw @a "Text1\nText2"</code>{{only|java}}
** <code>/tellraw @a {"rawtext":[{"text":"Text1\nText2"}]}</code>{{only|bedrock}}
* Display a message in the [[Enchantment Table]]'s glyphs:
** <code>/tellraw @a {"text":"Hello World","font":"alt"}</code>{{only|java}}
* Display a message in the [[illager]] runes:
** <code>/tellraw @a {"text":"Hello World","font":"illageralt"}</code>{{only|java}}
