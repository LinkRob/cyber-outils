{{History|java alpha}}
{{History||v1.2.0|snap=preview|Nether portals have an unobtainable item form corresponding to its block ID. It can be obtained via inventory editors with numeric item ID 90.
|When placed, nether portal blocks will always be in the east-west position. Further updates to the block will result in instantaneous deletion.}}
{{History|java beta}}
{{History||1.6|snap=Test Build 3|Nether portal items can be obtained from the newly added debug chests, mainly from the 5th slot of the 4th chest from the left, and the 16th slot of the 7th chest from the left.}}
{{History|||snap=release|Debug chests no longer spawn, preventing Nether portal items from being obtained this way.}}
{{History||1.8|snap=Pre-release 2 ;)|Added pick block functionality. This will change the currently selected slot to any containing a nether portal item, but will not allow it to be obtained if not already in the hotbar.}}
{{History|java}}
{{History||1.2.5|snap=pre|Nether portal items can now be obtained via Pick Block in creative.}}
{{History||1.3.1|snap=12w16a|Nether portal items can now be obtained in singleplayer worlds via the {{cmd|give}} command using the respective numeric ID.}}
{{History|||snap=12w17a|Nether portals can no longer be obtained with pick block in Creative.}}
{{History|||snap=12w18a|Likely due to the server split in this version, nether portal blocks now take a frame to disappear when updated. As a result, when two nether portal blocks are placed next to each other horizontally with the item, they can be seen to connect.}}
{{History||1.8|snap=14w25a|The direct item form of Nether portals has been removed from the game. It can no longer exist as an item in any way, only as a placed block.}}
{{History|pocket alpha}}
{{History||?|Nether portals exist as an item.}}
{{History|unknown}}
{{History||?|Nether portal blocks, when placed with this item, while always facing a single direction by default, would rotate accordingly if placed next to an existing nether portal block to connect with it.<ref>https://youtu.be/2UUX5gJdf2A?t=8m46s</ref>}}
{{History||?|Nether portal blocks no longer align with other placed nether portal blocks and instantly disappear, unless the only surrounding blocks are nether portals, [[air]], and/or [[obsidian]].}}

==== Appearances ====

{{History|java alpha}}
{{History||v1.2.0|snap=preview|Nether portal items have an unstable item model which changes depending on blocks which are targeted or in loaded chunks. It uses this model in inventories, when held in first or third person view or as a dropped item.
|[[File:Nether Portal (inventory) (NESW) JE1.png|32px]] Initially the Nether portal item would appear as a full cube like many other blocks, but targeting an existing portal block would cause the item to morph into its shape: [[File:Nether Portal (inventory) (NS) JE1.png|32px]] [[File:Nether Portal (inventory) (EW) JE1.png|32px]]
|Having an existing nether portal block within loaded chunks also appears to influence the shape of the nether portal item. For example, if no existing blocks are loaded, the item may appear in its full cube state, but loading a chunk containing an north-south oriented nether portal will result in the item automatically becoming north-south.}}
{{History|java beta}}
{{History||1.6|snap=Test Build 3|[[File:Nether Portal (inventory) (NS) JE2.png|32px]] [[File:Nether Portal (inventory) (EW) JE2.png|32px]] [[File:Nether Portal (inventory) (NESW) JE2.png|32px]] Block items have changed in this version to be brighter and rotated 90 degrees clockwise from their prior appearances. The "pane" appearance shapes can be seen to have been inverted as a result, with east-west oriented how north-south was previously and vice versa.}}
{{History||1.8|snap=Pre-release|[[File:Nether Portal (inventory) (NS) JE3.png|32px]] [[File:Nether Portal (inventory) (EW) JE3.png|32px]] [[File:Nether Portal (inventory) (NESW) JE3.png|32px]] Block items are now far brighter than before.}}
{{History|java}}

{{History||1.3.1|snap=12w22a|[[File:Nether Portal (inventory) (NS) JE5.png|32px]] [[File:Nether Portal (inventory) (EW) JE5.png|32px]] [[File:Nether Portal (inventory) (NESW) JE5.png|32px]] Block items have been rotated back to their pre-Beta 1.6 orientations.}}
{{History||1.4.2|snap=12w34a|[[File:Nether Portal (inventory) (NS) JE6.png|32px]] [[File:Nether Portal (inventory) (EW) JE6.png|32px]] [[File:Nether Portal (inventory) (NESW) JE6.png|32px]] Block items have been brightened to an almost unnoticeable degree.}}
