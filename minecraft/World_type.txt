'''World type''' is an option to change how worlds generate in ''[[Minecraft]]''.

== ''Java Edition'' ==
{{main|World preset|Custom world preset}}

When creating a new world, in the "More world options..." screen, players can choose which world preset to use, or not use world preset. [[World preset]]s are used to determine the dimensions the world has, which can be controlled by data packs.
