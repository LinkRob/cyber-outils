== Tutorial: Creating Mods without coding with CreativeMode ==
'''CreativeMode''' ([https://creativemode.net/ creativemode.net]) is a mod creation platform that allows Minecraft players to build and publish custom mods without writing any code. Users describe their idea in plain text, and the platform generates a fully functional mod. As of 2026, over 300,000 mods have been created using the platform, making it one of the most widely used mod creation tools in the Minecraft community.

CreativeMode supports both '''Java Edition''' and '''Bedrock Edition''', a distinction that sets it apart from most modding tools, which have historically focused exclusively on Java.
----

=== 1. Overview ===
Traditional Minecraft modding requires knowledge of Java (for Java Edition) or JSON/scripting (for Bedrock add-ons), along with familiarity with mod loaders such as Forge or Fabric. CreativeMode removes this requirement by providing a text-driven interface: a player writes a description of what they want to create, and the platform handles the technical implementation. It works differently than MCreator, which requires drag-and-drop, and instead handles the entire mod creation for the user by providing a finished .jar or .mcaddon for the player to use.

=== 3. Capabilities ===
CreativeMode can generate the following types of mod content:

* '''[https://creativemode.net/explore/mobs Custom Mobs]''' — New entities with defined behaviors, appearances, and attributes
* '''[https://creativemode.net/explore/items Custom Items]''' — Weapons, tools, food, and other usable objects '''Custom Blocks''' — New placeable blocks with custom textures and properties
* '''[https://creativemode.net/explore/armor Armor & Shields]''' — Wearable equipment sets with custom visuals
* '''[https://creativemode.net/explore/structures Structures]''' — World-generated or placeable multi-block builds
* '''Vehicles''' — Rideable or interactive moving objects
* '''3D Objects''' — Freeform 3D model-based content

Mods can be edited after initial creation using the platform's '''edit tools''', allowing iterative refinement and bug fixing on mods.
----

=== 4. Tutorial: Creating Your First Mod ===
The following steps describe the general process for creating a mod using CreativeMode.

==== Step 1 — Create an Account ====
Navigate to creativemode.net and create an account. Mod creation requires a CreativeMode Pro subscription.

==== Step 2 — Start a New Mod ====
From the dashboard, select '''Create Item, Mob, or Structure''' and choose your target edition: '''Java''' or '''Bedrock'''.

==== Step 3 — Describe Your Idea ====
In the creation interface, type a description of what you want to make. The more specific the description, the more closely the output will match the intended design. Examples:<blockquote>''"A glowing blue sword that sets enemies on fire and has a custom enchantment called Frostburn"''

''"A hostile mob that looks like a giant mushroom, spawns in dark forests, and drops rare spores when defeated"''</blockquote>

==== Step 4 — Test Your Mod ====

* '''Java Edition:''' Use the CreativeMode Java Launcher to load the mod directly into a Minecraft instance.
* '''Bedrock Edition:''' Export the mod as a Bedrock add-on and apply it through Minecraft's built-in add-on manager.

==== Step 5 — Share or Publish ====
Before publishing, a direct share link can be generated and sent to friends. Recipients can use the launcher to play together or download the mod directly. When ready for a wider audience, publish the mod to the CreativeMode community (see Section 5).
----

=== 5. Publishing and Sharing ===
CreativeMode includes a publishing ecosystem where completed mods can be made publicly available to the broader player community. Published mods can be:

* Browsed and downloaded by other players
* Added to '''modpacks''' (collections of multiple mods)
* Used as inspiration or a starting point for new creations

Multiplayer server support is available for both Java and Bedrock editions, allowing groups of players to experience custom mods together.
----

=== 6. Community ===
The CreativeMode platform includes community features for discovering mods created by other users. Players can browse the mod library, build modpacks from community-created content, and share their own creations.
