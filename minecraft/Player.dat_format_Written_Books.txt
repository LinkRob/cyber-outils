** {{nbt|byte|resolved}}: Optional. Created and set to 1 when the book (or a book from the stack) is opened for the first time after being created. Used to determine whether to [[Raw JSON text format#Component resolution|resolve advanced components]] within JSON, because their values become fixed at that point.
** {{nbt|int|generation}}: Optional. The copy tier of the book. 0 = original, 1 = copy of original, 2 = copy of copy, 3 = tattered. If the value is greater than 1, the book cannot be copied. Does not exist for original books. If this tag is missing, it is assumed the book is an original. 'Tattered' is unused in normal gameplay, and functions identically to the 'copy of copy' tier. 
** {{nbt|string|author}}: The author of the written book.
** {{nbt|string|title}}: The title of the written book. Lower priority than the item name set by [[Player.dat format/Display Properties|<code>tag.display.Name</code>]]. Can not be used to open locked containers.
** {{nbt|list|pages}}: The list of pages in the book.
*** {{nbt|string}}: A single page in the book. Each page is a serialized [[Raw JSON text format#Java Edition|JSON text]].
