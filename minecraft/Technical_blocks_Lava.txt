{{History|java classic}}
{{History||?|Lava has an extra, unobtainable item form corresponding to its block ID, which uses the "texture" rendered as a cube.}}
{{History||?|Flowing lava can be obtained via inventory editors with numeric item ID 10.
|Still lava can be obtained via inventory editors with numeric item ID 11.}}
{{History||0.24_SURVIVAL_TEST|Lava can be obtained as an item by having a [[creeper]] [[explode]] near it.}}
{{History||0.24_SURVIVAL_TEST_03|Explosions no longer drop lava as an item.}}
{{History|java infdev}}
{{History||20100615|When placed, still lava items always remain still until receiving a block update. Flowing lava items spread immediately.}}
{{History|java beta}}
{{History||1.6|snap=Test Build 3|Lava items can be obtained from the newly added debug chests, mainly from the 10th slot of the 1st chest from the left, and the 21th slot of the 4th chest from the left.
|Flowing lava items can be obtained from the newly added debug chests, mainly from the 11th slot of the 1st chest from the left, and the 22nd slot of the 4th chest from the left.}}
{{History|||snap=release|Debug chests no longer spawn, preventing lava and flowing lava items from being obtained this way.}}
{{History|java}}
{{History||1.3.1|snap=12w16a|Lava items can now be obtained in singleplayer worlds via the {{cmd|give}} command using the respective numeric IDs.}}
{{History||1.8|snap=14w25a|The direct item forms of lava and flowing lava have been removed from the game. They can no longer exist as items in any way, only as placed blocks.}}
{{History|pocket alpha}}
{{History||?|Lava exists as an item.}}
