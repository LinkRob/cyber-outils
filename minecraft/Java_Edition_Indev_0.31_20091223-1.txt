The first version of '''[[Indev 0.31]]''' was released on '''December 23, 2009''' at 00:40 UTC.<ref name=":0">[[wordofnotch:295879830|Oh, ok! Here, play with a version!]] – The Word of Notch, December 23, 2009</ref><ref>[[#logs|IRC logs]]: "''P6:40:14 <�08Notch�> http://www.minecraft.net/indev/''" (00:40 UTC)</ref>

This is the first version of the [[Indev]] development cycle of ''Minecraft'', and the first paid version of ''Minecraft'' (available at €5.00), as Notch released this version for paid users to test out new features.<ref name=":0"/>

== Additions ==
=== Mobs ===
; [[File:Rana.png|32px]] [[Rana]]
* Has the [[player]]'s shadows.
* All other mobs no longer spawn.

=== General ===
; [[Light]]ing
* Added dynamic lighting.
* There are 9 different light levels.
** Due to this, caves have now been made darker.
* Oddly, [[blocks]] in the [[inventory]] and [[hotbar]] are affected by lighting - upon generating a new world they appear dark, then go back to normal brightness after a while.
* Shadows appear below mobs.
* Changed shading on the sides of blocks.

;Debug
*Placing a [[TNT]] block, and then destroying it, will cause the layer below to turn to wood, but only blocks made of the same material get replaced.<ref>[http://www.youtube.com/watch?v=LmnESwvfIRk Minecraft 0.31 Plank Glitch]</ref> This was used by Notch to debug flooding.<ref>[[#logs|IRC logs]]: "''P6:58:46 <�08Notch�> if you place tnt above ground and destroy it you can make roofs very fast''" (00:58 UTC)</ref>

==Changes ==
===Gameplay===
;[[Game mode]]s
*This version, as well as 20091223-2, is in [[Creative mode]].
**[[Survival mode]] can be added back via modding. 

;[[Survival]] mode{{verify|type=untestable|edition=java|Could be in-1223-2}}
**The player now spawns with 99 stone slabs, stone, [[Water]] [[blocks]] and [[Lava]] blocks (leftover from an unreleased Indev 0.30 version).
**TNT was removed from hotbar.
**Removed primed [[TNT]], arrows, block drops and all mobs except [[Rana]] from the code.
**[[Blocks]] no longer drop [[items]] when mined.
**Attempting to fire arrows will not do anything.
** The player only has one bubble of [[air]] bubble when breathing underwater, down from 10.
**No survival build of this version was released, so these changes go unused, and can only be found via modding.

; [[Multiplayer]]
*Multiplayer was made partially inaccessible (although the multiplayer code still exists and can be re-enabled). 
** Connecting to a multiplayer server will cause players to spawn in a [[bedrock]] cube.{{citation needed}}
**The game will act as if it is in Singleplayer – [[chat]] is inaccessible and the player list cannot be opened.

; General
*New work-in-progress level format.
**Level saving/loading no longer works.
*[[File:Dandelion (item) JE1.png|16px]] Flowers in the build screen are now shown with both sprites crossed.<ref>[[#logs|IRC logs]]: "''P6:48:18 <Iguana> Plants and such look very squished in the inventory. :P''" (00:48 UTC)</ref>
*The player's fist no longer displays.
*Rain will now go through glass.
*The world is now generated as a small size by default.<ref>[[#logs|IRC logs]]: "''P6:57:25 <�08Notch�> oh yeah, I made it default to small while I was developing for quicker map regeneration times. =)''" (00:57 UTC)</ref>
* Grass block no longer spreads.
*Leaf particles fall at the normal speed again.{{verify|edition=java|type=change}}
*The size of the .jar file has been changed (1765K instead of 285K the previous version ([[Java Edition Classic 0.30]])) because of 4 new .md3 files. For more information, see [[Java Edition Indev 0.31 20091223-1/Development]].

==Bugs==
*Generating new world in a huge size sometimes causes a lot of Rana to spawn close to the player, resulting sometimes the game freezing.
*Placing a block on a slab causes the space between to be completely dark.
*The top of the map is completely dark.
* Block breaking particles are pitch black.<ref>[[#logs|IRC logs]]: "''P6:45:39 <Snowman> Block breaking particles are pitch black''" (00:45 UTC)</ref>
