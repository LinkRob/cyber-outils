A '''smooth quartz block''' is a mineral [[block]] used only for decoration. It is made by smelting [[blocks of quartz]].

== Obtaining ==

=== Breaking ===

Smooth quartz blocks can be [[breaking|mined]] using any [[pickaxe]]. If mined without a pickaxe, it [[drops]] nothing.
{{breaking row
|horizontal=1
|Smooth Quartz Block
|Pickaxe
|Wood
}}

=== Natural generation ===

2 smooth quartz blocks generate naturally as part of each bridge [[bastion remnant]].
