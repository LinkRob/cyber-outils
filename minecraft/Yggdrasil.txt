'''Yggdrasil''' is the name of the authentication system that is currently used for authenticating user credentials for ''Minecraft''.

''Minecraft'' [[Java Edition 1.6-pre]]{{verify|edition=java|type=change}} introduced this new authentication scheme, completely replacing the previous authentication system. [[Mojang Studios|Mojang's]] other game, [[Scrolls]], uses this method of authentication as well. Mojang has said that this authentication system should be used by everyone for custom logins, but credentials should never be collected from users. It, unlike previous versions, stores an access token instead of storing an encrypted form of the Mojang account email address and password.

== Trivia ==

*The name [[Wikipedia:Yggdrasil|Yggdrasil]] is a reference to the "World Tree" in old Nordic mythology.
