This page is a list of animation names for use with the [[Commands/playanimation|/playanimation]] command. These can be found in the vanilla resource pack folder under animations. The effect stacks column of the tables tells you whether running multiple of that same animation using multiple different animation controllers will cause the effect of that animation to multiply. Ex. if you run multiple <code>animation.ghast.scale</code> animation using multiple different animation controllers then the player will become larger and larger each time you add another one.

== Armor stand ==
Note: To make the animation the exact same as the armor stand version of the animation for the armor stand animations you have to use a molang query so that the animation does not fade out, Ex. instead of putting <code>a 9999</code> at the end of the /playanimation command just put <code>a 0 "aaaa == 1.0"</code> instead. (You will have to run another animation with the same animation controller to stop it though. )
