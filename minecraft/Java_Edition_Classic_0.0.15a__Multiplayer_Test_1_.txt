'''0.0.15a'''<ref>{{ytl|DeH5EI0TbsM}}</ref> (Multiplayer Test 1) is a version of [[Java Edition Classic]] released on May 31, 2009, at 19:04 UTC.<ref><samp>.jar</samp> file has a compilation time of 21:04 UTC+2.</ref><ref>[[#logs|IRC logs]]: "''[13:05] <@notch> http://www.minecraft.net/mptest/''" (19:05 UTC)</ref> It is the first version of ''Minecraft'' with multiplayer compatibility. This is the only multiplayer test currently archived.

==Additions==

===General===
;Multiplayer
*Added [[multiplayer]].
* Other players in multiplayer are rendered with the [[human]] mob model.<ref>{{ytl|r8SnlNiYmss}}</ref>
*Block particles don't appear in multiplayer.

==Changes==

===Blocks===
;[[File:Lava JE3.png|32px]] [[Lava]]
*Now flows faster than before.
*Model is no longer shaded.<ref group="note" name="gameplay">This has been verified by gameplay from this version's jar dated May 31, 2009 at 19:04 UTC.</ref>
* Liquids directly under a block no longer cause an x-ray effect.

===Mobs===
;[[Humans]]
*Human mob animation changed 
**The head and arms no longer flail around as much.<ref group="note" name="gameplay">This has been verified by gameplay from this version's jar dated May 31, 2009 at 19:04 UTC.</ref>

=== Textures===
; [[File:Oak Planks JE4.png|32px]] [[Planks]]
*Texture changed from [[File:Oak Planks JE3.png|32px]].
;[[File:Oak Leaves JE2.png|32px]] [[Leaves]] 
*Texture changed from [[File:Oak Leaves JE1.png|32px]].
;[[File:Oak Log Axis Y JE2 BE1.png|32px]] [[Log|Wood]]
*Texture changed from [[File:Oak Log Axis Y JE1.png|32px]].
;[[File:Gravel JE2.png|32px]] [[Gravel]]
* Texture changed from [[File:Gravel JE1.png|32px]].
*Now only generates underwater. 
;[[File:Sand JE2.png|32px]] [[Sand]]
* Texture changed from [[File:Sand JE1.png|32px]].
;General
*Removed redundant [[dirt]] and [[grass]] textures, and an unused texture of what seems to be a cloud from [[Java Edition 0.0.14a|0.0.14a]].

===Generated structures===
;[[File:Oak JE3.png|32px]] [[Tree]]s
*Trees have a new shape.
*Now look more like modern trees.

== Bugs ==

* Player can place blocks inside other players in multiplayer.
