'''v0.3.0 alpha''' was a major update to ''[[Pocket Edition|Minecraft: Pocket Edition]]'' that was released on April 24, 2012.<ref>https://web.archive.org/web/20120504163040/http://itunes.apple.com/us/app/id479516143?mt=8</ref><ref>http://web.archive.org/web/20120427014353/https://play.google.com/store/apps/details?id=com.mojang.minecraftpe</ref> It added notable features, such as [[crafting]], new [[mobs]], [[blocks]], [[items]], and [[tools]] as well as other changes and fixes.<ref>{{link|url=https://www.mojang.com/2012/04/minecraft-pocket-edition-now-with-crafting/|title=Minecraft - ''Pocket Edition'' Now with Crafting!|archive-url=http://web.archive.org/web/20191004200200/https://www.mojang.com/2012/04/minecraft-pocket-edition-now-with-crafting/|website=mojang.com|date=April 24, 2012}}</ref>

v0.3.0 alpha was reuploaded on April 24, 2012 to fix a crash upon launch, and reuploaded again later that day to add more inventory space and a smaller GUI. It also fixed an icon bug.

== Additions ==
=== Blocks ===
; [[Crafting table]]
* Allows the player to craft a larger variety of blocks and items.
* Can be crafted with [[wooden plank]]s.
; [[Brick slabs]]
* The half-height version of [[bricks]].
* Has a crafting recipe, but is not yet obtainable in Survival mode due to infinite stacks only counting as one of a material.
; [[Brick stairs]]
* The brick variant of stairs.
* Has a crafting recipe, but is not yet obtainable in Survival mode due to infinite stacks only counting as one of a material.

=== Items ===
; [[Dandelion yellow]]
* Used to craft [[yellow wool]].
* Can be crafted with [[dandelion]]s.
; [[Coal]]
* Obtained by mining [[coal ore]] with a [[pickaxe]].
* Can be used to craft [[torch]]es.
; [[Lapis lazuli]]
* Obtained by mining [[lapis lazuli ore]] with a [[stone pickaxe]].
* Can be used to craft [[blue wool]].
; Unobtainable
* [[Bone meal]]
* [[Cactus green]]
* [[Charcoal]]
** Can be used to craft [[torch]]es.
* [[Cocoa beans]]
* [[Cyan dye]]
* [[Gray dye]]
* [[Ink sac]]
* [[Light blue dye]]
* [[Light gray dye]]
* [[Lime dye]]
* [[Magenta dye]]
* [[Orange dye]]
* [[Pink dye]]
* [[Purple dye]]
* [[Rose red]]

=== Mobs ===
; [[Cow]]s
* A common passive [[mob]].
* Does not drop anything when it dies.
; [[Chicken]]s
* A common passive mob.
* Does not drop anything when it dies.

=== Gameplay ===
* New [[sounds|sound effects]]
* New [[inventory]]
; [[Crafting]]
* How the player makes blocks and items.
* Crafting menu can be accessed by either tapping the "Craft" button on the upper-left of the inventory, or by tapping on a crafting table.
* {{Version exclusive}}: uses the ''Minecraft'' Advanced Touch Technology Interface System (MATTIS) crafting system.
; [[Durability]]
* Most [[tool]]s, excluding [[shears]], now have a limited number of uses based on their [[tier]].
** Wooden tools have 11 uses, and stone tools have 132 uses.
** For most tools, breaking any block counts as 1 use.
*** For swords, this counts as 2 uses.
** Hitting a mob currently counts as 0 uses.

== Changes ==
=== Blocks ===
; [[Coal ore]]
* Now drops coal when mined with any [[pickaxe]].
; [[Iron ore]]
* Now drops itself when mined with a stone pickaxe.
; [[Lapis lazuli ore]]
* Now drops 4–9 lapis lazuli when mined with a stone pickaxe.
; [[Snow block]]s
* Can now be crafted with snowballs.
* Now drop snowballs when broken.
; [[Snow layer]]s
* Now drop snowballs when destroyed with a [[shovel]].
; [[Sugar cane]]
* Now drops its item form when broken.

=== Items ===
; [[Book]]s
* Are now used to craft [[bookshelves]].
* Can now be crafted with [[paper]].
; [[Bowl]]s
* Can now be crafted with [[wooden plank]]s.
; [[Paper]]
* Is now used to craft [[books]].
* Can now be crafted with [[sugar cane]].
; [[Snowball]]s
* Can now be used to craft [[snow block]]s.
; [[Stick]]s
* Are now used to craft wooden and stone [[tools]], [[ladder]]s, [[torch]]es, [[fence]]s, and [[fence gate]]s.
* Can now be crafted with wooden planks.
; [[Sugar]]
* Can now be crafted with [[sugar cane]].
; Wooden [[axe]]s, [[pickaxe]]s, [[shovel]]s, and [[sword]]s
* Can now be crafted with wooden planks and sticks.

=== Non-mob entities ===
; [[Camera]]s
* Are now obtainable via an inventory editor.

=== Gameplay ===
; [[Survival]]
* All items now need to be gathered, except [[shears]], [[bricks]], and [[glass]].
* The player no longer starts out with the following items in infinite stacks:
** [[Stone shovel]]
** [[Stone pickaxe]]
** [[Stone axe]]
** [[Stone sword]]
** [[Ladder]]
** [[Torch]]
** [[Wooden door]]
** [[Fence]]
** [[Fence gate]]
** [[Wooden plank]]s
** [[Wooden stairs]]
** [[Cobblestone stairs]]
** [[Stone slab]]
** 13 of the 16 colored [[wool]] blocks (excluding white, magenta, and orange)
** [[Leaves]]
** [[Bookshelves]]
; [[Creative inventory]] 
* Additions:
** [[Brick stairs]]
** [[Wooden slab]]
** [[Brick slab]]
** [[Orange wool]]
** [[Magenta wool]]
** [[Crafting table]]
