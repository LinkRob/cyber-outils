These [[commands]] manage [[server]] saves.

== save-all ==
{{Exclusive|Java|section=1}}
{{Infobox command
|name=save-all
|oplevel=4
|serveronly=y
|nocmdblock=y
}}

Saves the server to the data storage device.
Causes the server to mark all [[chunks]] and player data as needing to be saved. They are saved over time until all are flushed to the data storage device.

===Syntax===

<code>save-all</code>
: Normal mode.
<code>save-all flush</code>
: All the chunks are saved to the data storage device immediately, freezing the server for a short time.

== save ==
{{Exclusive|bedrock|section=1}}
{{Infobox command
|name=save
|oplevel=4
|serveronly=y
|nocmdblock=y
|cheat=y
}}

Prepares a backup, queries its status, or resumes.

===Syntax===

: <code>save <hold|query|resume></code>

===Result===

When the backup is ready, save query outputs the path of every file and the amount of bytes to truncate it separated by a colon.
