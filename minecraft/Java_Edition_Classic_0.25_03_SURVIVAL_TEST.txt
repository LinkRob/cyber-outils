'''0.25_03 SURVIVAL TEST''', an implicit retroactive renaming of the third reupload of [[0.25 SURVIVAL TEST]],<ref name="didn't bump">[[#logs|IRC logs]]: "''A11:58:33 <08Notch> i didn't bump the number :-O''" [...] "''A11:58:56 <Quatroking> Notch: but we do have a new version?''" [...] "''A11:59:11 <08Notch> yes, Quatroking ''" (16:58 to 16:59 UTC)</ref> so therefore labeled '''0.25 SURVIVAL TEST''' in-game,<ref>{{ytl|6NHN214GruY|Minecraft survival update, attacked by skeletons|citricsquid|September 3, 2009, 17:21:06 UTC}} | As cited in [[#logs|IRC logs]]: "''P12:02:24 <citricsquid> got a video :D''" (17:02:24 UTC)</ref> was a version of [[Survival Test]] released on September 3, 2009, at 16:57 UTC.<ref name="release">[[#logs|IRC logs]]: "''A11:57:05 <08Notch> level loading will work any second now''", "''A11:57:08 <08Notch> just uploaded a new index.jsp''" [...] "''A11:58:06 <08Notch> loading via url works now, yay''", "''A11:58:10 <08Notch> and arrows stay around much longer''" (16:58 UTC)</ref> This version is not available in the [[launcher]].

== Changes ==

===Entities===
;[[Arrow]]s
*Now stay around longer before despawning.<ref name="release" />

=== General ===
;General
*Loading a world via the URL now works.<ref name="release" />
;[[Controls]]
*[[Player]]s can no longer right-click to deal [[damage]].<ref>[[#logs|IRC logs]]: "''A11:51:55 <ZomBuster> Ill ask this again, can you stop mobs getting hurt from right-clicking?''" (16:51:55 UTC)</ref>{{verify|Although no direct proof from Notch exists, mobs cannot be hit by right clicking in 0.25_05, but they can in 0.24_03.|edition=java|type=change}}

==Trivia==
*0.25_04 SURVIVAL TEST does not exist. Each patch version of [[0.25 SURVIVAL TEST]] did not change the version number,<ref name="didn't bump" /> leading to one user mistakenly changing the wiki version<ref>[[#logs|IRC logs]]: "''A11:59:24 <Quatroking> then how should I put it on the wiki''" [...] "''A11:59:32 <Quatroking> Survival_test_4?''" [...] "''P12:00:34 <Quatroking> I'm changing it to 0.24_SURVIVAL_TEST_4, okay?''" (16:59–17:00 UTC)</ref> from "[[0.24_SURVIVAL_TEST_03]]" to "0.24_SURVIVAL_TEST_04",<ref>[[Special:Diff/2558|Wiki diff #2558]] – September 3, 2009, 17:00 UTC</ref> a version that does not exist, upon the release of this version. Notch saw this and thought that this user was telling him that the unlabelled patches for 0.25 should have labels and that the current version should be "_04", so Notch made the next version "[[0.25_05 SURVIVAL TEST]]",<ref>[[#logs|IRC logs]]: "''P12:11:04 <08Notch> 0.25_05 is up with a bug fix (monsters chasing dead monsters), and a small bonus. :D''" (17:11 UTC)</ref> even though it is only four versions after 0.25.
