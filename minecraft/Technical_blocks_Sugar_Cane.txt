{{History|java alpha}}
{{History||v1.0.11|Sugar cane has an extra, unobtainable item form corresponding to its block ID. It can be obtained via inventory editors with numeric item ID 83.}}
{{History|java beta}}
{{History||1.6|snap=Test Build 3|Sugar cane items can be obtained from the newly added debug chests, mainly from the 25th slot of the 3rd chest from the left, and the 9th slot of the 7th chest from the left.}}
{{History|||snap=release|Debug chests no longer spawn, preventing sugar cane items from being obtained this way.}}
{{History||1.8|snap=Pre-release|The block form of sugar cane is available in the Creative inventory, alongside its usually-obtainable item form.}}
{{History|||snap=Pre-release 2 ;)|Added pick block functionality. This will change the currently selected slot to any containing this otherwise-unobtainable sugar cane item, but will not allow it to be obtained if not already in the hotbar.}}
{{History|java}}
{{History||?|The direct block form of sugar cane is no longer available in the Creative inventory.}}
{{History||1.2.5|snap=pre|Pick Block now returns the actually obtainable sugar cane item.}}
{{History||1.3.1|snap=12w15a|Sugar cane items can now be obtained via Pick Block in creative.}}
{{History|||snap=12w16a|Pick Block once again returns the actually obtainable sugar cane item.
Sugar cane items can now be obtained in singleplayer worlds via the {{cmd|give}} command using the respective numeric ID.}}
{{History||1.7.2|snap=13w37a|The direct item form of sugar cane has been removed from the game. It can no longer exist as an item in any way, only as a placed block.}}
{{History|pocket alpha}}
{{History||Pre-release|Sugar cane exists as an item.
|The sugar cane block item is currently available in the Creative inventory.}}
{{History||v0.2.1|Survival players now start out with an infinite stack of the sugar cane block item in their inventory.}}
{{History||v0.3.0|Survival players no longer start out with an infinite stack of the sugar cane block item in their inventory.}}
{{History||v0.5.0|The sugar cane block item is given by the [[Nether reactor]].}}
{{History||v0.6.0|The correct sugar cane item is now given by the nether reactor and the creative inventory, making the block item no longer obtainable without inventory editing.<ref>{{bug|MCPE-883||Wrong sugarcane drop from the reactor and creative mode|Fixed}}</ref>}}
