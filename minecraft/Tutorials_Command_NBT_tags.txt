NBT tags can be specified for items and entities created with the {{cmd|give}} and {{cmd|summon}} commands. Each tag has the format <code><tagname>:<value></code> where <code><tagname></code> describes what it does, and <code><value></code> is what it applies. Multiple tags are separated by commas. (e.g. <code>{CustomName:'"Bob"', Invisible:true</code>). The contents of List tags are enclosed in square brackets <code>[]</code>, while the contents of Compound tags are enclosed in curly brackets <code>{}</code> – note that the entire data tag is itself a Compound tag (All within a set of <code>{}</code>). Tag names are case-sensitive, and white space is ignored. Additionally, some tags which are either true or false are stored as Byte tags (Example: <code>{NoAI:1b}</code>)

The player can quickly find data tags (NBT) without the use of external editors by using {{cmd|data}} to figure out the data for each entity or block entity. See more about this in the article [[Commands/data]].

See [[Chunk format#Entity format|Entity format]] for the various NBT Tags that are saved for each entity. This page also contains basic information for each NBT Tag.

When None is used in a tag name that means that this tag can be put directly into the start of the dataTag.

== Items ==
These can be used in {{cmd|give}} and {{cmd|item}} commands as well as {{cmd|clear}}. For commands such as {{cmd|summon}} and {{cmd|setblock}}, place them inside of a tag.

Example:

<code><nowiki>{id:"minecraft:stone",Count:3b, ..., tag:{Name:'{"text":"Name Here"}', ...}}</nowiki></code>

These tags can be used on any item.

Adding 128 hides "Upgrade" on armors

=== Spawner ===
These tags are used when using {{cmd|setblock}} or {{cmd|summon}} (spawner minecarts) to create spawners. Add only those data tags you want to avoid a potential error.
{| class="wikitable" style="width:100%" data-description="Monster spawner tags"
|-
! width="15%" align="center" | Tagname
! width="50%" align="center" | Description
! width="20%" align="center" | Value Type
! width="15%" align="center" | Syntax
|-
| EntityId
| Specifies what entity the spawner spawns.
| A ID of a Mob
| {SpawnData:{entity: {id: "minecraft:EntityName"}}
|-
| SpawnData
| Used for spawners that spawn entities with data tags.
| An entity NBT tag
| {SpawnData:{NBT tag}}
|- 
| SpawnCount
| How many entities the spawner can spawn at one time.
| Integer
| {SpawnCount:#}
|-
| SpawnRange
| The range of which the entities can spawn.
| Integer
| {SpawnRange:#}
|-
| RequiredPlayerRange
| The range of which a player must be in for the spawner to start spawning entities.
| Integer
| {RequiredPlayerRange:#}
|-
| Delay
| The number of ticks before entities spawn when a player is first detected.
| Integer
| {Delay:#}
|-
| MinSpawnDelay
| After the first spawn, this is the minimum amount of ticks before more entities can spawn.
| Integer
| {MinSpawnDelay:#}
|-
| MaxSpawnDelay
| Similar to MinSpawnDelay. After the first spawn, this is the maximum amount of ticks before more entities can spawn.
| Integer
| {MaxSpawnDelay:#}
|-
| MaxNearbyEntities
| Checks the number of entities within the spawn range ('SpawnRange' tag). If the number of entities it detects is over the set MaxNearbyEntities number, it does not spawn more entities unless the amount of entities within the spawn range is decreased.
| Integer
| {MaxNearbyEntities:#}
|-
| SpawnPotentials
| Used when creating spawners that spawn multiple types of entities. A weighted list of entities to be spawned, including NBT tags.
| A List
| SpawnPotentials:[{data: {entity: {id: "minecraft:EntityName"} }, weight:#}]
|-
| Weight
| Used if spawning multiple entities using SpawnPotentials. If the same as another SpawnPotentials entity, both have an even chance of spawning.
| A number
| {Weight:#}
|-
|}
Sub-tags used in the SpawnPotentials data tag.
{| class="wikitable" style="width:100%" data-description="Spawnpotentials tags"
|-
! width="15%" align="center" | Tagname
! width="50%" align="center" | Description
! width="15%" align="center" | Value Type
! width="20%" align="center" | Syntax
|-
| Type
| Determines the other entity that spawns with the entity specified in the EntityId data tag. MUST be used with SpawnPotentials.
| A string
| {SpawnPotentials:[{Type:"EntityName"}]}
|-
| Weight
| Determines the chance of spawning the entity specified in the 'Type' sub-tag. If set to the same as another other entity's weight, they have the same chance of spawning.
| A number
| {SpawnPotentials:[{Weight:#}]}
|-
| Properties
| Determines the entity data tag(s) that the entity (specified in the 'Type' sub-tag) is spawned with.
| An entity NBT tag
| {SpawnPotentials:[{Properties:{NBT tag}}]}
|-
|}
