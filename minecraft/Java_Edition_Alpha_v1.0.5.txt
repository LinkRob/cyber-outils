'''Alpha v1.0.5'''<ref>{{ytl|Yl-O-hUXnMY|Minecraft 2 - Crafting a Workbench|ParaWork|July 15, 2010}}</ref><ref>{{ytl|MJBtjxhsCH4|Minecraft: Snowballs!|Gnomonymous|July 13, 2010}}</ref><ref>{{ytl|QQiqCQg3g0M|Fastest way to get Snowballs|beastateverythin|July 13, 2010}}</ref> is a version that mainly added [[snowball]]s and [[snow]] blocks as well as fixing some bugs.

== Additions ==
=== Blocks ===
; [[File:Snow Block JE1 BE1.png|32px]] [[Snow Block]]
* Drops 6 snowballs when destroyed.
*Crafted from 9 snowballs at the time.

=== Items ===
; [[File:Snowball_JE1_BE1.png|32px]] [[Snowball]]s
* Can be thrown but deal no damage.
*Can be stacked to 64 in the inventory.

== Changes ==
=== Blocks ===
; [[File:Oak Wall Sign (N) JE1 BE1.png|32px]] [[Sign]]s
* No longer requires a free block above it when placed.

; [[File:Ice JE1 BE1.png|32px]] [[Ice]]
* Increased hardness from 0.1 to 0.5.

; [[File:Snow (layers 1) JE1 BE1.png|32px]] [[Snow]]
* Drops snowballs when broken by any means other than replacing with another block.

=== General ===
; [[Crash]]es
* Game no longer saves on crashes.
; [[Third-person view]]
* Third person view no longer causes water particles to surround the player.

== Bugs ==
* Entity shadows are glitched.

== Fixes ==
;3 bugs fixed
* Fixed building on snow bug.
* Fixed [[ice]] rendering bug.
* The sound of walking in the snow now plays correctly.

== Reupload ==
Alpha v1.0.5 was reuploaded a few minutes after release to fix a bug.
; [[Snow]]
* No longer goes through [[glass]].
