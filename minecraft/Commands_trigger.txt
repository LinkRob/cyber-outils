Changes the executor player's score in a [[scoreboard]] objective with a "trigger" criterion, and un-enabled the objective for this player. Allows non-operator players to modify their own scoreboard objectives under tightly controlled conditions. Often used to let players activate systems controlled by [[Data pack|data packs]] or [[Command Block|command blocks]].

==Syntax==

<code>trigger <objective></code>
: Adds <code>1</code> to the current value of <code><objective></code>.
<code>trigger <objective> add <value></code>
: Adds <code><value></code> to the current value of <code><objective></code>.
<code>trigger <objective> set <value></code>
: Sets the value of <code><objective></code> to <code><value></code>.

==Arguments==

{{argument|objective|objective}}
: An enabled scoreboard objective with the "trigger" criterion.
: {{arg desc|je=objective}}

{{argument|value|integer}}
: Specifies the value to be set to or added to the objective.
: {{arg desc|je=integer}}
