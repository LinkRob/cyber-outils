'''0.2.5''' is a server version of [[Java Edition Alpha]] released with client version [[Alpha v1.2.3|v1.2.3]] on November 23, 2010.

== Additions ==
* New server configuration settings
** <code>pvp <true/false></code> (<code>true</code> by default). If this is set to <code>false</code>, [[player]]s cannot directly attack other players (i.e. by hitting them or shooting them with a [[bow]]; things like [[lava]] will still damage them).
** <code>spawn-monsters <true/false></code> (<code>true</code> by default). If this is set to <code>false</code>, all hostile mobs will be removed and they cannot [[spawn]].
** <code>spawn-animals <true/false></code> (<code>true</code> by default). If this is set to <code>false</code>, all passive mobs will be removed and they cannot spawn.

== Changes ==
* Players and mobs on [[fire]] in [[multiplayer]] now visibly on fire.
* Damage is now correctly given for falling, drowning, and burning.
* Eating [[food]] restores [[health]].
* Players can now respawn.

== Fixes ==
* Fixed a block respawning bug in multiplayer.
