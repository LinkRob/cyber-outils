This version is the last version of [[Minecraft Infdev]]. This version was released on '''June 30, 2010'''.<ref>[[wordofnotch:754041531|I fixed a few bugs in /game/, and the game is now playable offline]] – The Word of Notch, June 30, 2010</ref> This is the first of two versions released on this date, as the latter was later retconned to be ''[[Java Edition Alpha v1.0.0|Alpha v1.0.0]]''.

== Fixes ==
* Fixed a bug where [[Void|falling out of the world]] does not kill the [[player]].
* [[Signs]] work the way they used to.
* A few other minor bug fixes.{{More info needed|nocat=what exactly?}}
