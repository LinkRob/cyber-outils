{{exclusive|java}}
[[Biome]]s stored as [[JSON]] files within a [[data pack]] in the path {{cd|data/<namespace>/worldgen/biome}}.

== JSON format ==

<div class="treeview">
* {{nbt|compound}}: The root object.
**{{nbt|boolean|has_precipitation}}: Determines whether or not the biome has precipitation.
**{{nbt|float|temperature}}: Controls gameplay features like grass and foliage color, and a height adjusted temperature (which controls whether raining or snowing if {{nbt|boolean|has_precipitation}} is <code>true</code>, and generation details of some features).
** {{nbt|string|temperature_modifier}}: (optional, defaults to none) Either <code>none</code> or <code>frozen</code>. Modifies temperature before calculating the height adjusted temperature. If <code>frozen</code>, makes some places' temperature high enough to rain (0.2).
** {{nbt|float|downfall}}: Controls grass and foliage color.
** {{nbt|compound|effects}}: Ambient effects in this biome.
*** {{nbt|int|fog_color}}: Decimal value converted from Hex color to use for fog.
*** {{nbt|int|sky_color}}: Decimal value converted from Hex color to use for the sky.
*** {{nbt|int|water_color}}: Decimal value converted from Hex color to use for water blocks and cauldrons.
*** {{nbt|int|water_fog_color}}: Decimal value converted from Hex color to use for fog.
*** {{nbt|int|foliage_color}}: (optional) Decimal value converted from Hex color to use for tree leaves and vines. If not present, the value depends on downfall and the temperature.
*** {{nbt|int|grass_color}}: (optional) Decimal value converted from Hex color to use for grass blocks, grass, tall grass, ferns, tall ferns, and sugar cane. If not present, the value depends on downfall and temperature.
*** {{nbt|string|grass_color_modifier}}: (optional, defaults to none) Can be <code>none</code>, <code>dark_forest</code> or <code>swamp</code>.
*** {{nbt|compound|particle}}: (optional) The [[particle]] to use throughout this biome.
**** {{nbt|float|probability}}: Controls how often the particle spawns. Value higher than 1 is regarded as 1, lower than 0 is regarded as 0.
**** {{nbt|compound|options}}: Controls what particle to use. See also [[Commands/particle]].
***** {{nbt|string|type}}: The namespaced id of the particle type.
*****; If <code>type</code> is <code>block</code>, <code>block_marker</code> or <code>falling_dust</code>, additional field are as follows<nowiki>:</nowiki>
***** {{nbt|compound|value}}: Contains the block state used for the particle.
****** {{nbt inherit/block_state}}
*****; If <code>type</code> is <code>item</code>, additional fields are as follows<nowiki>:</nowiki>
***** {{nbt|compound|value}}: Contains the item data used for the particle.
****** {{nbt|string|id}}: Namespaced id of the item to use.
****** {{nbt|int|Count}}: The amount of the item.
****** {{nbt|compound|tag}}: NBT data present on the item in JSON format. See [[NBT format#JSON and NBT]].
*****; If <code>type</code> is <code>dust</code>, additional fields are as follows<nowiki>:</nowiki>
***** {{nbt|list|color}}: Three floats representing the red, green, and blue components of the dust color, each from 0 to 1.
***** {{nbt|float|scale}}: Controls the size of the dust particles.
*****; If <code>type</code> is <code>dust_color_transition</code>, additional fields are as follows<nowiki>:</nowiki>
***** {{nbt|list|fromColor}}: Three floats representing the red, green, and blue components of the start color, each from 0 to 1.
***** {{nbt|list|toColor}}: Three floats representing the red, green, and blue components of the end color, each from 0 to 1.
***** {{nbt|float|scale}}: Controls the size of the particles.
*****; If <code>type</code> is <code>sculk_charge</code>, additional field is as follows<nowiki>:</nowiki>
***** {{nbt|float|roll}}: The angle the particle displays at in radians.
*****; If <code>type</code> is <code>vibration</code>, additional fields are as follows<nowiki>:</nowiki>
***** {{nbt|compound|destination}}: The destination.
****** {{nbt inherit/position source}}
***** {{nbt|int|arrival_in_ticks}}: The duration of the move.
*****; If <code>type</code> is <code>shriek</code>, additional field is as follows<nowiki>:</nowiki>
***** {{nbt|int|delay}}: The delay in ticks.
*** {{nbt|string}}{{nbt|compound|ambient_sound}}: (optional) A namespace ID of the sound event to use for ambient sound. Can also be an object to specify a fixed audible range of the sound.
**** {{nbt|string|sound_id}}: A namespace ID of the sound event to use.
**** {{nbt|float|range}}: (optional) The fixed audible range of the sound.
*** {{nbt|compound|mood_sound}}: (optional) Settings for [[mood]] sound.
**** {{nbt|string}}{{nbt|compound|sound}}: A namespace ID of the sound event to use. Can also be an object to specify a fixed range of the sound.
***** {{nbt|string|sound_id}}: A namespace ID of the sound event to use.
***** {{nbt|float|range}}: (optional) The fixed audible range of the sound.
**** {{nbt|int|tick_delay}}: The mininum delay between two plays. See also [[Ambience#Mood_algorithm]].
**** {{nbt|int|block_search_extent}}: Determines the cubic range of possible positions to find place to play the mood sound. The player is at the center of the cubic range, and the edge length is {{cd|2 * block_search_extent}}.
**** {{nbt|double|offset}}: The higher the value makes the sound source further away from the player.
*** {{nbt|compound|additions_sound}}: (optional) Settings for additions sound.
**** {{nbt|string}}{{nbt|compound|sound}}: A namespace ID of the sound event to use. Can also be an object to specify a fixed range of the sound.
***** {{nbt|string|sound_id}}: A namespace ID of the sound event to use.
***** {{nbt|float|range}}: (optional) The fixed audible range of the sound.
**** {{nbt|double|tick_chance}}: The propability to start playing the sound per tick. Value higher than 1 is regarded as 1, lower than 0 is regarded as 0.
*** {{nbt|compound|music}}: (optional) Specific music that should be played in the biome.
**** {{nbt|string}}{{nbt|compound|sound}}: A namespace ID of the sound event to use. Can also be an object to specify a fixed range of the sound.
***** {{nbt|string|sound_id}}: A namespace ID of the sound event to use.
***** {{nbt|float|range}}: (optional) The fixed audible range of the sound.
**** {{nbt|int|min_delay}}: The min delay between two music.
**** {{nbt|int|max_delay}}: The max delay between two music.
**** {{nbt|boolean|replace_current_music}}: Whether or not to replace music which is already playing.
** {{nbt|compound|carvers}}: The carvers to use.
*** {{Nbt|string}}{{nbt|compound}}{{nbt|list|air}}: (Optional, can be empty) List of carvers used during the <code>air</code> cave generation step. Can be an id of a configured carver, a tag of configured carvers, or a configured carver object, or a list of configured carver IDs, or a list of configured carver objects.
*** {{Nbt|string}}{{nbt|compound}}{{nbt|list|liquid}}: (Optional, can be empty) List of carvers used during the <code>liquid</code> cave generation step. Currently doesn't work. Can be an id of a configured carver, a tag of configured carvers, or a configured carver object, or a list of configured carver IDs, or a list of configured carver objects.
** {{nbt|list|features}}: (Can be empty) A list of 11 elements. Each element can be a tag of placed feature, a list of placed feature IDs, or a list of placed feature objects. The features are applied to each chunk in order in each step. The same placed features in the same step in two biomes cannot be in different orders. In each step, all feature IDs need to be ordered consistently across biomes. For example, in UNDERGROUND_ORES step of minecraft:plains, ore_dirt is before ore_gravel, so in other biomes' UNDERGROUND_ORES step, if there are ore_dirt and ore_gravel, ore_gravel cannot be after ore_dirt. The generation steps are also used in [[custom structure|stucture features]].
*** {{nbt|string}}{{nbt|list}}: Generation step <code>RAW_GENERATION</code>. Used by small end island features in vanilla.
*** {{nbt|string}}{{nbt|list}}: Generation step <code>LAKES</code>. Used by lava lakes in vanilla.
*** {{nbt|string}}{{nbt|list}}: Generation step <code>LOCAL_MODIFICATIONS</code>. Used for amethyst geodes and icebergs in vanilla.
*** {{nbt|string}}{{nbt|list}}: Generation step <code>UNDERGROUND_STRUCTURES</code>. Used for dungeons and overworld fossils in vanilla.
*** {{nbt|string}}{{nbt|list}}: Generation step <code>SURFACE_STRUCTURES</code>. Used for desert wells and blue ice patches in vanilla.
*** {{nbt|string}}{{nbt|list}}: Generation step <code>STRONGHOLDS</code>. Not used for features in vanilla.
*** {{nbt|string}}{{nbt|list}}: Generation step <code>UNDERGROUND_ORES</code>. Used for overworld ore blobs, overworld dirt/gravel/stone variant blobs, and sand/gravel/clay disks in vanilla.
*** {{nbt|string}}{{nbt|list}}: Generation step <code>UNDERGROUND_DECORATION</code>. Used for infested block blobs, nether gravel and blackstone blobs, and all nether ore blobs in vanilla.
*** {{nbt|string}}{{nbt|list}}: Generation step <code>FLUID_SPRINGS</code>. Used for water and lava springs in vanilla.
*** {{nbt|string}}{{nbt|list}}: Generation step <code>VEGETAL_DECORATION</code>. Used for trees, bamboo, cacti, kelp, and other ground and ocean vegetation in vanilla.
*** {{nbt|string}}{{nbt|list}}: Generation step <code>TOP_LAYER_MODIFICATION</code>. Used for surface freezing in vanilla.
** {{nbt|float|creature_spawn_probability}}: (optional) Higher value results in more creatures spawned in world generation. Must be between 0.0 and 0.9999999 (both inclusive).
** {{nbt|compound|spawners}}: (Required, but can be empty. If this object doesn't contain a certain category, mobs in this category will not be spawned) Entity spawning settings.
*** {{nbt|list|<mob category>}}: (Can be empty. If empty, mobs in this category will not be spawned) The key must be one of <code>monster</code>, <code>creature</code>, <code>ambient</code>, <code>water_creature</code>, <code>underground_water_creature</code>, <code>water_ambient</code>, <code>misc</code>, or <code>axolotls</code>. A list of spawner data objects, one for each mob which should spawn in this biome.
**** {{nbt|compound}}: The spawner data for a single mob.
***** {{nbt|string|type}}: The namespaced entity id of the mob.
***** {{nbt|int|weight}}: How often this mob should spawn, higher values produce more spawns.
***** {{nbt|int|minCount}}: The minimum count of mobs to spawn in a pack. Must be greater than 0.
***** {{nbt|int|maxCount}}: The maximum count of mobs to spawn in a pack. Must be greater than 0. And must be not less than {{nbt|int|minCount}}.
** {{nbt|compound|spawn_costs}}: (Required, but can be empty. Only mobs listed here use the spawn cost mechanism) See [[Spawn#Spawn costs]] for details.
*** {{nbt|compound|<entity id>}}: The namespaced entity id of the mob.
**** {{nbt|double|energy_budget}}: New mob's maximum potential.
**** {{nbt|double|charge}}: New mob's charge.
</div>
