'''Blue Husky's Minecraft Inventory''' ('''BHMI''') is a program written by Blue Husky Programming that stores and displays an inventory of all blocks and items in Minecraft, their data values, and suggested trading-post values. The table can be sorted just like Windows Explorer sorts files and can be searched with an internal window that pops up upon selection or pressing Ctrl+F. There is also a Value Calculator that comes up upon selection or pressing Ctrl+Q, which helps you work out how much one item is worth, as compared to another.
