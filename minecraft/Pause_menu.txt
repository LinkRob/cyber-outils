The '''pause menu''' is one of ''Minecraft''<nowiki>'</nowiki>s multiple [[menu screen]]s. Activated during gameplay, it provides a portal to configure game options, quit out of a world, and more.

This menu can be accessed anytime (when not in a [[GUI]]) by pausing the game with the {{Key|Esc}} key by default.

== Features ==
=== Pausing the game ===
When a player enters the pause menu, the game completely freezes until the player returns back to game. In [[Bedrock Edition]], it only works on singleplayer mode worlds.
