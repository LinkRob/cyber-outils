This template is used to have a consistent table format across the [[Programs and editors]] subpages. It expects to be used within the [[Programs and editors/header]] template. Note that the "<code>:Programs and editors</code>" prefix is necessary, as this template is not a subpage of the pages it is used on.
=== Usage ===
<pre style="width: 520px">

{{:Programs and editors/entry

| author = Author
| image = Example.png
| platform = {{OS|win|linux|mac}}
| programming language = C++

}}
}}</pre>
