{{info needed section|Test placed metadata and replacement capabilities}}
{{History|java}}
{{History||1.3.1|snap=12w19a|Cocoa has an extra, unobtainable item form corresponding to its block ID, which uses the fully grown texture. It can be obtained via the {{cmd|give}} command or inventory editors with numeric item ID 127.
|The item is obtainable in this snapshot via [[pick block]] in Creative mode.<ref>https://youtu.be/j1xK2SWpddw?t=3m45s</ref>
|The cocoa item can be placed anywhere, and result in suspended cocoa.<ref>https://youtu.be/j1xK2SWpddw?t=4m</ref>
|Unlike cocoa beans at the time, cocoa has a placement sound (that of wood).}}
{{History|||snap=12w21a|Pick Block used on cocoa now returns cocoa beans.}}
{{History||1.8|snap=14w25a|The direct item form of cocoa has been removed from the game. It can no longer exist as an item in any way, only as a placed block.}}
{{History|pocket alpha}}
{{History||v0.9.0|Cocoa exists as an item.}}
{{History||?|Attempting to place a cocoa item in an invalid space does not consume the cocoa, even in survival; however, cocoa beans are dropped at that location.<ref>https://youtu.be/2UUX5gJdf2A?t=9m24s</ref> It renders for a frame if placed on a non-jungle log, and is consumed if replacing an existing replaceable block such as grass.}}
{{History|foot}}
