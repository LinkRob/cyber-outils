Places a [[feature]] at the specified location where meet the placement requirements.

==Syntax==
:<code>/placefeature <feature> [<pos>]</code>{{only|java}}
:<code>/placefeature <featureName: Features> [position: x y z]</code>{{only|bedrock}}
:<code>/placefeature <featureRule: featureRules> [position: x y z]</code>{{only|bedrock}}

==Arguments==
{{el|je|short=1}}: {{argument|feature|resource}}<br>
{{el|be|short=1}}: {{argument|featureName: Features|enum}} or {{argument|featureRule: featureRules|enum}}
:{{IN|java}}, specifies the [[Custom feature|configured feature]] to place. Must be a [[resource location]].
:{{IN|bedrock}}, specifies the feature to place. Must be an namespaced ID of a feature rule or feature. If both a feature rule with the specified ID and a feature with the ID exist, the feature rule will be placed.
:See [[feature]] for IDs of vanilla features.

{{argument|pos|block_pos|position|CommandPosition}}
:Specifies the position of the origin for the feature to be placed.
:{{arg desc|je=block_pos|be=CommandPosition}}

{{Result table}}
