'''1.18.42''' is a minor update to {{el|ee}} released on October 25, 2022, which fixes bugs.<ref>{{cite|url=https://web.archive.org/web/20221026102639/https://educommunity.minecraft.net/hc/en-us/articles/4484636118420|title=What's New in the Mobile, Multiplayer, & More update (version 1.18.42)|website=Minecraft: Education Edition Support}}</ref>

== Changes ==
=== General ===
; [[Multiplayer]]
* Improved proxy support for multiplayer services.
* Greater connection reliability in multiplayer sessions.

; Library
* Searching content across the entire in-game Library is easier than ever with the new Library Search Bar.

; Coding
* Coding window now defaults to full screen on mobile devices.

== Fixes ==
* Various bug fixes in addition to performance and stability improvements.
