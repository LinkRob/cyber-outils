A '''resin brick''' is an item added in [[The Garden Awakens]] game drop. It is made by smelting [[Resin Clump|resin clump]]s and used for crafting [[Resin Bricks|resin bricks (block)]] and as a [[smithing]] material. 

== Obtaining ==
===[[Smelting]]===
Resin bricks can be obtained by smelting [[Resin Clump|resin clump]]s

{{Smelting
|showname=1
|Resin Clump
|Resin Brick
|0.01
}}

== Usage ==
=== Crafting ===
Resin bricks can be used to craft [[Resin Bricks|resin bricks (block)]].

=== Smithing ===
Resin bricks can be used as an armor trim material via a [[Smithing Table]].

{{Smithing

== Appearance ==
Like all resin blocks and items, resin bricks appear bright, contrasting orange, similar to [[lava]]. They also appear more shiny and slightly crystalized.
