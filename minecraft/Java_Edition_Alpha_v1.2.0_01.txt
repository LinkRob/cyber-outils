'''Alpha v1.2.0_01''' is a version of [[Alpha]] that was released on October 30, 2010, at 21:47 UTC.<ref group=note> .jar file has a compilation time of 23:47 UTC+2.</ref>

== Changes ==
=== Blocks ===
; [[Gravel]]
* Now spawns in the [[Nether]], replacing the location of some [[Soul Sand]].

; [[Furnace]]
* Can now place towards the player.

=== Gameplay ===
; [[Armor]]
* No longer blocks damage.

== Bugs ==
* [[Player]] damage sound is very loud.

== Fixes ==
; 3 bugs fixed
* Fixed an inventory crash.<ref>[[#logs|IRC logs]]: "''<Notch> I've updated the client with a fix for the inventory crash as well''", "''<Notch> at least for ONE of them''" (21:54 UTC)</ref>
* The game sometimes no longer crashes when the player creates a new world.
* [[Furnace|Furnaces]] can now place towards the player.
