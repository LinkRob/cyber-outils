'''com.mojang''' is the folder used internally by ''Minecraft'' Bedrock Edition. It contains worlds, [[JSON]] data, and other files necessary for the game to run.

== Location ==

Below is a table showing the default directory for {{mono|com.mojang}}.<ref name=":0" />

On Xbox One, the files are stored locally.{{info needed}} They are also stored online if signed in to Xbox Live.<ref name=":0">{{cite|url=https://help.minecraft.net/hc/en-us/articles/4409165790605-Managing-Data-and-Game-Storage-in-Minecraft-|title=Managing Data and Game Storage in Minecraft|website=help.minecraft.net}}</ref>

=== Add-ons ===

Each world, and the {{mono|com.mojang}} folder itself, has a resource_packs folder. This contains resource packs with the following structure:
<div class="toccolours treeview">

** pack_icon.png
** shaders
*** glsl
**** renderchunk.dat
*** hlsl
**** renderchunk.fragment.dat
**text
***<language>.lang
***languages.json
</div>

Behavior packs can contain anything that a resource pack contains, plus additional files:{{verify}}

*** entities

</div>
