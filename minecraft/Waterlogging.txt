'''Waterlogging''' is the mechanic that allows non-cube [[blocks]] (that is, blocks that do not completely fill their block volume, such as doors, ladders, and plants) to be filled with a water source block. Both the non-cube block and the water source block occupy the same space. If the non-cube block is destroyed, the water source block remains.

{{IN|be}}, generally all non-cube blocks can be waterlogged and none can be used to displace water source blocks, although they can still displace flowing water.

== Mechanism ==
{{IN|java}}, certain blocks have a {{cd|waterlogged}} block state that can be {{cd|true|d=or|false}}. This is a temporary solution; a [[Java Edition mentioned features#Full split of liquids from blocks|full separation]] of blocks and fluids is planned.<ref>{{reddit|a11ig3/umm_wasnt_the_new_update_supposed_to_make_water|eamrmid|We are still working on this, though, and hope to have similar functionality one day.|Dinnerbone|November 28, 2018|context=4}}</ref>

{{IN|java}}, when the waterlogging block that can be pushed by the [[piston]] fails to be recovered within 2 [[tick]]s, the waterlogging state of the block is eliminated. Otherwise, the block can retain the waterlogging state. This feature can be used in the circuit of a "piston worm" as an alternative solution since [[dispenser|dispensers]] cannot be pushed by pistons {{in|java}}.

{{IN|bedrock}}, waterlogging is handled by the game's layers system. Through editing, any block can be waterlogged, as well as other features such as placing multiple slabs into a single block. In normal gameplay, a player cannot displace water source blocks using doors or other non-cube blocks to create breathing spaces underwater, like one can do in ''Java Edition''. Only flowing water can be displaced in ''Bedrock Edition''.

All waterlogged blocks share most properties as water source blocks, and as such, are non-flammable and explosion-proof even if said waterlogged block is flammable. Waterlogged Blocks are immune to freezing, and can interact with [[Lava]] to [[Fluid#Mixing|produce]] [[Cobblestone]] or [[Obsidian]], since Lava cannot convert waterlogged blocks to [[stone]].
