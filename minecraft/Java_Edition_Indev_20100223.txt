A version of '''[[Minecraft Indev]]''' was released on '''February 23, 2010''', and the final version of Minecraft named [[Indev]].<ref>[[wordofnotch:407142251|Indev update, on to infinite!]] – The Word of Notch, February 23, 2010</ref><ref>https://www.youtube.com/watch?v=H5_G6O5JWn0</ref>

== Changes ==
=== Blocks ===
; [[File:Cobblestone JE2 BE1.png|32px]] [[Cobblestone]]
* Can now be smelted into [[stone]].

; [[File:Water JE11.gif|32px]] [[Water]]
* Improved performance.

; [[File:Oak Log (UD) JE2 BE1.png|32px]] [[Log|Wood]]
* Now drops itself instead of [[planks]] when {{control|broken}}.

=== Mobs ===
*Sheep only drop light gray wool when punched.

=== Items ===
; [[Armor]]
* Can no longer be stacked.
