'''Information block''' is a block that can be used by the teacher in [[MinecraftEdu]] to write text.

== Usage ==
The information block can be opened by right clicking. When right clicked, it opens a menu with text that a teacher can write. 

Player can also copy text in the information block, paste text into information block or save text from the block.
