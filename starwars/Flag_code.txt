'''Flag code''' was a code that used flags to communicate messages. When the [[comm unit]]s of the ''[[Executor]]'' were jammed while it was being [[Attack on the Executor (Scourge crisis)|attacked]] by [[droid]]s [[Scourge crisis|corrupted]] by the [[Scourge]], the [[starship|ship]]'s crew used flag code to warn approaching [[Galactic Empire|Imperial]] [[transport]]s about the droids.<ref name="Vader 38">[[Darth Vader (2020) 38|''Darth Vader'' (2020) 38]]</ref>
