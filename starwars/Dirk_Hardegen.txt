'''Dirk Hardegen''' is a [[Wikipedia:German|German]] [[Wikipedia:Author|author]]. Hardegen wrote the scripts for a number of [[German Clone Wars audio dramas]] which adapted a number of episodes of ''[[Star Wars: The Clone Wars]]'' animated television series.<ref name="German Clone Wars" />
