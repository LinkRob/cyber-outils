In the [[First Order military|military]] of the [[First Order]], a '''Code Red''' was indicative a security breach on its [[Starship|ships]], which necessitated a lockdown.<ref name="The Escape" /> In [[34 ABY]],<ref name="Date">{{ResistanceDate|2|18}}</ref> the [[Resistance]] operatives [[Kazuda Xiono]] and [[Jarek Yeager]] ran from pursuing [[First Order stormtrooper|stormtroopers]] while aboard the First Order [[Resurgent-class Star Destroyer|''Resurgent''-class Star Destroyer]]<ref name="The Escape" /> ''[[Thunderer]]''.<ref name="Timelines">''[[Star Wars: Timelines]]''</ref> As the pair sprinted further away, [[Agent]] [[Tierny]] demanded via [[Comm unit|comlink]] that all positions should be locked down to prevent their escape, calling a Code Red. A [[Unidentified First Order security personnel|security worker]] responded affirmatively to her request.<ref name="The Escape" />
