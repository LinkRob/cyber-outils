The {{Term/Store|Fierce Deity Set||Series, BotW}} is an [[Armor Set]] in {{BotW}} and {{TotK}}.<ref>{{Cite Book|quote= |book= CaC |publisher= |page= 193}}</ref>

==Location and Uses==
{{Inventory/Set|BotW|Fierce Deity Set}}
The Fierce Deity Set is an [[Armor]] set consisting of the [[Fierce Deity Mask]], [[Fierce Deity Armor]], and [[Fierce Deity Boots]]. All three pieces can be obtained using the [[amiibo (Rune)|amiibo Rune]] while scanning the Majora's Mask Link amiibo. Each time the figure is scanned, a chest will appear that has a small chance to contain one of the pieces. As the Amiibo can only be scanned once per real-world day, a player must collect the set over three or more real-world days. 

The set can be enhanced by a [[Great Fairy]] but cannot be [[Dye|dyed]] at the [[Kochi Dye Shop]]. When it has been enhanced by two levels, it provides the Charge Atk. Stamina Up [[Set Bonus]] when worn with the full set, while each piece individually provides a single Attack Up effect. It resembles the armor worn by Fierce Deity Link from [[Majora's Mask (Item)|Majora's Mask]].
