TITLE : Game Boy Printer

[[File:Game Boy Printer.png|100px|right]]
The '''Game Boy Printer''' (ポケットプリンタ Pocket Printer) is a thermal printing accessory created for select [[Game Boy]] and [[Game Boy Color]] games. It is backward compatible with all [[Game Boy Advance]] models except the [[Game Boy Micro]].

In {{LA}}, the Game Boy Printer can be used to print [[The Travels of Link]] photographs from the [[Photographer]] in the [[Camera Shop]]. It was also compatible with several other games released for the Game Boy and Game Boy Color, notably including later [[Pokémon]] games.
