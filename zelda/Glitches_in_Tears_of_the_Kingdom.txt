==Duplicate Decayed Master Sword==
{{Glitch
|name= Duplicate Decayed Master Sword
|patched= Yes
|version= 1.1.0
|effect= Creates a duplicate of the [[Decayed Master Sword]] that can be found on the [[Great Sky Island]].
|prerequisites= A save file that has completed the Great Sky Island tutorial.
|instructions= In the pause menu, create a manual save file in the Room of Awakening.
#Start a new game and play through the intro.
#Wake up in the awakening room and check to see if there is an autosave. '''DO NOT PICK UP THE DECAYED MASTER SWORD.'''
#Reload the manual save, pull out any blade that is one-handed.
#Hold '''R''' and press minus.
#'''Watch four memories without unpausing (you can skip each memory).'''
#Press '''+''' and reload the autosave.
#If the weapon you have thrown is now on the ground, pick it up.
#Play through the Great Sky Island.
#Get to the cutscene where the Decayed Master Sword is transferred, then go back to the Room of Awakening. If the Decayed Master Sword is still there, the glitch was performed successfully.
|notes= 
*The game must be restarted in order to keep the Decayed Master Sword, so it is recommended to do this on a separate profile.
*Players have reported that reloading a save file with the Decayed Master Sword can despawn the sword and corrupt a weapon slot, this does not occur on 1.0.0 but may occur on further versions so testing that is heavily recommended.
*The Decayed Master Sword can still break, and can only fuse via glitches.
*Once the Decayed Master Sword is picked up, it cannot be dropped.
*Once the Decayed Master Sword breaks, the player can only retrieve it by reloading a save file.
