The {{Term/Store|Catalog||Series, TFH}} is an interface in {{TFH}}.<ref>{{Cite|Catalog|N/A|TFH}}</ref>

==Overview==
The {{Term|TFH|Catalog}} can be viewed by speaking to {{Term|TFH|Madame Couture|link}} in her [[Madame Couture's|shop]], or {{Term|TFH|Madame Couture's Apprentice|link}} inside {{Term|TFH|Hytopia Castle|link}}. It displays the icons of all {{Plural|TFH|Outfit|link}} available for purchase, as well as those owned by {{Term|TFH|Link|link}}, in a scrolling carousel on the bottom screen.

The top screen displays a description of the selected {{Term|TFH|Outfit}} and, if it is not yet owned, a list of the {{Plural|TFH|Material|link}} and {{Plural|TFH|Rupee|link}} required to purchase it. If the {{Term|TFH|Outfit}} is owned, the list is replaced by a preview model of {{Term|TFH|Link}} wearing the {{Term|TFH|Outfit}}, which can be rotated using the L and R buttons, or posed using the Y and X buttons.

When viewing an unowned {{Term|TFH|Outfit}}, a "Material Hint" button appears on the bottom screen. Pressing this button displays a version of the {{Term|TFH|Material List|link}} where the required {{Plural|TFH|Material}} are highlighted with a glowing effect.
