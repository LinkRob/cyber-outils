The {{Term/Store|Deluxe Picto Box||Series, TWW, TWWHD}} is an item in {{TWW}}.<ref>{{Cite Book|quote= |book= E|publisher= |page= 121}}</ref>

==Location and Uses==
The Deluxe Picto Box is an upgraded version of the original Picto Box which allows Link to take pictographs in full color. [[Lenzo]] adjusts Link's original Picto Box after he completes his [[Lenzo's Research Assistant|Research Assistant quest]]. Also, a [[Forest Firefly]] is needed in order to upgrade the Picto Box. This is not required in {{TWWHD|-}}. 

The Deluxe Picto Box is necessary to complete the Nintendo Gallery since [[Carlov]] only accepts color pictographs. It is also needed for a handful of other sidequests. A [[New Game Plus]] file starts with the Deluxe Picto Box from the beginning.
