{{Term/Store|Hero's Path Mode||Series, BotW}} is a mode in {{BotW}} introduced as part of {{TMT}} [[DLC]] pack.<ref name= "Hero">{{Cite|{{Color|BotW Red|Hero's Path mode}} unlocked. Press {{Icon|BotW X}} on the map to see your journey's path thus far.|Tutorial|BotW}}</ref>

Hero's Path Mode is in {{TotK}} again but is '''Not Part Of a DLC'''.

==Overview==
{{Term|BotW|Hero's Path Mode}} tracks every step {{Term|BotW|Link|link}} has taken during the last 200 hours.<ref>{{Cite Web|quote= This new map feature shows the path Link has walked through Hyrule from the last 200 hours of gameplay.|author= |published= |retrieved= June 3, 2017|url= http://zelda.com/breath-of-the-wild/news/expansion-pass-dlc-pack-1-detailed/|title= Expansion Pass DLC Pack 1 Detailed|site= Zelda.com|type=}}</ref> This path appears on the Map as a green line that follows Link's steps. The process can be sped up, paused, and skipped.

Upon obtaining {{TMT|-}} and opening the {{Term|BotW|Sheikah Slate|link}}'s {{Term|BotW|Map|link}}, a notice will appear informing {{Term|BotW|Link}} that {{Term|BotW|Hero's Path Mode}} has been unlocked.<ref name= "Hero"/>

Hero's Path Mode acts the same in {{TotK}}.
