The {{Term/Store|Button Settings||Series, HW, HWL, HWDE}} menu is an interface in {{HW}}.<ref>{{Cite|Button Settings|Controller Settings|HWDE}}</ref>

==Overview==
The {{Term|HWDE|Button Settings}} menu is a submenu of the {{Term|HWDE|Controller Settings|link}} menu.<ref>{{Cite|You can change the button settings by entering Settings from the main menu and selecting Button Settings in Controller Settings.|Tutorial|HWDE}}</ref> The {{Term|HWDE|Button Settings}} menu allows the player to map their own controls and assign different actions to the [[Controller Buttons]].<ref name="Cntrl Settings"/> A diagram of the used controller is shown with different boxes stating the name of the button and what action is assigned to it. The player can change these actions by selecting a box and pressing the A button, which makes a list of every action appear for the player to choose from. Selecting an action will successfully change the button. The "Confirm Settings" box must be pressed in order to save any changes made in the {{Term|HWDE|Button Settings}} menu.<ref>{{Cite|Confirm Changes|Button Settings|HWDE}}</ref><ref>{{Cite|Confirm changes and return to the previous screen.|Button Settings|HWDE}}</ref>

While playing with two [[Joy-Con]]s or a [[Pro Controller]], the player can switch between two preset options: Warriors style and Zelda style.<ref>{{Cite|Warriors Style|Button Settings|HWDE}}</ref><ref>{{Cite|Zelda Style|Button Settings|HWDE}}</ref> The Warriors style reflects the button settings used in {{Wp|Dynasty Warriors}}, a game which {{HW|-}} was inspired from.<ref>{{Cite|Set as Dynasty Warriors style.|Button Settings|HWDE}}</ref> The Zelda style follows a button mapping more similar to other button settings in {{TLoZ|Series}}.<ref>{{Cite|Set as Legend of Zelda style.|Button Settings|HWDE}}</ref> The only difference between the two presets are the A, B, X, and Y buttons. Both the Warriors style and the Zelda style have L as {{Term|HWDE|Target Lock-On|link}},<ref>{{Cite|{{Icon|HWDE L}} Target Lock-On|Button Settings|HWDE}}</ref> ZL as {{Term|HWDE|Guard (Ability)|link}},<ref>{{Cite|{{Icon|HWDE ZL}} Guard|Button Settings|HWDE}}</ref> R as {{Term|HWDE|Focus Spirit|link}},<ref>{{Cite|{{Icon|HWDE R}} Focus Spirit|Button Settings|HWDE}}</ref>, ZR to use an {{Term|HWDE|Item|link}},<ref>{{Cite|{{Icon|HWDE ZR}} Use Item|Button Settings|HWDE}}</ref>, and pressing down the R stick to use {{Term|HWDE|Fairy Magic|link}}.<ref>{{Cite|{{Icon|HWDE Right Stick Press}} Fairy Magic|Button Settings|HWDE}}</ref> Pressing minus to toggle the {{Term|HWDE|Map|link}},<ref>{{Cite|{{Icon|HWDE -}} Toggle Map|Button Settings|HWDE}}</ref>, plus to pause the game,<ref>{{Cite|{{Icon|HWDE +}} Pause|Button Settings|HWDE}}</ref>, and the D-Pad to switch {{Plural|HWDE|Warrior|link}} and {{Plural|HWDE|Item}} cannot be changed at all. In the Warriors style, the X button is used for {{Plural|HWDE|Combo Attack|link}},<ref>{{Cite|{{Icon|HWDE X}} Combo Attacks|Button Settings|HWDE}}</ref>, the A button is used for {{Plural|HWDE|Special Attack|link}},<ref>{{Cite|{{Icon|HWDE A}} Special Attack|Button Settings|HWDE}}</ref>, the B button is used to {{Term|HWDE|Dodge|link}},<ref>{{Cite|{{Icon|HWDE B}} Dodge|Button Settings|HWDE}}</ref>, and the Y button is used for {{Plural|HWDE|Regular Attack|link}}.<ref>{{Cite|{{Icon|HWDE Y}} Regular Attacks|Button Settings|HWDE}}</ref> In the Zelda style, the X button is used for {{Plural|HWDE|Special Attack}},<ref name="X Special">{{Cite|{{Icon|HWDE X}} Special Attack|Button Settings|HWDE}}</ref> the A button is used to {{Term|HWDE|Dodge}},<ref name="A Dodge">{{Cite|{{Icon|HWDE A}} Dodge|Button Settings|HWDE}}</ref>, the B button is used for {{Plural|HWDE|Regular Attack}},<ref name="B Dodge">{{Cite|{{Icon|HWDE B}} Regular Attacks|Button Settings|HWDE}}</ref>, and the Y button is used for {{Plural|HWDE|Combo Attack}}.<ref name="Y Combo">{{Cite|{{Icon|HWDE Y}} Combo Attacks|Button Settings|HWDE}}</ref>

When playing with a singular right sided Joy-Con, the player can use the same styles used with two Joy-Cons or a Pro Controller, the Warriors style and Zelda style. Both the Zelda style and the Warriors style use the same button layout as when playing with two Joy-Cons, but the controls are rotated 90 degrees on its side to match the right Joy-Con. So for the Warriors style, B is for {{Plural|HWDE|Regular Attacks}},<ref name="B Dodge"/> X is for {{Plural|HWDE|Special Attack}},<ref name="X Special"/> A is to {{Term|HWDE|Dodge}},<ref name="A Dodge"/> and Y is for {{Plural|HWDE|Combo Attack}}.<ref name="Y Combo"/> With the Zelda style, the Y button is for {{Plural|HWDE|Special Attack}},<ref>{{Cite|{{Icon|HWDE Y}} Special Attacks|Button Settings|HWDE}}</ref> X is to {{Term|HWDE|Dodge}},<ref>{{Cite|{{Icon|HWDE X}} Dodge|Button Settings|HWDE}}</ref> A is for {{Plural|HWDE|Regular Attack}},<ref>{{Cite|{{Icon|HWDE A}} Regular Attack|Button Settings|HWDE}}</ref> and B is for {{Plural|HWDE|Combo Attacks}}.<ref>{{Cite|{{Icon|HWDE B}} Combo Attacks|Button Settings|HWDE}}</ref> Buttons that cannot be changed manually or between the two preset are the SL button to {{Term|HWDE|Guard (Ability)}},<ref>{{Cite|{{Icon|HWDE SL}} Guard|Button Settings|HWDE}}</ref> the R stick to move,<ref>{{Cite|{{Icon|HWDE Right Stick}} Move|Button Settings|HWDE}}</ref> pressing down the R stick to {{Term|HWDE|Target Lock-On}},<ref>{{Cite|{{Icon|HWDE Right Stick Press}} Target Lock-On|Button Settings|HWDE}}</ref> the plus button to pause,<ref>{{Cite|{{Icon|HWDE +}} Pause|Button Settings|HWDE}}</ref> and the SR button to do a number of actions.<ref>{{Cite|{{Icon|HWDE SR}} Multifunction Button|Button Settings|HWDE}}</ref> Above the two presets, the {{Term|HWDE|Multifunction Settings|link}} button appears only when using one Joy-Con which allows the player to view the controls of the SR button.<ref>{{Cite|Check the functionality of holding {{Icon|HWDE SR}}.|Button Settings|HWDE}}</ref>

The buttons changed while playing with a singular left sided Joy-Con are only the minus button and the letter buttons. Instead of the plus button, the minus button is used to pause the game.<ref>{{Cite|{{Icon|HWDE -}} Pause|Button Settings|HWDE}}</ref> While using the Warriors style, instead of pressing the X button to perform {{Plural|HWDE|Special Attack}}, the right button must be pressed.<ref>{{Cite|{{Icon|HWDE D-Pad Right}} Special Attacks|Button Settings|HWDE}}</ref> Instead of the A button to {{Term|HWDE|Dodge}}, the down button must be pressed.<ref>{{Cite|{{Icon|HWDE D-Pad Down}} Dodge|Button Settings|HWDE}}</ref> The up button must be pressed instead of the Y button to perform {{Plural|HWDE|Combo Attack}}.<ref>{{Cite|{{Icon|HWDE D-Pad Up}} Combo Attacks|Button Settings|HWDE}}</ref> Instead of the B button, the left button must be pressed to perform {{Plural|HWDE|Regular Attack}}.<ref>{{Cite|{{Icon|HWDE D-Pad Left}} Regular Attacks|Button Settings|HWDE}}</ref> While using the Zelda style, instead of pressing the A button to perform {{Plural|HWDE|Regular Attack}}, the down button must be pressed instead.<ref>{{Cite|{{Icon|HWDE D-Pad Down}} Regular Attacks|Button Settings|HWDE}}</ref> Instead of pressing the B button to perform {{Plural|HWDE|Combo Attack}}, the left button must be pressed instead.<ref>{{Cite|{{Icon|HWDE D-Pad Left}} Combo Attacks|Button Settings|HWDE}}</ref> Instead of pressing the X button to {{Term|HWDE|Dodge}}, the right button must be pressed instead.<ref>{{Cite|{{Icon|HWDE D-Pad Right}} Dodge|Button Settings|HWDE}}</ref> Instead of pressing the Y button to perform {{Plural|HWDE|Special Attack}}, the up button must be pressed instead.<ref>{{Cite|{{Icon|HWDE D-Pad Up}} Special Attack|Button Settings|HWDE}}</ref>

==Trivia==
*The {{Term|HWDE|Button Settings}} will always show the double [[Joy-Con]]s in a [[Joy-Con Grip]] even if the players Joy-Cons are not in a grip.
