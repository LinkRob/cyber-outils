The {{Page Name}} is an Armor set in {{TotK}}.

== Location and Uses ==
The full uniform set worn by the {{Term|TotK|Yiga Clan|link}}; a shinobi full red bodysuit with an iconic mask. The set consits of {{Term|TotK|Yiga Clan Mask|link}}, {{Term|TotK|Yiga Armor|link}}, and {{Term|TotK|Yiga Tights|link}}.

The set requires each parts to be found individually. They are found in three locations: {{Term|TotK|Akkala Ancient Tech Lab|link}}, {{Term|TotK|Great Plateau|link}}, and {{Term|TotK|Aldor Foothills|link}}. Each of these locations have at least a hostage, who are forced to make armor for the Yiga Clan. Once these hostages are freed, they give Link one part of the Yiga Clan armor set.

The Yiga Armor set has similar statistics like the {{Term|TotK|Stealth Set|link}} from {{BotW}}. It adds Stealth up to silence normal footsteps and make enemies harder to hear Link. It has low armor rating and doesn't provide much protection.

Wearing a full set will make {{Term|TotK|Link|link}} pose as a Yiga clan member, allowing him to blend in with at least almost every other Yiga. It also allows Link to access most Yiga-restricted locations, to which he normally could not.

* Aside from disguise, wearing the full armor set has special interactions for certain situations:
