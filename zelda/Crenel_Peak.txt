{{Term/Store|Crenel Peak||Series, BotW}} is a location in {{BotW}}.<ref>{{Cite|Crenel Peak|Map|BotW}}</ref>

==Features and Overview==
{{Term|BotW|Crenel Peak}} is located in {{Term|BotW|Hyrule Field|link}}.{{Note|In {{CaC}}, {{Term|BotW|Crenel Peak}} is shown on a map to be part of the {{Term|BotW|Lanayru Wetlands|link}}.<ref>{{Cite Book|quote= |book= CaC |publisher= |page= 273}}</ref> However, this contradicts the game's file data for the location which considers it to be part of {{Term|BotW|Hyrule Field}}, so it is not considered [[Guidelines:Canon|Canon]].<ref>{{Cite|Central Hyrule|System|BotW}}</ref>}}

==Nomenclature==
{{Term|BotW|Crenel Peak}} is named after {{Term|TMC|Mount Crenel|link}}, a mountain from {{TMC}}. In other languages, including Japanese and German, it shares its name with {{Term|TMC|Mount Crenel}}.
