The {{Term/Store|Hylian Set||Series, BotW}} is an [[Armor]] set in {{BotW}}.{{Name Ref|BotW}}

==Location and Uses==
The Hylian Set is an [[Armor]] set consisting of the [[Hylian Hood]], [[Hylian Tunic]], and [[Hylian Trousers]]. All three pieces are sold at both the {{Term|BotW|Enchanted|link}} armor shop in [[Kakariko Village#Breath of the Wild|Kakariko Village]] and [[Ventest Clothing Boutique]] in [[Hateno Village]]. It does not feature any set bonuses.
