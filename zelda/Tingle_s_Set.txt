==Location and Uses==
{{Stub|BotW}}
{{Term|BotW|Tingle's Set}} can be found by using {{Term|BotW|Magnesis|link}} to pull three DLC {{Plural|BotW|Treasure Chest|link}} from the ground in various spots in {{Term|BotW|Hyrule Field|link}}. {{Term|BotW|Tingle's Hood|link}} can be found in the {{Term|BotW|Exchange Ruins|link}}, {{Term|BotW|Tingle's Shirt|link}} can be found on the large island next to {{Term|BotW|Hyrule Castle|link}}, and {{Term|BotW|Tingle's Tights|link}} can be found in the {{Term|BotW|Mabe Village Ruins|link}}. This set can only be found if "{{Term|BotW|The Master Trials|link}}" DLC is active. Like the {{Term|Series|Dark Series|link}}, {{Term|Series|Phantom Ganon Set|link}}, {{Term|Series|Phantom Set|link}}, and {{Term|Series|Radiant Set|link}} it humorously scares other characters when worn.
