The {{Term/Store|File-Selection Screen|File-Selection Screens|Series, TWWHD, ST, ALBW}},{{Exp Game|TWWHD, ST, ALBW}},<ref>{{Cite Manual|quote= |game= TWWHD|page= 6}}</ref><ref>{{Cite Manual|quote= |game= ST|page= 13}}</ref><ref>{{Cite Manual|quote= |game= ALBW|page= 4}}</ref> titled '''File-Selection''' in all versions of {{TWW}} prior to {{TWWHD}} and also known as the {{Term/Store|Player Select Screen|Player Select Screens|ALttP, LA, LADX, LANS}},{{Exp Game|ALttP, LA}}<ref>{{Cite Manual|quote= |game= ALttP|page= 9}}</ref><ref>{{Cite Manual|quote= |game= LA|page= 6}}</ref><ref>{{Cite Manual|quote= |game= LADX|page= 8}}</ref> the {{Term/Store|File Select Screen|File Select Screens|OoT, OoT3D}},{{Exp Game|OoT}}<ref>{{Cite Manual|quote= |game= OoT|page= 9}}</ref> the {{Term/Store|File Selection Screen|File Selection Screens|MM, MM3D, OoS, OoA}},{{Exp Game|MM, OoS, OoA}}<ref>{{Cite Manual|quote= |game= MM|page= 8}}</ref><ref>{{Cite Manual|quote= |game= OoS|page= 12}}</ref><ref>{{Cite Manual|quote= |game= OoA|page= 12}}</ref> the {{Term/Store|File Selection|File Selections|FSAE}},{{Exp Game|FSAE}}<ref>{{Cite Manual|quote= |game= FSAE|page= 4}}</ref> the {{Term/Store|Select Game Screen|Select Game Screens|FSA}},{{Exp Game|FSA}}<ref>{{Cite Manual|quote= |game= FSA|page= 24}}</ref> the {{Term/Store|File Selection Menu|File Selection Menus|PH}},{{Exp Game|PH}}<ref>{{Cite Manual|quote= |game= PH|page= 8}}</ref> the {{Term/Store|File Menu|File Menus|FPTRR}},{{Exp Game|FPTRR}}<ref>{{Cite Manual|quote= |game= FPTRR|page= 11}}</ref> and the {{Term/Store|Player Select||LCT}},{{Exp Game|LCT}}<ref>{{Cite|{{Color|LCT Blue|Player Select}}|Player Select|LCT}}</ref> is a recurring interface in {{TLoZ|Series}}. The {{Term|Series|File-Selection Screen}} goes unnamed in {{LA|NS}}, {{OoT3D}}, and {{MM3D}}.

==Overview==
==={{ALttP|-}}===
{{Stub|ALttP}}

===={{ALttP&FS}}====
{{Stub|ALttP, FS}}
Each [[Saving|saved game]] in {{ALttP&FS}} stores the player's progress for both {{ALttP|-}} and {{FS}}, therefore the collection features a combined {{Term|FS|File-Selection Screen}} for both games.

==={{LA|-}}===
{{Stub|LA}}

==={{OoT|-}}===
The {{Term|OoT|File-Selection Screen}} in {{OoT}} features a cloudy night sky visible behind the menu. Three [[Saving|saved games]] can be selected, with each one displaying only the player's chosen name for {{Term|OoT|Link|link}}. Copying, deleting, and further options are available below the saved games.

When a saved game is selected, it then expands to show the number of times {{Term|OoT|Link}} has fallen in battle (achieved {{Term|OoT|Game Over|link}}), the size of his {{Term|OoT|Life Gauge|link}}, and icons denoting the {{Plural|OoT|Spiritual Stone|link}} and {{Plural|OoT|Sage Medallion|link}} he has collected.

===={{OoT3D|-}}====
In {{OoT3D}}, the three saved games are displayed on the bottom screen, while the top screen shows a daytime sky, which gradually changes to night and back to day. Each of the three saves displays the player's chosen name for {{Term|OoT3D|Link}}, the size of his {{Term|OoT3D|Life Gauge}}, which {{Plural|OoT3D|Spiritual Stone}} and {{Plural|OoT3D|Sage Medallion}} he has collected, and the date and time of the saved game according to the [[Nintendo 3DS]] clock. The options to copy or delete a saved game now appear after one has been selected.

If {{MQ}} has been unlocked, then the player selects a "Normal" or {{MQ|-}} mode before the {{Term|OoT3D|File-Selection Screen}} appears, meaning that each mode gets its own {{Term|OoT3D|File-Selection Screen}} and set of saved games. In addition, the top screen will display a rotating statue of {{Term|OoT3D|Link}} in a particular pose, with a brief description of the mode.

==={{MM|-}}===
The {{Term|MM|File-Selection Screen}} in {{MM}} has a similar appearance to that in {{OoT|-}}, though with the night sky taking on more of an early dawn coloring. Only two [[Saving|saved games]] can be selected, or three in the Japanese version, each displaying only the player's chosen name for {{Term|MM|Link|link}}, with an additional Owl icon if the game was saved using an {{Term|MM|Owl Statue|link}}. Copying, deleting, and further options are available below the saved games.

When a saved game is selected, it then expands to show {{Term|MM|Link}}'s {{Term|MM|Life Gauge}}—the number of {{Plural|MM|Heart Container|link}} and {{Plural|MM|Piece of Heart|link}}—as well as his current amount of {{Plural|MM|Rupee|link}} and {{Plural|MM|Mask|link}}, and which {{Term|MM|Boss|link}} remains he has obtained. If an {{Term|MM|Owl Statue}} icon is present, it will show the in-game day and time of the saved game.

===={{MM3D|-}}====
In {{MM3D}}, the number of saved games has been increased back to three. Selected from the bottom screen, each one displays the player's chosen name for {{Term|MM3D|Link}}, the number of his {{Plural|MM3D|Heart Container}}, which of the four [[Transformation]] {{Plural|MM3D|Mask|link}} and four {{Term|MM3D|Boss|link}} remains he has obtained, and the date and time of the saved game according to the [[Nintendo 3DS]] clock. The options to copy or delete a saved game not appear after one has been selected.

During the {{Term|MM3D|File-Selection Screen}}, the top screen displays many additional details about the selected saved game, including the total number of {{Plural|MM3D|Mask}} collected, the current {{Plural|MM3D|Piece of Heart|link}} (out of four), the in-game day and time, which {{Plural|MM3D|Song|link}} have been learned, {{Term|MM3D|Link}}'s current {{Term|MM3D|Sword|link}}, {{Term|MM3D|Shield|link}}, {{Term|MM3D|Quiver|link}} and {{Term|MM3D|Bomb Bag|link}}, and the location of the saved game.

==={{PH|-}}===
In {{PH}}, the {{Term|PH|File-Selection Screen}} appears on the bottom screen, while the game's title logo appears on the top screen. Only two [[Saving|saved games]] can be selected. The option to copy or delete a saved game appears after one has been selected.

Each saved game on the {{Term|PH|File-Selection Screen}} displays the player's chosen name for {{Term|PH|Link|link}}, the size of his {{Term|PH|Life Gauge|link}}, and icons denoting the {{Plural|PH|Spirit|link}} rescued, the {{Plural|PH|Pure Metal|link}} obtained, and the {{Term|PH|Phantom Sword|link}}. No additional information is shown after selecting a game, though the player can then choose between continuing the adventure and playing {{Term|PH|Battle Mode|link}}.

==={{ST|-}}===
In {{ST}}, the {{Term|ST|File-Selection Screen}} appears on the bottom screen; only two [[Saving|saved games]] can be selected. The option to copy or delete a saved game appears after one has been selected. The top screen displays a scrolling mural, featuring stone carvings of various [[Enemies in Spirit Tracks|Enemies]], [[Characters in Spirit Tracks|Characters]] and [[Items in Spirit Tracks|Items]] that {{Term|ST|Link|link}} encounters on his adventure.

Each saved game on the {{Term|ST|File-Selection Screen}} displays the player's chosen name for {{Term|ST|Link}}, the size of his {{Term|ST|Life Gauge|link}}, and which of the five Seals have been obtained. No additional information is shown after selecting a game, though the player can then choose between continuing the adventure and playing {{Term|ST|Battle Mode|link}}.

==={{ALBW|-}}===
The {{Term|ALBW|File-Selection Screen}} in {{ALBW}} is a continuation of the game's title screen, as opposed to a subsequent menu. The bottom screen of the [[Nintendo 3DS]] displays the player's chosen name for {{Term|ALBW|Link|link}} and the size of his {{Term|ALBW|Life Gauge|link}} for each of the three [[Saving|saved games]]. A blue diamond around the file number indicates that the saved game is in [[Hero Mode]]. The top screen displays an isometric overhead view of the selected saved game's location, which slowly pans around to show much of the area, while the lower border of the top screen lists the location's name, the amount of {{Plural|ALBW|Rupee|link}} {{Term|ALBW|Link}} has collected, and which {{Term|ALBW|Sword|link}}, Tunic, and {{Term|ALBW|Shield|link}} he possesses.

The option to copy or delete a saved game appears after one has been selected. In addition the bottom screen will then display which {{Plural|ALBW|Pendant of Virtue|link}} have been obtained, or, if {{Term|ALBW|Link}} has reached {{Term|ALBW|Lorule|link}}, which {{Plural|ALBW|Portrait|link}} of the {{Plural|ALBW|Sage|link|display=Seven Sages}} have been recovered.

==={{LCT|-}}===
{{Noncanon|Start}}
The {{Term|LCT|Player Select}} menu can be accessed by choosing any option on the {{Term|LCT|Title Screen|link}}.<ref>{{Cite manual|quote= Once you’ve chosen a game mode, the Player Select screen will appear.  |game= LCT |page= 4}}</ref> Choosing {{Term|LCT|Score Attack|link}} or {{Term|LCT|Practice|link}} will move to the {{Term|LCT|Player Select}} menu immediately, while {{Term|LCT|Multiplayer|link}} will show the {{Term|LCT|How Many Players?|link}} menu before showing the {{Term|LCT|Player Select}} menu.<ref>{{Cite Manual|quote=  If you’re playing a multiplayer match, you will first choose the number of players. |game= LCT |page= 4}}</ref> In the {{Term|LCT|Player Select}} menu, eight save file slots sit in two rows; four slots on the top and four slots on the bottom. Here, the player can choose which save file they want to use.<ref>{{Cite manual|quote=  Select a profile to use. |game= LCT |page= 4}}</ref> Once a save file is selected, the player will be taken to the {{Term|LCT|Level Select|link}} menu if they are in the {{Term|LCT|Score Attack}} mode. In the {{Term|LCT|Multiplayer}} and {{Term|LCT|Practice}} modes, they will be taken to the {{Term|LCT|Stage Select|link}} menu. If the player chooses a slot that has not yet been filled in, they will be taken to the {{Term|LCT|Player Registration|link}}. In {{Term|LCT|Multiplayer}}, the player chooses each save file of the player. Each save file selected will be bordered by a colored square, along with a label which marks the number of player.<ref>{{Cite|P1|Player Select|LCT}}</ref> The first border is blue, the second is red, the third is green, and the fourth is yellow. Once all the players are selected, the player will be prompted to confirm their selections.<ref>{{Cite|Are these players OK?|Player Select|LCT}}</ref> Selecting "Yes" will take the player to the {{Term|LCT|Stage Select}} menu, while selecting "No" will take them back to the {{Term|LCT|Player Select}} menu to reselect their players. The {{Term|LCT|Erase File|link}} option in the bottom right corner allows the player to erase any existing save files. In only the {{Term|LCT|Score Attack}} and {{Term|LCT|Practice}} modes, the {{Term|LCT|Top Players|link}} option appears in the top right corner of the {{Term|LCT|Player Select}} menu. Selecting this will show the player which save file has the highest scores on every {{Term|LCT|Level|link}}, and if they are on {{Term|LCT|Practice}}, it will show them the high scores for every {{Term|LCT|Stage|link}}. To exit the {{Term|LCT|Player Select}} menu, the player can select the option in the bottom left corner.
