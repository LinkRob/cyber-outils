'''Armadillo scutes''' are [[item]]s that [[armadillo]]s drop when brushed. They can be used to craft [[wolf armor]] which can be put on [[wolves]].

== Obtaining ==

=== Mob loot ===

[[Armadillo]]s drop armadillo scutes when they are [[brush]]ed.

== Usage ==

=== Crafting ===
Armadillo scutes can be crafted into [[wolf armor]].
{{Crafting usage}}

=== Repairing ===
Armadillo scutes can be used to repair [[wolf armor]].
