'''1.0.28''' is an update for {{el|ee}} which fixed several bugs.<ref>{{cite|url=https://education.minecraft.net/support/knowledge-base/latest-changelog-minecraft-education-edition/|title=What's New in Minecraft: Education Edition|date=April 30, 2018}}</ref>

== Fixes ==

* Fixed an issue that would cause the game client to crash on an earlier version of Windows 10 (RS1)
* Misc bug fixes with text input and Korean language support
