'''Alpha v1.0.16''', along with [[Alpha server 0.1.1|server 0.1.1]], is a version of {{el|je}} that added new features and commands for servers. This version is available in the [[Minecraft Launcher|launcher.]]

==Additions==
===General===
; Servers
* {{cmd|/pardon}} removes entries from the banlist.
* {{cmd|/pardon-ip}} specifies the IP address to remove from the banlist.
* Re-added {{cmd|/op}} and {{cmd|/deop}}.
* Added server operators, which can send server commands by typing a slash followed by a server command. Server operators can also build and destroy blocks near the spawn area.

; [[Splash]]
* Added new splashes:
** Menger sponge!
** idspispopd!
** Eple (original edit)!
** So fresh, so clean!

== Changes ==
* Support for more records.

== Bugs ==

* Placing a [[sign]] on a [[cactus]] will cause the game to [[Crash|crash.]]
