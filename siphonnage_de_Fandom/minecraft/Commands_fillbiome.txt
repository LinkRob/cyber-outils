Fills a specified area of a region with a specific [[biome]].

== Usage ==

Because biomes in a world are stored in cells of 4×4×4 blocks, this command is applied on each selected cell instead of each block.

Though biomes are stored in cells, biome boundaries are slightly fiddled with to make them smooth. So the shape of the region whose biome is actually changed is irregular.

The command only changes the biome, but not the blocks in it. For example, changing a forest to a desert with this command will not change the grass blocks to sand and will not plant cacti, but [[rabbit]]<nowiki/>s will spawn in that "desert", that will still look like the forest.

== Syntax ==
: <code>/fillbiome <from> <to> <biome></code>
The fillbiome [[command]] also has an optional alternate syntax when using the <code>replace</code> option:
: <code>/fillbiome <from> <to> <biome> replace <filter></code>

== Arguments ==

{{argument|from|block_pos}} and {{argument|to|block_pos}}
: The two corners to fill the biome between.
: {{arg desc|je=block_pos}}

{{argument|biome|resource}}
: Specifies the biome to fill the specified area with. See {{slink|Biome|Biome IDs}} for a list of vanilla biome IDs.
: {{arg desc|je=resource|registry=minecraft:worldgen/biome}}

{{argument|filter|resource_or_tag}}
: Specifies the biomes in the fill region to be replaced. If not specified, replaces all biomes in the fill region.
: {{arg desc|je=resource_or_tag|registry=minecraft:worldgen/biome}}
