An '''NBT path''' is a descriptive label used to specify a collection of particular elements from an [[NBT format|NBT data tree]]. A path has the general form <code>node.….node</code>, where each <code>node</code> declares what types of child tags can be chosen from previous tags.

== Nodes ==
These are all seven types of nodes available.

The tags collection start with only one element (i.e. the root tag) and changes along the nodes when resolving path. Tags in the final tag collection are just the targets selected by the NBT path.

In an NBT path, {{cd|.}} (dot/period) characters separate the nodes. Required nodes can be used arbitrarily, except the root compound tag node must be the first in the path when it is present.

== Name escaping ==

The '''valid character set''' (without quote) for a path seems to be all non-whitespace characters, as long as any opening brackets and braces (<code>[</code> and <code>{</code>) are closed and at the end of each node (that is, followed by nothing but a period or the end of the path). That being said, the "reasonable character set" for defining a tag name includes all [[Wikipedia:ASCII|ASCII]] lowercase and uppercase letters, digits, underscore, period, and square and curly brackets ([[Wikipedia:Regular expression|Regular expression]]: <code>[a-zA-Z0-9_\.[\]{}]*</code>).

Quoted strings, such as <code>"Lorem ipsum"</code> or <code>'Lorem ipsum'</code>, can be used if a tag name needs to be escaped.

== Examples ==
=== Mixed path ===
* <code>{}</code>—Specifies the root tag
* <code>{foo:4.0f}</code>—Specifies the root tag if its children tag "foo" is <code>4.0f</code>
* <code>foo</code>—Specifies the tag named "foo" under the root tag
* <code>foo.bar</code> or <code>foo{}.bar</code>—Specifies foo's children tag named "bar".
* <code>foo.bar[0]</code>—Specifies the first element of the list (or array) "bar"
* <code>foo.bar[-1]</code>—Specifies the last element of the list (or array) "bar"
* <code>foo.bar[0]."A [crazy name]!"</code>—Specifies the children tag named "A [crazy name]!" under that first element
* <code>foo.bar[0]."A [crazy name]!".baz</code>—Specifies the children tag named "baz" under that crazily named tag
* <code>foo.bar[]</code>—Specifies all elements of the list (or array) "bar"
* <code>foo.bar[].baz</code>—Specifies the children tags named "baz" under all elements of the list "bar"
* <code>foo.bar[{baz:5b}]</code>—Specifies all elements of the list "bar", in which the "baz" tags are <code>5b</code>
* <code>foo{bar:"baz"}</code>—Specifies the "foo" tag if its child tag "bar" has the value <code>"baz"</code>
* <code>foo{bar:"baz"}.bar</code>—Specifies the "bar" tag under "foo", only if it matches the value <code>"baz"</code>

=== Example 1 ===
<code>/data get entity @p foo.bar[0]."A [crazy name]!".baz</code>

These names have been arbitrarily picked, for demonstrative purposes.

*<code>foo</code>—Specifies the subtag named "foo" under the root tag.
* <code>foo.bar</code>—Specifies foo's child named "bar".
* <code>foo.bar[0]</code>—Specifies the first element of the list "bar"
* <code>foo.bar[0]."A [crazy name]!"</code>—Specifies the child named "A [crazy name]!" under that first element
* <code>foo.bar[0]."A [crazy name]!".baz</code>—Specifies the child named "baz" under that crazily named element
