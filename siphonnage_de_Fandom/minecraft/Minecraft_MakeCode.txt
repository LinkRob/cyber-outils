'''Minecraft MakeCode''' is a version of Microsoft MakeCode designed for {{el|Education}}. it allows the player to program the [[Agent]] and in-game events using [[wikipedia:Visual_programming_language|Block]], [[wikipedia:Python_(programming_language)|Python]] or [[wikipedia:JavaScript|JavaScript]].

== Trivia ==
* There was an exploit that players can use the Python mode to access [[creative]] mode by typing the code <code>player.gamemode("creative")</code> in some worlds featuring the agent mob, mainly in Hour of Code worlds.<ref>{{ytl|sP3Q12ICvbc}}</ref>
** A YouTuber by the name of camman18 uploaded the video featuring the creative mode exploit.<ref>{{ytl|OJ_5Kc7aQEo}}</ref> It got caught by the attention of a [[Mojang Studios|Mojang]] employee and was patched around June 2023, by replacing these worlds with a different name without the code exploits.<ref>{{ytl|hXShmGvVm8c}}</ref>
