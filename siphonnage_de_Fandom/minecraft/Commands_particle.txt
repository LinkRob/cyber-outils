Creates [[particles]].

== Syntax ==
*'''Java Edition'''
: <code>particle <name> [<pos>]</code>
: <code>particle <name> <pos> <delta> <speed> <count> [force|normal] [<viewers>]</code>
*'''Bedrock Edition'''
: <code>particle <effect: string> [position: x y z]</code>

== Arguments ==
{{argument|name|particle|effect: string|basic_string}}
: Specifies the particle to create.
: {{IN|bedrock}}, {{lcfirst:{{arg desc|be=string}}}} And it should be the namespaced identifier of the particle (namespace cannot be omitted).
: {{IN|java}}, {{lcfirst:{{arg desc|je=particle}}}}

{{argument|pos|vec3|position: x y z|CommandPositionFloat}}
: Specifies the position at which to create the particle. If not specified, defaults to the position of the executor.
: {{arg desc|je=vec3|be=CommandPositionFloat}}

{{el|je|short=1}}: {{argument|delta|vec3}}
: {{arg desc|je=vec3}}
: Specifies the size of the 3-dimensional cuboid volume to spawn particles in, centered on position <code><pos></code>, and multiplied by about 8 (using <code>1 1 1</code> specifies a cuboid of about 8×8×8 in size). Negative values may be used, but have the same effect as their positive counterparts (using <code>-1 -1 -1</code> still equates to an 8×8×8 cuboid). Note that the generated particles aren't evenly distributed over the cuboid, instead it uses a Gaussian distribution resulting in a particle-gradient most dense at the center. [[Commands#Tilde and caret notation|Tilde and caret notation]] may be used, the resulting coordinates are then used as delta.

::''Exception 1:'' When <code><name></code> is <code>entity_effect</code> or <code>ambient_entity_effect</code>, a <code><count></code> of 0 causes the <code><delta></code> and <code><speed></code> to act like RGBE values instead, ranging from 0.0 to 1.0.  The three <code><delta></code> values give red, green, and blue components for the color; the <code><speed></code> provides an exponent that makes the colors brighter or dimmer, with 128 being a default.
::''Exception 2:'' When <code><name></code> is <code>note</code>, a <code><count></code> of 0 causes the first value of <code><delta></code> to specify the note's color, ranging from 0.0 to 1.0. The values of 0.0 and 1.0 produce green particles, and the values in between produce colors according to the table on [[Note block#Notes|Note block § Notes]].
::''Exception 3:'' When <code><count></code> is set to 0, the <code><delta></code> instead acts as motion values for the particle, with <code><speed></code> acting as a multiplier. <code><dx></code>, <code><dy></code> and <code><dz></code> instead becomes <code><motion:x></code>, <code><motion:y></code> and <code><motion:z></code> respectively. Particles that don't have any motion to begin with are not affected by this (Example: <code>barrier</code>).

{{el|je|short=1}}: {{argument|speed|float}}
: Specifies the speed of the particle. Does not work on all particles (Example: <code>angry_villager</code>).
: {{arg desc|je=float|min=0.0}}

{{el|je|short=1}}: {{argument|count|integer}}
: Specifies the number of particle effects to create. If 0, it results in a single particle. See the exceptions on <code><delta></code> for why having a <code><count></code> of 0 can be useful.
: {{arg desc|je=integer|min=0}}

{{el|je|short=1}}: {{cd|force{{!}}normal}}
: Specifies the display mode: <code>normal</code> or <code>force</code>.
:: <code>normal</code>: the particle(s) will be sent to players within 32.0 blocks (exclusive).
:: <code>force</code>: allows the particle(s) to be sent to players within 512.0 blocks (exclusive).
:: Defaults to the <code>normal</code> mode.

{{el|je|short=1}}: {{argument|viewers|entity}}
: Allows control of which player should view this particle instead of everyone in the viewing range of the particle.
: {{arg desc|je=entity|amount=multiple|type=players}}

== Examples ==
To create a stationary huge explosion particle 10 blocks to the east:
* {{El|java}}: <code>/particle minecraft:explosion_emitter ~10 ~ ~</code>
* {{El|bedrock}}: <code>/particle minecraft:huge_explosion_emitter ~10 ~ ~</code>
