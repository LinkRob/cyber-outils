'''Alpha v1.0.8''' was a version of [[Alpha]] released on July 20, 2010,<ref>[[wordofnotch:833718811|Minecraft Alpha 1.0.8]] – The Word of Notch, July 20, 2010</ref> which added [[cow]]s, [[milk]], and [[leather]]. It also changed the [[crafting]] recipe for leather [[armor]].

== Additions ==
=== Items ===
; [[File:Leather JE1 BE1.png|32px]] [[Leather]]
* Drops when a cow is killed.

; [[File:Milk Bucket JE1 BE1.png|32px]] [[Milk Bucket]]
* Currently unobtainable.
* Has no function.

=== Mobs ===
; [[File:Cow JE1.png|48px]] [[Cows]]
* Drops 0–2 leather upon [[death]].

== Changes ==
=== Items ===
; [[Armor|Leather Armor]]
* Now crafted using [[leather]], rather than [[wool]].
