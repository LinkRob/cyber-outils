Used to remove players' [[spawn]] points in the [[world]].

== Syntax ==

: <code>clearspawnpoint [player: target]</code>

== Arguments ==

{{argument|be=1|player: target|CommandSelector<Player>}}
: Specifies the [[player]] whose spawn point should be removed. If not specified, defaults to the command's executor ({{code|@s}}).
: {{arg desc|type=players|be=player}}

{{Result table|the arguments are not specified correctly|unparseable|unparseable}}
{{Result table|<code>player: target</code> is not of [[Target_selectors#Player_type_and_single_type|player type]]|N/A|fail}}
{{Result table|<code>player: target</code> fails to resolve to one or more online players|fail}}
{{Result table|<code>player: target</code> is not specified and the command's executor is not a player}}
{{Result table|<code>player: target</code>'s spawn point is already cleared}}

{{Result table}}
