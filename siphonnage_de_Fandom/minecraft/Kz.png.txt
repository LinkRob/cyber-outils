'''kz.png''' is a [[texture atlas]] used for storing textures of [[painting]]s.

'''paintings_kristoffer_zetterstrand.png''' was a texture atlas found inside <samp>[[minecraft.jar]]</samp> used for storing textures of paintings {{in|JE}}.

== Format ==
<samp>kz.png</samp> is a fixed-width 256×256-pixel file that is split into different 16x16 squares which correspond to the texture of each painting.

Like with <samp>[[terrain.png]]</samp>, <samp>[[items.png]]</samp> and <samp>[[particles.png]]</samp>, paintings were originally stored on a main [[texture atlas]] rather than being separate individual files. Empty slots were filled in with the magenta grid texture.

== Trivia ==
* The "Kz" in the name "Kz.png" stands for "[[Kristoffer Zetterstrand]]", the artist of the majority of the Minecraft paintings, indicated by the fact that the file was renamed "paintings_kristoffer_zetterstrand.png" in Java Edition 1.6.
