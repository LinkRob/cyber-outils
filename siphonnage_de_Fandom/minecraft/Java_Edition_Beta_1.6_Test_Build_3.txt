'''Beta 1.6 Test Build 3''' is a version used to test [[Java Edition Beta 1.6]] the day before its release. It was never officially released to the public, however, both the client and the server are packed in an archive that can be found on the legacy update server.<ref>https://s3.amazonaws.com/MinecraftDownload/prerelease/build.zip</ref>

== Additions ==
===Blocks===
; [[File:Dead Bush JE1 BE1.png|32px]] [[Dead bush]]
* Found in [[Desert]]s.

; [[File:Grass JE1.png|32px]] [[Grass]]
* Found in certain [[biome]]s.
* [[Seed]]s are now found in grass; using a [[hoe]] on the ground no longer yields seeds.

; [[File:Fern JE1.png|32px]] [[Fern]]
* Has the same characteristics as grass.

; [[File:Oak Trapdoor JE1 BE1.png|32px]] [[Trapdoor]]

=== Items ===

; [[File:Map (item) JE1 BE1.png|32px]] [[Map]]s
* Lets the player scope out different biomes.

=== General ===

; [[Splash|Splashes]]
* Added "It's groundbreaking!"
* Added "Let our battle's begin!"
* Added "The sky is the limit!"

===Command format===
; [[Server.properties]]
* Added new settings:
** <code>view-distance</code>.
** <code>allow-nether</code>.

===Gameplay=== 
; [[Multiplayer]]
* Added [[The Nether|Nether]] support.

==Changes==
===Blocks===
; General
* Blocks destroyed by other players in multiplayer now show the breaking block particle effect.
* It's no longer possible to build solid blocks on the top layer of the map.
* Blocks that don't change appearance when the data changes don't send block updates when their data changes now.

; [[File:Red Bed JE1 BE1.png|32px]] [[Bed]]s
* Trying to sleep in the nether causes the bed to explode.

; [[File:Dispenser (S) JE1.png|32px]] [[Dispenser]]s
* When activated, it will make sounds and trigger particles in multiplayer.

; [[File:Oak Door (Right) JE4 BE1.png|32px]] [[Door]]s
* Now make sound for other players in multiplayer.

; [[File:Fire JE1.png|32px]] [[Fire]]
* Has been severely nerfed so it spreads slower, and doesn't spread infinitely.

; [[File:Ice (item) JE1 BE1.png|32px]] [[Ice]]
* Now regenerates regardless of whether it's snowing or not

; [[File:Jukebox JE1 BE1.png|32px]] [[Jukebox]]
* Now ''supports'' more than 15 different music discs. 
** No additional music discs were added until [[Java Edition 1.0.0]]. The fifteenth music disc was only added in [[Java Edition 1.19]] and the sixteenth in [[Java Edition 1.20]], well over a decade later.

; {{Animate|Red Mushroom JE2.png;Brown Mushroom JE2.png|32px}} [[Mushroom]]s
* Now spread, albeit slowly.

; {{Animate|Powered Rail (NS) JE2 BE2.png; Powered Powered Rail (NS) JE2 BE2.png|32px}} [[Powered rail]]s
* Now speedier to offset the loss of glitch-boosters.

; [[File:Water JE11.gif|32px]] [[Water]]
* Below a layer of source blocks no longer behaves like source blocks.

===Items===
; [[File:Arrow JE2 BE1.png|32px]] [[Arrow]]s
* When shot by one player, can now be picked up by other players.

===Non-mob entities===
; [[File:Oak Boat JE1.png|32px]] [[Boat]]s & [[File:Minecart_JE2_BE1.png|32px]] [[minecart]]s
* Can't go through [[nether portal|portals]] that are empty or occupied.

===Gameplay===
; [[Lighting]]
* The lighting on block icons in the inventory has been changed to appear brighter.

; [[Player]]s
* When stuck in walls, will slide towards the nearest gap if there is one.

===General===
; [[Control]]s
* {{key|Shift}}+clicking while crafting makes as much as possible and moves it straight to player's inventory.
* {{key|Shift}}+clicking something in player's inventory will push it directly in player's hot bar and vice-versa.

; Network traffic
* Compressed network traffic more aggressively.

; [[Texture pack]]s
* Added support for <code>misc\grasscolor.png</code> and <code>misc\foliagecolor.png</code> images.

===World generation===

* A line of up to 7 chests will generate near the spawn point, containing each Item/block in the game, even the ones that shouldn't be obtainable. The content of the chest is the following: (the repeating of the first 38 Items after the Powered Rail is found In-game in the chests, the reason is unknown.)

==Trivia==

* <!--The previous Beta 1.6 Test Builds (1 & 2) were released privately.{{cn}} Beta 1.6 Test Build 3 was accidentally released to the public.-->
* Advanced OpenGL is enabled by default in this version. In [[Java Edition Beta 1.6|Beta 1.6]] Advanced OpenGL was removed temporarily until [[Java Edition Beta 1.6.5|Beta 1.6.5]] due to bugs.
** Advanced OpenGL will crash [[Minecraft]] on some computers.
* Picking up multiple stacks of items takes a few ticks to finish, unlike the final version where it only takes one.
* The fix for the crash when riding a vehicle or animal through a nether portal is done differently.{{Verify|type=change|edition=java|In what way?}}
* Session requests are performed over HTTP instead of HTTPS.
** Session requests fail on any code other than HTTP 200, instead of only with HTTP 400.
* Connection to the server is closed differently; no thread is used in this build.
* GL state when rendering items is not properly reset, which may lead to graphical artifacts.{{Verify|type=change|edition=java|In what way?}}

===Validity===

While modern versions of ''Minecraft'' are hosted on <code>s3.amazonaws.com/Minecraft.Download</code>, this version is hosted on <code>s3.amazonaws.com/MinecraftDownload</code> (without the period). At first it may seem that this site is not owned by [[Mojang Studios]], but it can be verified as Mojang-owned in several ways:

*The legacy ''Minecraft'' [[launcher]] (from 2013) uses this site to update, which can be verified through a decompiler.
*''Minecraft'' [[Classic]] was loaded from <code>s3.amazonaws.com/MinecraftDownload/classic/minecraft.jar</code> when it could still be accessed on [[minecraft.net]].<ref>While the page for classic is no longer accessible, [http://web.archive.org/web/20150910183326/https://minecraft.net/classic/play archived versions] do include this link.</ref></onlyinclude>
