'''0.0.15a''' (Multiplayer Test 3) was a version of [[Java Edition Classic]] released on June 3, 2009, at 18:28 UTC.<ref name="updated">[[#logs|IRC logs]]: "''[12:28] <@Notch> the mp test server is updated with better client interpolation. =)''" (18:28 UTC)</ref>

== Changes ==

=== General ===
* Better client interpolation.<ref name="updated" /> 

== Fixes ==

* Fixed player animations.<ref>[[#logs|IRC logs]]: "''[12:34] <@Notch> the players animate better now, I hope?''" (18:34 UTC)</ref>

== Bugs ==
* A lot of players appear to just be standing about.<ref>[[#logs|IRC logs]]: "''[14:07] <@C418> the client predictions removed the lag. but it also added people just standing about''" (20:07 UTC)</ref>
