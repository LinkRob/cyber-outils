'''1.9.1'''<ref>[[Special:Diff/1471602|Wiki diff #1471602]], December 7, 2009, 01:02</ref><ref name="changelog"/> is a [[Classic]] server version released with [[Classic 0.29|0.29]] on October 29, 2009.<ref>[[wordofnotch:226839147|"Creative mode client update and Server update"]] – The Word of Notch, October 29, 2009</ref>

== Fixes ==
* Trees now will not grow unless <code>grow-tree</code> is set to "true" in [[server.properties]].<ref name="changelog"/>
* Opping and/or de-opping a [[player]] will update their status immediately without them having to relog.<ref name="changelog"/>
