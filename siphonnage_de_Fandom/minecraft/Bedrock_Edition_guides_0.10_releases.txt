This guide is a simplified overview of all the changes in the [[Bedrock Edition]] 0.10.x releases, which assumes at least some familiarity with 0.9.x releases.

== Creature ==
=== Changes ===
{|{{Simple Guide table|Changed Mobs}}
|-
|General
|
|
* {{ve}} Made slight adjustments to each animal so that the walking animation is now faster.
* Hostile mobs now spawn in groups.
* Baby animals can now swim.
|-
|[[Slime]]
|[[File:Slime JE3 BE1.png|128px]]
|
* Slimes now have a bouncing animation.
|}
