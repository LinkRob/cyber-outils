{{exclusive|bedrock}}
This page lists NBT structures of block entities {{in|bedrock}}.

A [[block entity]] is used by ''Minecraft'' to store information about a block that can't be stored in the block's block states.

== Block Entity ==
{{#if:{{#var:isIncluded}}||
All block entities share this base:
*{{nbt|compound}}: The block entity's root tag.}}
** {{nbt|string|CustomName}}: (May not exist) The custom name of the block entity.
** {{nbt|string|id}}: The savegame ID of the block entity.
** {{nbt|byte|isMovable}}: 1 or 0 (true/false) - true if the block entity is movable with a piston.
** {{nbt|int|x}}: X coordinate of the block entity.
** {{nbt|int|y}}: Y coordinate of the block entity.
** {{nbt|int|z}}: Z coordinate of the block entity.

=== Beacon ===
{{#if:{{#var:isIncluded}}||
Additional fields for [[beacon]]:
*{{nbt|compound}}: The block entity's root tag.}}
** {{nbt|int|primary}}: The primary effect selected, see [[Status_effect|Potion effects]] for IDs. Set to 0 when no effect is selected.
** {{nbt|int|secondary}}: The secondary effect selected, see [[Status_effect|Potion effects]] for IDs. Set to 0 when no effect is selected. When set without a primary effect, does nothing. When set to the same as the primary, the effect is given at level 2 (the normally available behavior for 5 effects). When set to a different value than the primary (normally only Regeneration), gives the effect at level 1.{{needs testing}}
