== Changes ==
=== Mobs ===
; [[Slime]]
* Changed their texture

=== Other ===
* The client now checks if two instances of the game try to save to the same level, and quits if it does.
** It is checked with a {{cd|session.lock}} file.
* Multiplayer progress.
* The arm no longer gets stuck if {{key|F5}} is disabled while moving, as well as holding an item.
** As a result, the arm no longer has the idle animation when the inventory is shown.

==Fixes==
;1 bug fixed
