'''Alpha v1.0.16_02'''<ref>{{ytl|BXV8cil0lZo|Cannon as High Speed Transport|MrDopekitten|August 15, 2010}}</ref> is a version of ''Minecraft'' ({{el|je}}) released on August 13, 2010. Corresponding server version [[Alpha server 0.1.3|0.1.3]] was released on August 17, 2010.

== Additions ==

* Added {{cmd|tell}} command for players to whisper things to other players
* {{cmd|list}} will show a list of connected players to the op who issued it

== Changes ==

* Ops can now build in the spawn area
* The server logs what admin does, and broadcasts any admin events to all connected ops

== Fixes ==
;2 bugs fixed
* Fixed {{cmd|save-off}}
* Fixed a bug relating to player (and mob{{verify}}) death.

== Trivia ==
* [[Herobrine]] was first shown in an edited screenshot from this version. The [[world seed]] in which the Herobrine screenshot was taken is {{code|478868574082066804}} at coordinates: X=5.0602, Y=71, Z=-298.5365<ref>https://minecraftathome.com/projects/herobrine.html</ref>
