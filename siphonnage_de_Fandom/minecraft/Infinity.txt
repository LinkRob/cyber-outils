'''Infinity''' is an [[enchantment]] to [[bow]]s that prevents regular [[arrow]]s from being consumed when shot. One arrow is needed to use a bow enchanted with Infinity. 

== Usage ==
A [[bow]] enchanted with Infinity can be used to shoot unlimited arrows, as long as the player's inventory contains at least 1 arrow. Fired arrows cannot be retrieved except in Creative mode (in which they are erased instead of added to the player's inventory).

Infinity has no effect on [[Tipped Arrow|tipped]] and [[Spectral Arrow|spectral]] arrows; they are still consumed as usual.

A [[crossbow]] still consumes arrows if [[commands]] are used to add Infinity to it.

Infinity is practically useless in Creative mode, as arrows don't need to be in the player's inventory.

== Incompatibilities ==
[[Mending]] and Infinity are mutually exclusive. However, if combined with [[commands]], both enchantments function as normal.
