The '''Friendly Update''' is the name for ''[[Pocket Edition|Minecraft: Pocket Edition]]'' version [[Pocket Edition v0.15.0 alpha|Alpha v0.15.0]], a major update released on June 10, 2016 for Android, and June 13, 2016 across all platforms.

The official name for the update, the ''Friendly Update'', was revealed on June 3, 2016 in a blog post on the Mojang website.<ref>https://web.archive.org/web/20160603130421/http://www.mojang.com/2016/06/whats-in-015-the-friendly-update-for-pocket-win-10/</ref>

== Notable features ==

{{main|Pocket Edition v0.15.0 alpha}}

=== Additions ===
* [[Realms]], which requires logging into an Xbox Live account
*[[Achievements]] for iOS and Android devices
* Online multiplayer via Xbox Live
* Pig riding
* [[Piston]]s and [[Piston|sticky piston]]s
* The [[observer]], a block update detector.
* Sheep now drop [[mutton]].
*[[Arrow|Tipped arrows]], which are made by using cauldrons
*[[Horse Armor|Leather horse armor]], which can be dyed.
* Seven new mobs: [[horse]]s, mules, donkeys, [[skeleton trap]]s, [[Zombie Horse|zombie horses]], [[stray]]s, and [[husk]]s.
* [[Name tag]]s
* [[Lead]]s
* [[Fire charge]]s
* [[Carrot on a stick]]
*[[Village]]s now spawn in [[taiga]] biomes and [[ice plains]] biomes.

=== Changes ===
* [[Trapdoor]]s no longer require supporting blocks.
* [[Shear]]s now lose durability when breaking any block.
* For performance, online multiplayer now uses less bandwidth.
* Villages in [[savanna]] biomes now use acacia wood.

== Further revisions ==

* [[Pocket Edition v0.15.1 alpha|Alpha v0.15.1]], [[Pocket Edition v0.15.2 alpha|Alpha v0.15.2]], [[Pocket Edition v0.15.3 alpha|Alpha v0.15.3]], and [[Pocket Edition v0.15.4 alpha|Alpha v0.15.4]] fixed numerous bugs and crashes.
* [[Pocket Edition v0.15.6 alpha|Alpha v0.15.6]] added some features specific for virtual reality, and also fixed some bugs and crashes from Alpha v0.15.4.
* [[Pocket Edition v0.15.7 alpha|Alpha v0.15.7]], [[Pocket Edition v0.15.8 alpha|Alpha v0.15.8]], [[Pocket Edition v0.15.9 alpha|Alpha v0.15.9]], and [[Pocket Edition v0.15.10 alpha|Alpha v0.15.10]] added various texture packs and skin packs.
