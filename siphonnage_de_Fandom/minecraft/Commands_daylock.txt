Locks and unlocks eternal [[daytime]].

==Syntax==

: <code>daylock [lock: Boolean]</code>
: <code>alwaysday [lock: Boolean]</code>

==Arguments==

{{argument|be=1|lock: Boolean|enum}}

: Specifies whether the eternal daytime is locked or not.
: {{arg desc|be=bool}} If not specified, defaults to <code>true</code>. Note that this argument has the ''opposite'' sense from the <code>gamerule dodaylightcycle</code> command's argument.

==Result==
{{Result table|onlybe=1}}
{{Result table|the arguments are not specified correctly||unparseable}}
{{Result table|succeed}}
{{Result table}}

On success, sets the game option "Always Day" to the argument value. If the argument is <code>false</code>, turns on the "Do Daylight Cycle" game option. If the argument is <code>true</code> or is omitted, turns off the "Do Daylight Cycle" game option and sets the time of day (<code>time daytime</code> value) to 5000 [[ticks]], which is one in-game hour before noon.
