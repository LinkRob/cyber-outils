'''Alpha v1.0.1'''<ref>{{ytl|7HZLzz13B6k|Minecraft secret friday update the third|LouisWasTaken|July 2, 2010}}</ref> was the third of the [[Seecret Updates]], released on July 2, 2010.<ref>[[wordofnotch:763147353|Seecret Friday update the third! OooooOOOoo!]] – The Word of Notch, July 2, 2010</ref> It is the first version truly named Alpha as [[Alpha v1.0.0]] was only called "Alpha" retroactively upon the release of v1.0.1.

== Changes ==
=== Blocks ===
; [[File:Cobblestone Stairs JE1 BE1.png|32px]] [[Cobblestone stairs]]
* Inventory model is now 3D: [[File:Cobblestone Stairs (inventory) JE2.png|32px]]

; [[File:Oak Door (item) JE2 BE1.png|32px]] [[Oak door]]
* Item texture changed from [[File:Oak Door (item) JE1.png|32px]]

; {{Animate|Red Mushroom JE2.png;Brown Mushroom JE2.png|32px}} [[Mushroom]]s
* Generate anywhere.{{verify|Needs clarification|type=untestable}}
* If generated in sunlight will eventually drop.
** Do not drop at night time.

; [[File:Oak Stairs JE1 BE1.png|32px]] [[Oak stairs]]
* Inventory model is now 3D: [[File:Oak Stairs (inventory) JE2.png|32px]]

; [[File:Oak Wall Sign (N) JE1 BE1.png|32px]] [[Sign]]s
* Can now be placed on the sides of [[block]]s.
* Smaller and non-solid.

; [[File:Spawner JE1.png|32px]] [[Spawner]]s
* Does not drop as an item upon being mined.

; [[File:Lit Furnace (S) JE1.png|32px]] Burning [[furnace]]
* Now drops a regular furnace when mined instead of a burning furnace.

=== Mobs ===
; General
* Improved [[mob AI]].{{needs testing|type=untestable}}

=== World generation ===
; [[Cave]]s
* Can be much bigger than before.{{verify|type=untestable}}

; [[File:Coal Ore JE1 BE1.png|32px]] [[Coal ore]]
* Blobs now vary in size.{{verify|type=untestable}}

== Removals ==
=== Blocks ===
; [[File:Clockwise Gear (N).gif|32px]] [[Gear]]s
* Removed and replaced by the newly added redstone.
** This means that gears placed on worlds will turn into redstone or pop off, depending on how they were placed.

=== General ===
; [[Java Edition distance effects/Historical effects|Distance effects]]
* Due to their removal, [[gear]]s no longer appear very stretched at far distances.</onlyinclude>
