Sets the [[Spawn#Player spawning|world spawn]].

== Syntax ==
* '''Java Edition'''
: <code>setworldspawn [<pos>] [<angle>]</code>

* '''Bedrock Edition'''
: <code>setworldspawn [spawnPoint: x y z]</code>

== Arguments ==
{{argument|pos|block_pos|spawnPoint: x y z|CommandPositionFloat}}
: Specifies the [[coordinates]] of the [[Spawn#Player spawning|world spawn]]. If not specified, defaults to the block position of the command's execution. {{IN|bedrock}}, <code>x</code> and <code>z</code> that are greater than 30,000,000 or less than -30,000,000 revert to 30,000,000 and -30,000,000 respectively. <code>y</code> values which are greater than 256 and less than 0 revert to 256 and 0 respectively.
: {{IN|java}}, {{lcfirst:{{arg desc|je=block_pos}}}}
: {{IN|bedrock}}, {{lcfirst:{{arg desc|be=CommandPositionFloat}}}}

{{el|je|short=1}}: {{argument|angle|angle}}
: Specified the yaw angle to spawn with. Defaults to 0.0.
: {{arg desc|je=angle}}

== Note ==
This command can not be used to set the world spawn in any [[dimension]] other than the [[Overworld]]. {{IN|java}}, if executed in another dimension, the command will act as if it succeeded, but the world spawn will not be changed.

On success, [[spawn chunk]]s are also changed along with the world spawn {{in|java}}.

Normal spawn spreading still applies, and can be set with a [[Commands/gamerule|gamerule]].
