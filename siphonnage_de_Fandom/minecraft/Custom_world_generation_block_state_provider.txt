** {{nbt|string|type}}: The type of the block state provider. One of {{cd|simple_state_provider}} (specifies a block state directly), {{cd|rotated_block_provider}} (rotates axially-rotated block, such as logs, chain), {{cd|weighted_state_provider}} (chooses a block state from a weighted list), {{cd|randomized_int_state_provider}} (assigns a random value to an integer block property), {{cd|noise_provider}} (randomly choose a block state according to a noise value), {{cd|dual_noise_provider}} (randomly choose a block state according to two noise values), or {{cd|noise_threshold_provider}} (use different block state when a noise value above or below the threshold).
