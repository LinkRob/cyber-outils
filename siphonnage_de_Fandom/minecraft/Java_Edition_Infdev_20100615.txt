This version of '''[[Minecraft Infdev]]''' was released on '''June 15, 2010'''.<ref>[[wordofnotch:701052977|Dynamic water and Buckets]] – The Word of Notch, June 15, 2010</ref>

== Additions ==
=== Items ===
; [[File:Bucket JE1 BE1.png|32px]] [[Bucket]]
* Collects [[water]] and [[lava]].
; [[File:Water Bucket JE1 BE1.png|32px]] [[File:Lava Bucket JE1 BE1.png|32px]] [[Water Bucket]] and [[Lava Bucket]]
* Places water and lava respectively.
* Cannot be placed onto a [[block]] already containing a [[liquid]] to replace it; only non-liquid blocks can be used to replace liquids. 

=== General ===
; [[Options]]
* Fast/fancy graphics toggle.
** This option only toggles the [[clouds]] between 2D and 3D. Fast clouds are identical to the old clouds present in [[Infdev (June 8, 2010)]]. Fancy graphics are preset by default.

== Changes ==
* Water and lava now flow.
** [[Entities]] (except shot [[arrow]]s) in flowing [[liquid]] will move along with the current.
* [[Day]]s are now slightly longer than [[night]]s.{{verify|edition=java|type=change|By how much?}}
* [[Leaves]] now decay again.
* [[Door]]s now drop when broken by upgrading some worlds.{{verify}}

== Bugs ==
* Lava does not correctly clear up once removing the source.
