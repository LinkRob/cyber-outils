A version of '''[[Indev 0.31]]''' was released on '''January 24, 2010''', at 23:10 UTC<ref group="note">The jar of this version is dated January 24, 2010 at 23:10 UTC.</ref> <ref name="Forum">{{link|url=https://www.minecraftforum.net/forums/archive/alpha/alpha-survival-single-player/796524-another-update?page=2|title=Ok, /indev/ appears to have been updated again within the last 20 minutes...|author=betasword|website=Minecraft Forum|date=January 24, 2010}}</ref> Its release was mentioned a day late in the announcement of the next Indev version's release.<ref>[[wordofnotch:353150540|Tile particle emittors, better explosions, and ads]] – The Word of Notch, January 25, 2010</ref>

== Additions ==
===General===
; Blocks
* New particle effect for harvesting blocks.<ref group="note" name="gameplay">This has been verified by gameplay from this version's jar dated January 24, 2010 at 23:10 UTC.</ref>

== Changes ==
=== Items ===
; [[File:Arrow_JE2_BE1.png|32px]] [[Bow]]s
* Now use [[arrow]]s when firing.<ref group="note" name="gameplay" />
* Firing an arrow underwater creates bubble particles.

; General
* The player can no longer drop whole stacks of items, and must instead drop one at a time.<ref group="note" name="gameplay" />
* Now get destroyed by fire and lava.{{verify|type=change|edition=java}}

=== World generation ===
; [[Indev house]]
* Now contains an extra [[chest]] with TNT in it.<ref name="Forum"/>

; World
* All air directly above bedrock layer is turned into lava.{{verify|Could be as early as in-111-1}}

=== Blocks ===
; [[Torch]]
* Shrank torch hitbox.{{verify|type=change|edition=java|could be as early as in-122}}
* [[File:Torch JE3 BE1.png|32px]] Added a top texture.{{Verify|could be the previous persion}}

; [[File:TNT JE2 BE1.png|32px]] [[TNT]]
* TNT explosions will lose power when going through stronger materials.<ref group="note" name="gameplay" />
* Now produce smoke particles.<ref name="Forum3">{{link|url=https://www.minecraftforum.net/forums/archive/alpha/alpha-survival-single-player/796524-another-update?page=2|title=HOLY! smouldering to the tnt!!! explode a tnt and watch the dust fly!|author=gigaman|website=Minecraft Forum|date=January 24, 2010}}</ref>
* Now deals more damage.<ref name="Forum1">{{link|url=https://www.minecraftforum.net/forums/archive/alpha/alpha-survival-single-player/796524-another-update?page=2|title=TNT seems to kill you a lot more.|author=Ladon|website=Minecraft Forum|date=January 24, 2010}}</ref>
* No longer destroys blocks when ignited in water or lava.{{verify|Based off this post: https://www.minecraftforum.net/forums/archive/alpha/alpha-survival-single-player/796525-new-features-in-indev I'm assuming that this was added in in-124-2}}

; [[File:Chest (S) JE1.png|32px]] [[Chests]]
* The player can no longer make triple chests.<ref name="Forum2">{{link|url=https://www.minecraftforum.net/forums/archive/alpha/alpha-survival-single-player/796524-another-update?page=2|title=You can no longer make 3 chests. :sad.gif:|author=dehodson|website=Minecraft Forum|date=January 24, 2010}}</ref>
