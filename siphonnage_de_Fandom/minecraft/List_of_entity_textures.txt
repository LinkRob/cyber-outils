This page serves as a compact list of all unique [[mob]] and [[entity]] textures or skins which have ever existed in officially released versions of ''Minecraft''. For an overview on when each texture was changed, see the appropriate [[History of textures]] subpages.

Original texture files for Java Edition can be downloaded with {{dl|9638f6997fd59545585242eadab1e5039356e77a|client|title=latest client.jar}}, and the entire default resource pack for Bedrock Edition can be downloaded from https://www.minecraft.net/en-us/addons.
