'''0.2.7''' is a server version of [[Java Edition Alpha]] released with client version [[Java Edition Alpha v1.2.5|1.2.5]] on December 1, 2010.<ref>{{tumblr|notch|2060360123|Bug update #4, and we're six people in the office now!}}</ref>

== Changes ==

* Fixed a memory leak bug in the server where entity position updates accumulated in orphaned player objects.
* Removed server support for the {{cmd|/home}} command.
