''Hour of Code'' is an yearly coding sessions released [[Minecraft Education]]. These sessions usually involve students choosing from [[wikipedia:Visual_programming_language|Block coding]] to [[wikipedia:Python_(programming_language)|Python coding]] languages, in order to begin. So far, there are 6 Hour of Code sessions.

[[File:Hour of Code 2019 Thumbnail.jpg|thumb|The thumbnail of Hour of Code 2019.]]

The first Hour of Code was for 2019. This Hour of Code was about forest fires.
"Explore basic coding concepts and learn about artificial intelligence (AI) in this free Hour of Code lesson in Minecraft: Education Edition! Help the [[Agent]] prevent forest fires with Minecraft and MakeCode..."
This Hour was also called "AI for Good".

Hour of Code 2020 was about social-emotional skills. "Use basic coding concepts to bring two villages together in this free Hour of Code lesson in Minecraft: Education Edition. Players will experience empathy and compassion for their neighbours, learn about cooperation and inclusion, and practice social-emotional skills." This Hour of Code was also called "A Tale of Two Villagers".

Hour of Code 2021, called "TimeCraft", was about the importance of computer skills. Players will experience and choose their own adventure game and explore diverse key moments in human achievement. This Hour of Code adventure revolved around travelling through space and time, while exploring the concept of building a better future using code.

Hour of Code 2022 was called "Escape Estate". This Hour of Code required players to unlock secrets, solve and reveal hidden clues via code, in order to escape from a mysterious mansion owned by Dr. Breakowski.

Hour of Code 2023 was called "Generation AI". This Hour of Code was about using problem-solving skills, computational thinking and creativity to explore Responsible AI principles. Players will have to travel back in time, correct problems, resolve issues around fairness and discrimination, reliability and safety, and more as they progress towards capturing the culprit.

The latest Hour of Code of 2024 is called "The Show Must Go On!" In this Hour of Code, players become the star coder, director and the creative mastermind. They must solve puzzles and learn key computer science skills, while saving the show. Throughout this session, players will explore the theatre to find the missing star, the Agent, and help it overcome stage fright. In the end, the players will customize the stage show with their creative input and watch their coding skills come to life.
