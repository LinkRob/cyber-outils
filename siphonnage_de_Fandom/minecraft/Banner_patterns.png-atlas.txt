'''banner_patterns.png-atlas''' is a procedurally-generated [[texture atlas]] used to store textures for all [[banner pattern]]s.
{{-}}
== Format ==
<samp>banner_patterns.png-atlas</samp> is a fixed-width 512 × 512-pixel file that store textures for all banner patterns.
