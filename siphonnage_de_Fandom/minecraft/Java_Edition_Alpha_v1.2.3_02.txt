'''Alpha v1.2.3_02''' is a version of [[Alpha]] that was released with [[Alpha server 0.2.5 01|server 0.2.5_01]] on November 25, 2010, which was the first part of a bug-fix update.<ref>[[wordofnotch:1681247283|Bug update #1. More coming tomorrow]] – The Word of Notch, November 25, 2010</ref></onlyinclude>

There is currently no direct evidence that ''Alpha v1.2.3_03'' existed.
There could be a chance that Notch skipped from version Alpha v1.2.3_02 to [[Alpha v1.2.3_04]].
