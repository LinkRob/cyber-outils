'''1.9''' (originally named '''1.8.3''') is a [[Classic]] server version that released with [[Classic 0.28|0.28]] on October 27, 2009.<ref>[[wordofnotch:224775024|"The skinny on the creative mode update"]] – The Word of Notch, October 27, 2009</ref>

The <samp>README</samp> file for this version labels it as "'''1.8.3'''", but the <samp>README</samp> for [[Java Edition Classic server 1.9.1|1.9.1]] changes this label to "1.9",<ref name="README"/> implying that this version was originally labeled "1.8.3" and retroactively renamed to 1.9.

== Additions ==
* Added server support for all features added in [[Java Edition Classic 0.28|0.28]].
* Added support for survival multiplayer.
** This is still a work in progress, and was not publicly available on the website.
** Was very buggy at this time.

== Fixes ==
* Fixed exploit where someone logging in with an illegal name would cause players to disconnect.<ref name="README"/>
