'''Alpha v1.1.2_01''' is a version of [[Alpha]] released on September 23, 2010, to fix bugs. This version is available in the [[Minecraft launcher|launcher]].

== Changes ==
* ''Minecraft'' now downloads resources from Amazon S3 cloud storage service, instead of directly from minecraft.net.</onlyinclude>

== Trivia ==
* As a result of the above change, this is the oldest Minecraft version where sounds still work without the use of a proxy or an edited Java runtime.
*In this version, PewDiePie recorded his first YouTube video: [https://www.youtube.com/watch?v=9jeJbdVl2jI Minecraft Multiplayer Fun].
* This was the last version to feature the old terrain generator along with the [[Grass Block|bright green grass]], which was an iconic staple of Alpha. 
<!-- * And this is the first version to support applying skins. -->
** In addition, due to the above,{{verify|type=change|edition=java}} this was the last version in which the [[Far Lands]] would simply not render beyond 32,000,000 blocks out from the center of the map.
** This was also the last version to have [[Java Edition removed features#.22Winter Mode.22 map type|winter mode]].
** This was also the last version to generate monoliths on the terrain.
