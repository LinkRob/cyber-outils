<onlyinclude>'''Beta 1.7'''<ref>https://mcupdate.tumblr.com/post/7080876374/minecraft-beta-17</ref> is a version of [[Java Edition Beta]] released on June 30, 2011, which adds [[piston]]s and [[shears]] among other changes.

== Additions ==
=== Blocks ===
; [[File:Piston (U) JE1.png|32px]] [[Piston]]s
*Can push blocks when powered by [[redstone]].
; [[File:Sticky Piston (U) JE1.png|32px]] [[Sticky Piston]]s
*Can push and pull blocks when powered by redstone.

=== Items ===
; [[File:Shears JE1 BE1.png|32px]] [[Shears]]
* New [[tool]].
* Used to pick up [[leaves]].
* Used to obtain [[wool]] from a [[sheep]] without harming it. 
** Yields more wool than killing sheep.

=== Mobs ===
; [[File:Silverfish JE1 BE1.png|32px]] [[Silverfish]] 
* Texture was added. 
** It cannot be summoned, as there was no AI for it.

== Changes ==
=== Blocks ===
; General
* The gray textures in the breaking animation have been replaced with opacity.

; [[Bricks]]
* Texture changed from [[File:Bricks JE2 BE1.png|32px]] to [[File:Bricks JE3.png|32px]].

; [[Cobblestone]]
* Texture changed from [[File:Cobblestone JE2.png|32px]] to [[File:Cobblestone JE3.png|32px]].

; [[File:Cobweb JE1 BE1.png|32px]] [[Cobweb]]s
* Now requires shears or a sword to be broken properly, and drops 1 [[string]] when destroyed.

; [[File:Oak Fence (EW) JE1.png|32px]] [[Fence]]s
* Can now place any block on the top.

; {{Animate|Sandstone Slab JE1.png;Oak Slab JE1 BE1.png;Cobblestone Slab JE2 BE2.png;Seamless Stone Slab JE1.png|32px}} [[Slab]]s
* Single slabs now use the bottom half of the full block's texture.

=== Items ===
; [[File:Flint and Steel JE3 BE1.png|32px]] [[Flint and steel]] 
* Now required to trigger [[File:TNT JE2 BE1.png|32px]][[TNT]].

=== General ===
; [[Control]]s
* When pressing {{key|F3}} in-game, a value ("F") from 0 to 3 will appear to indicate direction.

; [[Texture pack]]s
* The bed side texture has been moved in the texture pack file, as well as the cake texture.

=== Mobs ===
; {{Animate|Orange Sheep JE1.png;Magenta Sheep JE1.png;Light Blue Sheep JE1.png;Yellow Sheep JE1.png;Lime Sheep JE1.png;Pink Sheep JE1.png;Gray Sheep JE1.png;Light Gray Sheep JE1.png;Cyan Sheep JE1.png;Purple Sheep JE1.png;Blue Sheep JE1.png;Green Sheep JE1.png;Brown Sheep JE1.png;Red Sheep JE1.png;Black Sheep JE1.png;|32px}} [[Sheep]]
* No longer drop wool from punching them, they must be either sheared or killed.

== Bugs ==
* Right-clicking on a sheep causes the game to crash.

== Fixes ==
;2 bugs fixed
* Fixed [[clay]] generation.
* [[Squid]] can now despawn.</onlyinclude >

== Trailer ==
An official video documenting some of Beta 1.7's major features was released on Mojang's official YouTube channel on May 24, 2011. The video was made by Hat Films. Made before ''[[Java Edition]]'' was officially released (and long before [[Java Edition 1.7|1.7]] came out), the trailer omits “Beta” when referring to the version number.
