'''Alpha v1.0.11''', also known as '''Seecret Friday 6''', is the sixth [[seecret update]].<ref name="sf6"/> It added many new [[item]]s and [[block]]s, added a new [[mob]], and made other changes. This version is available in the [[Minecraft Launcher|launcher]].

== Additions ==
===Blocks===
; [[File:Sugar Cane JE1.png|32px]] [[File:Sugar Cane (item) JE1 BE1.png|32px]] [[Sugar Cane|Reeds]]
* Can be found next to [[beach]]es.

; [[File:Clay JE1 BE1.png|32px]] [[Clay]]
* Generates near water bodies.

===Items===
; [[File:Paper JE1 BE1.png|32px]] [[Paper]]
* [[Crafting|Crafted]] from 3 reeds in a row in the crafting table.

; [[File:Book JE1 BE1.png|32px]] [[Book]]
* Crafted from 3 paper in a column in the crafting table.

; [[File:Clay Ball JE1 BE1.png|32px]] [[Clay Ball]]
* 4 dropped when a clay block is broken.

; [[File:Brick JE1 BE1.png|32px]] [[Brick]]
* Obtained from [[smelting]] clay balls.

; [[File:Slimeball JE1 BE1.png|32px]] [[Slimeball]]
* Dropped by the smallest slimes, however it currently has no use.

===Mobs===
; [[File:Slime JE1.png|48px]] [[Slime]]s
* A [[hostile mob]] which splits into smaller slimes upon [[death]].
* Splits only when killed by the fist and not with swords.

== Changes ==

===Blocks===
; [[File:Bookshelf JE1.png|32px]] [[Bookshelves]]
* Are given a crafting recipe, crafted from [[planks]] and [[book]]s, making them obtainable legitimately again.
** However, when it's broken, it still drops nothing.
; [[File:Bricks JE2 BE1.png|32px]] [[Bricks]]
* Texture changed from [[File:Bricks JE1.png|32px]]
* Now craftable from 4 [[brick]] items in a 2×2 area.
; [[File:Cactus JE2 BE1.png|32px]] [[Cactus]]
* Texture changed from [[File:Cactus JE1.png|32px]]
* Cactus now causes [[damage]] to mobs only if they touch it or collide with it.
* Cactus can now only be placed on [[sand]].

===Items===
* Player's held [[item]]s display differently from the [[third person]].
* [[Milk]] can now be obtained by right-clicking a [[cow]] with a [[bucket]].
* All [[shovel]]s except for wooden now destroy [[snow]] layers instantly.</onlyinclude>

===World generation===
* Added clay and reeds to the terrain generator.
* Changed the generation of [[tree]]s and [[flower]] patches.
