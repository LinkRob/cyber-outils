'''Game drops''' (or simply '''drops''') are frequent named updates that add various blocks, items, mobs, and sometimes, structures and biomes. It was introduced on September 2024, with [[Bundles of Bravery]] being the first official game drop. Around three to four game drops are typically released each year.

Most game drops have several features added under their own experimental toggles.

== Game drops by season ==
Game drops are classified to four types by season:
* Spring Drop
* Summer Drop
* Fall Drop
* Winter/Holiday Drop

== Trivia ==
* Game drops replaces the original "1 major update per year".
** In this case, [[Tricky Trials]] is the last major update released.
* [[Bats and Pots]] is the only game drop to be released in 2023.
* Bats and Pots and [[Armored Paws]] are the only game drops that were released in 1.20 era ([[Trails & Tales]]).
** They are also the only game drops that are "retroactive".
* [[The Garden Awakens]] and [[Chaos Cubed]] are game drops that featured new biome additions (In this case, [[Pale Garden]] for The Garden Awakens, [[Sulfur Caves]] for Chaos Cubed).
* Most game drops have several features added under their own experimental toggles{{Only|BE}} (i.e, "Drop 1 of 2026" for [[Tiny Takeover]]).
* The Garden Awakens and [[Mounts of Mayhem]] are game drops that does not have their own experimental toggles.
** This is likely due to both of which being the last game drop released for that year.
** If the features for Mounts of Mayhem could have added in [[Bedrock Edition 1.21.120]], it would have added them under "Drop 4 2025" experimental toggle.
