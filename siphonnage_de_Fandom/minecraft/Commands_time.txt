Changes or queries the [[world]]'s game [[time]].

==Syntax==

* '''Java Edition'''
: <code>time add <<nowiki/>time></code>
:: Adds <code><<nowiki/>time></code> to the in-game daytime.
: <code>time query (daytime|gametime|day)</code>
:: Queries current time.
: <code>time set (day|night|noon|midnight)</code>
: <code>time set <<nowiki/>time></code>
:: Sets the internal daytime.

* '''Bedrock Edition'''
: <code>time add <amount: int></code>
:: Adds <code><<nowiki/>time></code> to the internal daytime.
: <code>time query <daytime|gametime|day></code>
:: Queries current time.
: <code>time set <amount: int></code>
: <code>time set <time: TimeSpec></code>
:: Sets the internal daytime.

==Arguments==

{{argument|time|time|amount: int|int}}
: Specifies the time to add or set.
: {{arg desc|je=time|be=int}}

{{code|daytime{{!}}gametime{{!}}day}}
: Specifies the time to query. Must be <code>daytime</code>, <code>gametime</code> or <code>day</code>.
:* <code>daytime</code> - the number of game [[tick]]s since dawn. (the internal daytime modulo 24000)
:* <code>gametime</code> - the age of the world in game ticks. (the game time modulo 2147483647)
:* <code>day</code> - the number of in-game days passed. (the internal daytime divided by 24000, then modulo 2147483647)

{{el|je|short=1}}: {{code|day{{!}}night{{!}}noon{{!}}midnight}}<br>
{{el|be|short=1}}: {{argument|be=1|time: TimeSpec|enum}}
: Specifies the time to set.
: Must be <code>day</code>, <code>night</code>, <code>noon</code>, <code>midnight</code>, <code>sunrise</code>{{only|bedrock}}, or <code>sunset</code>{{only|bedrock}}.
:* <code>day</code> = 1,000
:* <code>night</code> = 13,000
:* <code>noon</code> = 6,000
:* <code>midnight</code> = 18,000
:* <code>sunrise</code> = 23,000
:* <code>sunset</code> = 12,000

== Notes ==
<code>/time set ...</code> command {{in|java}} always directly sets the "internal daytime" to the specified number. But {{in|bedrock}}, when {{cd|time: TimeSpec}} is specified, it '''increases''' the "internal daytime" to meet the specified {{cd|time: TimeSpec}}.

For example:
:{{In|java}}, when executing <code>/time set day</code> or <code>/time set 1000</code>, the "internal daytime" is set to 1000, so the "day" value returns to 0.
:{{IN|bedrock}}, when executing <code>/time set 1000</code>, the "internal daytime" is also set to 1000. But if now the "internal daytime" is 25001 (1 day + 1001 ticks), after executing <code>/time set day</code>, it won't become 1000 or 25000, since '''it only increases time''' when using {{cd|time: TimeSpec}}. In fact, it turns into 49000 (2 days + 1000 ticks), and the "day" value becomes 2. If now the "internal daytime" is 25000 (1 day + 1000 ticks), after executing <code>/time set day</code>, it remains unchanged.

==Examples==

* To set the time to 1,000: <code>time set 1000</code>
* To add one [[day]] to the world time: <code>time add 24000</code>
* To change/reset in-game day count to desired number: <code>time set <desired day number*24000+time of day in ticks></code>; to change day count to day 472 at noon (6000): <code>time set 11334000</code>
