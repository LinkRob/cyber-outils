'''1.20.32''' is a minor update to ''[[Bedrock Edition]]'' released on October 5, 2023, which fixes bugs. 

== Fixes ==
; 4 issues fixed
* Fixed “§” text modifiers overwriting text when next to a line break on iOS ({{bug|MCPE-174480}}).
* Fixed an issue that caused the keyboard to become unresponsive when placing multiple signs successively ({{bug|MCPE-175072}}).
* Buttons and some other non-full blocks once again prevent spiders and other mobs from spawning on them and on adjacent blocks ({{bug|MCPE-175119}}).
* Fixed purchased content not transferring to a Microsoft account when logging in for the first time.
