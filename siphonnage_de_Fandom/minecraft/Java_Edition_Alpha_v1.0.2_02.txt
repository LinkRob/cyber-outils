'''Alpha v1.0.2_02'''<ref>{{ytl|HMxp5YkobCo|Minecraft tour 1 July 6th|rswinteller|July 7, 2010}}</ref> is a version of [[Java Edition Alpha|Alpha]] released on July 6, 2010.

== Changes ==
=== Blocks ===
; [[File:Water JE11.gif|32px]] [[Water]]
* Flowing water will have its "level" data value directly set to 0 only if there is an opaque block or another water block down.

=== General ===
; Debug strings
* The game output log now prints a "Loading texture" (+ <web link>) string when the player's skin is loading.
