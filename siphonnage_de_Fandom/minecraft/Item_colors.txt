=== Item forms of colored blocks ===
The inventory color of the grass is calculated with {{cd|temperature:0.5}} and {{cd|rainfall:1.0}}. The result is {{cd|AdjTemp:0.5, AdjRainfall:0.5}}, We can get the color({{color|#7CBD6B}}) for the middle of center(x:127, y:127) of the {{cd|grass.png}}.

These are exclusive to ''Java Edition''; Bedrock Edition instead has pre-colored textures used for items, distinct from the textures actually used for blocks in placed form (see [[Bedrock Edition history of textures/Items]]).

=== Maps ===
{{section needed}}

The color value used is -12173266, adding 2<sup>24</sup> returns a value of 4603950, giving a map color of {{color|#46402E}}. This color is overlaid onto filled map item icons only.<!--- in older versions this was a texture, it was later changed between 1.6.4 and 1.12.2 on Java Edition--->

=== Dyed leather armor ===
[[File:DyeGraph3.png|thumb|Leather armor color codes]]
{{section needed}}

The default color is {{color|#A06540}} (Dec: 10511680). This is used for leather horse armor, and leather helmet, chestplate, leggings, and boots. Dyes return the same colors as [[Dyes#Color values]].

=== Firework stars ===
{{section needed}}

The default color is {{color|#8A8A8A}} (Dec: 9079434). When dyes are applied, the final color is different from that used for leather armor. They do not match one to one. {{info needed}}
