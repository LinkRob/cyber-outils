A version of [[Classic|Java Edition Classic]] was released on May 16, 2009, at 16:16 UTC,<ref>TigIRC logs: ''(12:16:34) notch: dock, fartron: There's a new version up. Reload the page''</ref> which made changes to mouse movement and fixed bugs.

== Changes ==
=== General ===
; General
* Pressing {{key|Y}} swaps the mouse Y-axis.<ref>TigIRC logs: ''(12:16:40) notch: 'Y' swaps the y axis on the mouse''</ref>
* Changed the mouse looking code.<ref>TigIRC logs: ''(12:16:48) notch: and the mouse look code is changed''</ref>

== Bugs ==
* Testers still reported issues with the mouse code.<ref>TigIRC logs: ''(12:19:06) dock: mouse look is better... but still slightly unpleasant ''</ref> This version also reportedly had texture issues,<ref>TigIRC logs: ''(12:18:41) fartron: i reloaded and now there are no textures''</ref><ref>TigIRC logs: ''(12:19:58) fartron: textures aren't loading for me''</ref> a broken mouse invert,<ref>TigIRC logs: ''(12:29:17) fartron: still white and still no invert..''</ref> and FPS drops when turning the camera.<ref>TigIRC logs: ''(12:23:05) dock: seems like it is running at <10fps rotation smoothness  when I rotate''</ref>
