'''Alpha v1.2.1'''<ref>[[wordofnotch:1486843146|Minecraft Alpha 1.2.1, Minecraft Server 0.2.3]] – The Word of Notch, November 5, 2010</ref> was a version of [[Alpha]] released on November 5, 2010, to fix bugs. Although the [[Minecraft Launcher|launcher]] claims to have this version available, the version listed is just a duplicate of [[Alpha v1.2.1_01]].<ref>{{bug|MCL-9282}}</ref>

== Changes ==
=== Blocks ===
; [[Leaves]]
* Particle colors now reflect the biome instead of having the grayscale texture.

=== Mobs ===
; Hostile mobs 
* Now only spawn at light level 7 or lower regardless of height, as they did before [[Alpha 1.2.0]].

=== General ===
* Music now plays on [[Multiplayer]]

== Fixes ==
; 3 bugs fixed
* Signs on the sides of cacti no longer crash the game.
* Optimized CPU usage for mob spawning.
* Music now plays in multiplayer.</onlyinclude>

== Trivia ==

* This is the only Alpha v1.2 version that is currently lost.
