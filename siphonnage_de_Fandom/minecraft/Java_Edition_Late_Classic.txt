'''Late Classic''' refers to seven versions of '''[[Classic]]''' released from October 27 to November 10, 2009. These versions are all in [[Creative]] mode, except for the Survival mode variant of [[Classic 0.30|0.30]], but Survival mode can be enabled in all versions by editing a line of <code>Minecraft.class</code> in <samp>[[minecraft.jar]]</samp>.

== Additions ==
;Building
*Left click removes blocks and right click places blocks.
*New blocks:
**[[Obsidian]]

;[[Multiplayer]]
*Players now push each other when standing next to each other.
*Opping or deopping a player makes changes instantaneously instead of having to reload.
*Players can build through other players.
*Player tags don't appear over other players unless the mouse is hovered over them.

;[[Option]]s
*Added rain toggle to options.
*Added tree growing switch to <samp>[[server.properties]]</samp>.

;General
*Re-added [[Creative]] mode.
*The ability to save levels locally as a .mine file.
