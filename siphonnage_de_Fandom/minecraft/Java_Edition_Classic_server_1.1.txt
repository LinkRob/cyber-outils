'''1.1'''<ref name=":0"/> was a [[Classic]] server version released with [[Classic 0.0.16a 01|0.0.16a_01]] on June 8, 2009.<ref>{{WON|120096050|New server up|June 8, 2009}}</ref>

== Additions ==
* Added server-side support for the {{cmd|say}} command.

== Changes ==
* Removed server-side support for the {{cmd|broadcast}} command as it was renamed to {{cmd|say}}.

== Fixes ==
* Fixed the "private" flag not working.
