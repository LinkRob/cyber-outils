The '''Bundles of Bravery''' is a game drop that features [[Bundle|Bundles]] and [[Hardcore]] mode for [[Bedrock Edition|Bedrock]] and Java Edition Realms. It was released on October 22, 2024. It was also announced at [[Minecraft Live 2024]].

== Additions ==
=== [[Game mode]]s ===
* [[Hardcore]] mode for [[Bedrock Edition|Bedrock]] and Java Edition Realms
** A new variant of [[Survival]] mode (after [[Adventure]] mode) in which the world is locked to the hardest difficulty.
** A [[player]] dies cannot respawn, but can continue on via [[Spectator]] mode.

=== Items ===
* [[Bundle]]
** Can be crafted using a [[string]] and a [[leather|piece of leather]].
** Can hold a mixed stack of items at a time.
** Can be dyed into 16 different colors.
** The specific item to be removed from a bundle can be selected using the scroll wheel.
** No longer experimental, but an item that is one of the longest to develop.
