A version of '''[[Indev 0.31]]''' was released on '''January 30, 2010''', at 1:22 UTC.<ref name="WoN 0130 release">[[wordofnotch:360469298|Phew, last indev update for today]] – The Word of Notch, January 30, 2010 1:22 UTC</ref>

== Additions ==
=== Blocks ===
; [[File:Crafting Table JE1 BE1.png|32px]] [[Workbench]]
* Pressing {{control|use}} on a workbench will open a 3×3 crafting grid.<ref group="note" name="gameplay">This has been verified by gameplay from this version's jar dated January 30, 2010, at 1:10 UTC.</ref>

=== Items ===
; [[File:Golden Sword JE1.png|32px]] [[File:Golden Axe JE1.png|32px]] [[File:Golden Pickaxe JE1.png|32px]] [[File:Golden Shovel JE1.png|32px]]
* Golden [[sword]]s, [[axe]]s, [[pickaxe]]s, and [[shovel]]s.<ref group="note" name="gameplay"/>

; [[File:Bowl JE1 BE1.png|32px]] [[Bowl]]
* Used to make mushroom stew.<ref name="WoN 0130 release"/><ref group="note" name="gameplay"/>

; [[File:Mushroom Stew JE1 BE1.png|32px]] [[Mushroom stew]]
* New food item.<ref name="WoN 0130 release" /><ref group="note" name="gameplay"/>
* Restores {{Health|8}} health.

; [[File:Gunpowder JE1 BE1.png|32px]] [[Gunpowder]]

; [[File:String JE1 BE1.png|32px]] [[String]]

; [[File:Feather JE1.png|32px]] [[Feather]]

=== Mobs ===
; [[File:Beast_Boy.png|32px]] [[Beast Boy]]
* Has {{hp|20}} HP
* No in-game animations.
* Drops 0-2 [[feather]]s when killed.<ref group="note" name="gameplay"/>

== Changes ==
=== Blocks ===
; [[File:Chest (S) JE1.png|32px]] [[Chest]]s
* Can now be crafted.<ref name="WoN 0130 release"/><ref group="note" name="gameplay"/>
; [[File:Smooth Stone Slab JE1 BE1.png|32px]] [[Stone slab]]s
* Can now be crafted.
; Plants
* Now display similarly to items in the inventory (just like today).

=== Items ===
* Animated textures (currently fire and gears) now display in the inventory.

=== Mobs ===
; [[File:Black_Steve.png|32px]] [[Black Steve]]
* Now drops 0-2 [[gunpowder]] when killed.<ref group="note" name="gameplay"/>

; [[File:Steve_(mob).png|32px]] [[Steve (mob)|Steve]]
* Now drops 0-2 [[string]] when killed.<ref group="note" name="gameplay"/>

=== World generation ===
* Removed all Indev House [[chest]]s.<ref group="note" name="gameplay"/>
* Re-added the Infinite Lava Sea at the bottom of the map.
** This time it is infinitely deep.

=== Gameplay ===
; [[Crafting]]
* There are now 36 recipes.<ref name="WoN 0130 release"/>
* Added 2×2 crafting grid to the player [[inventory]].<ref group="note" name="gameplay"/>
* Removed 3×3 inventory crafting grid by pressing {{key|b}}.<ref group="note" name="gameplay"/>
* Axes can now be crafted on either side.<ref group="note" name="axeleft">In the previous version's jar, dated January 29, 2010, at 14:04 UTC; in gameplay; axes could only be crafted with the two upper blocks/ingots/diamonds on the left. Starting with this version, dated January 30, 2010, at 1:10 UTC, axes could now be crafted with the upper blocks/ingots/diamonds facing either side.</ref>

=== General ===
; [[Score]]
* Removed the scoreboard in the top right of the screen.<ref group="note" name="gameplay"/>

; [[Statistics]]
* Player statistics are now removed from the inventory.<ref group="note" name="gameplay"/></onlyinclude>

== Fixes ==
; From 20100122
* Fixed an infinite reach bug.
; From 20100128
* Fixed graphical glitch with using swords.
; From 20100129
* Dropped stacks of items will now smelt as separate items (previously only 1 item would smelt and the rest disappeared).
* Right-clicking on stacked crafted items takes out all of them instead of just one.

== Bugs ==
* The number on hotbar items also pulses when new items are picked up.
* The x-ray effect caused by having the player's head in a block is now permanent as long as the player stays in a block.
* Bows disappear from the hotbar when {{control|used}} without arrows.
