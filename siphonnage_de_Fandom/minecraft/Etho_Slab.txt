The '''etho slab''' is a joke [[slab]] introduced exclusively in [[Java Edition 2.0]]. It is a reference to the YouTube channel [https://www.youtube.com/user/EthosLab EthosLab].

==Obtaining==
===Breaking===
Punching the block breaks it instantly and  drops in the item form.

===Crafting===
Etho slabs are crafted using 3 TNT blocks.
{{Crafting
|ignoreusage=1
|A2=TNT|B2=TNT|C2=TNT
|Output=Etho Slab,6
}}

== Usage ==

Etho slabs behave like [[TNT]] although there is a 25% chance to spawn a [[Anvil#Falling_anvils|falling anvil]] one block above the nearest player up to 20 blocks away.
