'''Alpha v1.2.0_02''' is a version released to fix a bug.

This version is duplicated inside the [[Minecraft Launcher|launcher]], as attempting to play [[Alpha v1.2.0]] will download and launch v1.2.0_02 instead.<ref>{{bug|MCL-1421}}</ref>

== Changes ==
* [[Soul sand]] generates in some of the positions previously taken by [[gravel]] in [[the Nether]].

== Fixes ==
; 1 bug fixed
* Items no longer disappear when the [[player]] dies.
