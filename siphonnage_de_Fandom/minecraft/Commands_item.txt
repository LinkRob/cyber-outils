Manipulate or copy [[item]]s in the [[Inventory|inventories]] of [[block]]s ([[chest]]s, [[furnace]]s, etc.) or [[entities]] ([[player]]s or [[mob]]s).

== Syntax ==
: <code>'''item modify''' (block <pos>|entity <targets>) <slot> <modifier></code>
:: Modifies the items in the specified slot with the specified modifier.
: <code>'''item replace''' (block <pos>|entity <targets>) <slot> '''with''' <item> [<count>]</code>
:: Replaces the items in the specified slot with the specified items.
: <code>'''item replace''' (block <pos>|entity <targets>) <slot> '''from''' (block <sourcePos>|entity <sourceTarget>) <sourceSlot> [<modifier>]</code>
:: Copies the source items to the target slot and optionally modifies it with the <code>modifier</code>.

== Arguments ==
{{argument|pos|block_pos}}
: Specifies the position of the block to be modified.
: {{arg desc|je=block_pos}}

{{argument|targets|entity}}
: Specifies one or more entities to modify.
: {{arg desc|je=entity|amount=multiple|type=entities}}

{{argument|slot|item_slot}}
: Specifies the inventory slot to be modified. Valid values depend on whether a block or an entity is being modified.
: {{arg desc|je=item_slot}}

{{argument|modifier|resource_location}}
: Specifies the [[Item modifier|item modifier]] to apply on the chosen item.
: {{arg desc|je=resource_location}}

{{argument|item|item_stack}}
: Specifies the item to be placed in the block or entity's inventory slot.
: {{arg desc|je=item_stack}}

{{argument|count|integer}}
: Specifies the number of items to be placed in the block or entity's inventory slot.
: {{arg desc|je=integer|min=1|max=64}}<!--unparseable if bigger than 64, failed if bigger than the max stack size-->

{{argument|sourcePos|block_pos}}
: Specifies the position of the block to copy items from.
: {{arg desc|je=block_pos}}

{{argument|sourceTarget|entity}}
: Specifies an entity to copy items from.
: {{arg desc|je=entity|amount=single}}

{{argument|sourceSlot|item_slot}}
: Specifies the inventory slot to copy the items from. Valid values depend on whether the source is block or an entity. See <code><slot></code> argument above for more information.

== Examples ==
* To replace the items in the bottom-right slot of a single chest two block above with four spruce saplings:
** <code>/item replace block ~ ~2 ~ container.26 with minecraft:spruce_sapling 4</code>
* To replace the items in the rightmost hotbar slot of the nearest player with four spruce saplings:
** <code>/item replace entity @p hotbar.8 with minecraft:spruce_sapling 4</code>
* To replace the item in the offhand of the selected player with the item in their main hand:
** <code>/item replace entity @s weapon.offhand from entity @s weapon.mainhand</code>
* To put a brown [[banner]] on a player's head
** <code>/item replace entity @s armor.head with minecraft:brown_banner</code>
* To increase the count of the item in your main hand:
** <code>/item modify entity @s weapon.mainhand example:increase_count</code>
** file in a datapack: <code>data/example/item_modifiers/increase_count.json</code><syntaxhighlight lang="json">{
  "function": "minecraft:set_count",
  "count": 1,
  "add": true
}</syntaxhighlight>
