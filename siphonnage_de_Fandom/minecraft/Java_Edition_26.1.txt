'''Java Edition 26.1''', named [[Tiny Takeover]], is a game drop for [[Java Edition]], released on March 24, 2026. It is the first version to use the new YY.D.H version format and the first to require Java 25.

== Additions ==
=== Blocks ===
* [[Golden Dandelion]]
** A new decoration block which can be planted on [[flower pot]]s like other [[flower]]s do.
** Can be crafted with a [[dandelion]] surrounded by 8 [[gold nugget]]s.
** Can be used to feed most baby mobs, which will prevent them from ageing.
*** It will age again when fed on again.
** Can be used to craft [[yellow dye]]s and [[Suspicious Stew|Saturation suspicious stews]].

== Changes ==
=== Blocks ===
* [[Note Block]]
** Added a new trumpet sound.
*** Plays when placed on top of a [[Copper|copper block]].
*** Its oxidation stages make different sounds.

** Can now be crafted with any [[nugget]] and [[paper]].
