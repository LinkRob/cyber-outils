'''Beta 1.1_02''' is a version of [[Java Edition Beta]] released on December 22, 2010,<ref>{{tweet|notch|17569425494376449|groooan, updated to 1.1_02, mandatory for client and server, fixing the container not opening with empty hands bug|December 22, 2010}}</ref> to fix a bug with [[chest]]s in [[Beta 1.1_01]].

== Changes ==
=== Blocks ===
; [[Chest]]
* It now opens even if the [[player]]'s hand is empty when trying to open it.

== Fixes ==
;1 bug fixed
* Fixed a bug where chests would not open if the player's hand was empty.

== Trivia ==
* This is the final version of Minecraft released in 2010.
