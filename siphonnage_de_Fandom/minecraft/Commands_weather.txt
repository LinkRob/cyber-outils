Sets the [[weather]]. {{IN|bedrock}}, it can also output current weather.

==Syntax==

* '''Java Edition'''
: <code>weather (clear|rain|thunder) [<duration>]</code>

* '''Bedrock Edition'''
: <code>weather <nowiki><clear|rain|thunder></nowiki> [duration: int]</code>
: <code>weather query</code>

==Arguments==

<code>clear|rain|thunder</code>
:* <code>clear</code> – Set the weather to clear.
:* <code>rain</code> – Set the weather to [[rain]] (or [[snowfall]] in cold [[biomes]]).
:* <code>thunder</code> – Set the weather to a [[thunderstorm]] (or blizzard in cold biomes).
{{argument|duration|time|duration: int|int}}
: Specifies the time for the specified weather to last.
: {{IN|java}}, if not specified, resets the game's regular weather cycle.
: {{IN|bedrock}}, the time is specified in game ticks. If not specified or 0, the duration defaults to a random value between 300 seconds and 900 seconds.
: {{arg desc|je=time|min=1|be=int}} And it should be between 0 and 1000000 (inclusive).

==Examples==

* To get clear weather for one ''Minecraft'' day: /<code>weather clear 24000</code>

* To make it rain, but let it end at its own pace: /<code>weather rain</code>
