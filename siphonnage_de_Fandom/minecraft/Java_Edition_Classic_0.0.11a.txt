'''0.0.11a'''<ref>[https://www.youtube.com/watch?v=lZn60uMgE2A Lost Minecraft castle video]</ref> was a version of [[Java Edition Classic]] released on May 17, 2009,<ref name=WON>[[wordofnotch:109000107|"Minecraft 0.0.11a for public consumption"]] – The Word of Notch, May 17, 2009</ref> at 11:56 UTC,<ref>[[#lwjgl logs| LWJGL IRC Logs]]: "''[13:56:55] <Notch_> ok, it's up. 0.0.11a''" (11:56 UTC)</ref> almost 4 minutes after the release of [[0.0.10a]] to fix the game being unplayable.

While there is a version called "c0.0.11a" in the launcher, it is actually an early [[Java Edition Classic 0.0.12a/Development|development version of 0.0.12a]]; although labeled "0.0.11a" in-game, it contains files from May 18, 2009 (a day later than the release of this version), and has early multiplayer code present.

This was the first public version of ''Minecraft'',<ref name=WON/> posted on the TIGSource Forum labeled '''Minecraft (alpha)'''.<ref>{{citation|url=https://forums.tigsource.com/index.php?topic=6273.0|title=Minecraft (alpha)|website=TIGSource|author=[[Markus Persson]]|date=May 17, 2009}}</ref>

== Fixes ==
; 1 bug fixed
* Fixed an issue with start and destroy functions making the game unplayable.<ref>[[#lwjgl logs|LWJGL IRC logs]]: "''[13:53:34] <Notch_> I forgot to take out the normal start() and destroy()..''" (11:53 UTC)</ref>

== Trivia ==
* This version was used to mark the 10 years anniversary of Minecraft.
* This version was referenced in this official Minecraft YouTube video  [https://www.youtube.com/watch?v=LMCt-gSvEqU here].
