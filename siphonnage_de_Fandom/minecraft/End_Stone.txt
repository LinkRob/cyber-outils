'''End stone''' is a block that appears in [[the End]] and, apart from generated structures, makes up all of the solid ground that exists in that dimension.

== Obtaining ==
=== Breaking ===
End stone can be obtained using any [[pickaxe]]. If mined without a pickaxe, it drops nothing.
{{breaking row|horizontal=1|End Stone|Pickaxe|Wood}}

=== Natural generation ===
[[File:TheEnd.png|300px|thumb|right|A large island consisting entirely of end stone.]]

End stone is found only in [[the End]], where it makes up all the floating islands that generate in the dimension.

=== Post-generation ===
==== Exit portal ====
The 16 end stone blocks under the edge of the [[exit portal]] are replaced when the [[ender dragon]] is respawned, and again when it is killed. Because [[end crystal]]s, which are used to respawn the dragon, are renewable, this does make end stone renewable.

[[End gateway]]s generate a small floating island of end stone when an entity travels through, for the entity to land on if there are no valid locations.{{verify|Only confirmed in Bedrock Edition}}

If an exit portal exists at a different position from the world origin (for example, an old exit portal from before 1.9), it will be completely converted into end stone if the ender dragon is re-summoned.

== Usage ==
End stone has a [[blast resistance]] of 9, which is 3 more than that of ordinary [[stone]]. This is the highest blast resistance of any block movable by pistons besides [[anvil|anvils]]{{only|BE}}, [[ancient debris]] and [[block of netherite]]. It also cannot be picked up by [[endermen]] and cannot be destroyed by the [[ender dragon]]. In addition, it is the only block on which [[chorus flower]]s can be planted.

=== Note Blocks ===
End stone can be placed under [[note block]]s to produce "bass drum" sound.

=== Sculk Catalyst Interactons ===
This block can be replaced by sculk both upon world generation and from a Sculk Catalyst. This is the only block that is both replaceable with Sculk AND cannot be destroyed by the Ender Dragon.
