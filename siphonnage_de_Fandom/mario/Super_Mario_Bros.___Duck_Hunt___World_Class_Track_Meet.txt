'''''Super Mario Bros. / Duck Hunt / World Class Track Meet''''' is a compilation title for the [[Nintendo Entertainment System]], released exclusively in North America in 1990, where it was bundled with the NES Power Set. The game is an enhancement of the ''[[Super Mario Bros. / Duck Hunt]]'' cartridge, as it not only includes ''[[Super Mario Bros.]]'' and ''[[w:c:nintendo:Duck Hunt|Duck Hunt]]'' but also ''[[w:c:nintendo:World Class Track Meet|World Class Track Meet]]''. The player can select any of the three games upon booting on the system, but to select another game, they have to reset the game.

The NES Power Set in general is an upgrade over the NES Action Set, which the first ''Super Mario Bros. / Duck Hunt'' was bundled with, because aside from an NES Zapper for ''Duck Hunt'', the NES Power Set also includes a [[w:c:nintendo:Power Pad|Power Pad]] for ''World Class Track Meet''.
