'''Clash of Captains''' is a [[Captain Command]] in the ''[[Minion Quest: The Search for Bowser]]'' campaign in ''[[Mario & Luigi: Superstar Saga + Bowser's Minions]]''.

== Description ==
If the user uses Clash of Captains, they face off against the enemy captain in a 1v1. The user also takes some damage from every enemy, besides the enemy captain, that is still in the battle. After using Clash of Captains, the user cannot use any Captain Commands for the rest of the battle.

== Flavor text ==
* In-game description: ''Exclusive to Goombas. A showdown with the opposing captain. Be mindful of the damage that will be taken from enemies along the way!''
