'''''Donkey Kong Country Returns 3D''''' is a ''[[Donkey Kong Country (series)|Donkey Kong Country]]'' game released for the [[Nintendo 3DS]] in 2013. It is a [[reissue|remake]] of ''[[Donkey Kong Country Returns]]'' for the [[Wii]].

== Plot ==
{{Main|Donkey Kong Country Returns#plot}}

==Development==
This game was announced at Nintendo Direct on February 14, 2013. This game has the same plot and storyline as the Wii version, but with new levels and the beginner-friendly New Mode where DK and Diddy have 3 Hearts, and there are more items to buy for a cheaper price. 

==Differences and changes==

===Gameplay changes=== 

*The port features a New Mode which: 
**Adds an additional heart to the life meter, providing three hearts in the normal game, and two in Mirror Mode.
***However, despite offering an extra heart, Mirror Mode still removes all the hearts from every level, preventing the player from recovering any damage.
*Adds additional items in [[Cranky Kong's Shop]], including the [[Red Balloon|Green Balloon]], [[Crash Guard]], and [[DK Barrel]].
*The prices are lowered for the other items in Cranky Kong's Shop:
**1 [[Red Balloon]] costs two [[Banana Coin|Banana Coins]] each instead of three, 3 Red Balloons cost five Banana Coins each instead of seven, and 7 Red Balloons cost ten Banana Coins each instead of fifteen.
**[[Map Key|Map Keys]] cost ten Banana Coins each instead of twenty.
**[[Banana Juice]] costs seven Banana Coins each instead of twenty.
**[[Heart Boost|Heart Boosts]] cost three Banana Coins each instead of ten.
**[[Squawks the Parrot|Squawks]] costs five Banana Coins each instead of fifteen.
*Up to three items can be used in one level.
**Banana Juice only protects against five hits instead of ten, because of the raised item limit.
