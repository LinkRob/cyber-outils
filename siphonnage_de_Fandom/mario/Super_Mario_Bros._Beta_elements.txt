This article pertains to the beta elements from ''[[Super Mario Bros.]]''

== Unused objects ==
=== Climbable Object ===
A climbable object Mario can use to go up and down, like the vines. It makes a "buzzing" sound as the player climbs it as though Mario is repeatedly hitting his head on something
[[File:SuperMarioBrosBrownBall.png|thumb]]

=== Unused Fire Bar Type ===
A short Fire Bar that quickly rotates counterclockwise. This type is never used in any valid levels, however; its clockwise counterpart <code>'''1C'''</code> is used only in World 5-4. The settings are stored in this order: Clockwise ('''1B'''), Speedy Clockwise ('''1C'''), Counterclockwise ('''1D'''), Speedy Counterclockwise ('''1E'''), and Long Firebar ('''1F'''). Fire Bar ('''1E''') has both the faster speed ('''$38''') and counterclockwise rotation ('''$10''').

== Miscellaneous ==
=== Unused Variable ===
RAM address '''03F0''' keeps track of the number of blocks hit. However no routine ever reads the value stored here.

=== Unused Pointer ===
Worlds 2-2 and 7-2 have a third level pointer for World 3, which leads to the same place as the normal World 2 and World 7 level pointers do.

=== Duplicated Scroll Stop Object ===
There's two identical scroll stop objects: '''46''' and '''47'''. Only the latter is used by the game's valid levels.

=== Removed Tiles ===
The bricks and Bowser's bridge may have each used four unique tiles at some point in development, judging by the arrangement of existing tiles. The second and fourth tiles in each highlighted group are pieces of the block behind the title logo.
