The '''Security Thwomp''' is a colossal [[Thwomp]] variant featured in ''[[Super Princess Peach]]''.

== Profile ==
=== Physical description ===
Security Thwomp is a Thwomp the size of the rooms.

=== Behavior ===
[[File:Security Thwomp Caught.png|The Security Thwomp has caught Peach and Perry breaking in.|thumb|left||200px]]
The Security Thwomp is found in different rooms, sleeping. When it wakes up, Peach must mimic the pose of the statue. If she does not, the Security Thwomp swallows Peach and returns her back to the starting point.
{{clrl}}
== In ''Super Princess Peach'' ==
[[File:Security Thwomp Asleep.png|thumb|200px|The Security Thwomp is asleep.]]
The Security Thwomp is found in certain rooms of [[Bowser's Villa]]. When [[Princess Peach|Peach]] enters the room, the Security Thwomp is seen sleeping, but every so often, it will wake up and make sure no intruders are inside the room at this point, effectively freezing time in the room as it searches the room, Peach will need to hide behind the room's statues and do exactly what the statues are doing (either stand still, duck, or jump). If Peach is caught, the Security Thwomp will open it's large mouth and swallow both her and [[Perry]] forcing them back at the room's start. Any enemies killed in the room will respawn after this, but items collected won't. This doesn't deduct any health, but it does get repetitive. If Peach isn't caught, the Security Thwomp will go back to sleep, allowing Peach to continue onward until it wakes up again, at which point Peach will have to hide again. There is no way to destroy the Security Thwomp (mainly because it is in the background on the wall). The only thing that can be done is to reach the end without being caught. Security Thwomps are found in 8-1, 8-3, and 8-5.

== Trivia ==
* Given that its size taking up the walls, the Security Thwomp is the largest Thwomp, even more than the [[Super Thwomp]].
