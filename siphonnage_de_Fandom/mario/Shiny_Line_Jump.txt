'''Shiny Line Jump''' is a [[Stickers#Battle Stickers|Battle Sticker]] in ''[[Paper Mario: Sticker Star]]''. These stickers are more powerful variants of the [[Line Jump]] sticker, and allow [[Mario]] to attack all enemies on-screen with repeating jump attacks.

== Description ==
=== Physical description ===
Shiny Line Jump stickers are very similar to regular Line Jump stickers except for the silver background and the shiny blue boot. It also only takes up one space in the [[Sticker Album]].
