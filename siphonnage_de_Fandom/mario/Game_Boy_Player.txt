The '''Game Boy Player''' is an accessory for the [[Nintendo GameCube]] that allows for [[Game Boy]], [[Game Boy Color]], and [[Game Boy Advance]] cartridges to be played on the system. It was originally released in 2003. The Game Boy Player is the successor of the [[Super Game Boy]], which allows for Game Boy games to be played on the [[Super Nintendo Entertainment System]]. An extended purpose of both the Game Boy Player and Super Game Boy is being able to play the game from a television screen.

Games with tilt functionality built into their cartridge not made for normal play on the Game Boy Player. Two of the games with tilt functionality are ''[[Mario (franchise)|Mario]]''-related, ''[[WarioWare: Twisted!]]'' and ''[[Yoshi Topsy-Turvy]]''. The reason for this is that playing them would require the entire system to be rotated due to the cartridge's motion sensors, something that the Nintendo GameCube was not designed for.

A few Game Boy Advance games received optimizations if played on a Game Boy Player, mainly from added rumble support. These games display the Game Boy Player logo upon being booted, regardless of whether it is being played on the Game Boy Player or some other device. Two ''Mario'' games were optimized for the Game Boy Player, ''[[Super Mario Advance 4: Super Mario Bros. 3]]'' and ''[[Mario & Luigi: Superstar Saga]]''.
