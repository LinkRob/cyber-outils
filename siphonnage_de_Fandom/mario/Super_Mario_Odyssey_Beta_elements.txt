== Unused Codes ==

=== E3 Leftovers ===
There are a few classes in the game's code that reference E3 Demo of the game. There is a sequence director that tells the game which sequence to load: the main game (under the name "'''Hakoniwa'''"), or the E3 sequence (under the name "'''E3Sequence'''"). However, the game passes the former instead of the latter as the resource loader would load the resources that are used in the [[Sand Kingdom]] and the [[Metro Kingdom|Metro Kingdom.]]

It is theoretically possible to force the game to load this sequence by changing the string passed to '''SequenceFactory::createSequence(char const *sequenceName)'''. However, loading this will fail due to it trying to load the layouts from the E3 File Text and creating these with the needed panes are necessary to fix this problem.

=== Version Display ===
[[File:Super-Mario-Odyssey-Version-Display.png|left|thumb|Shows the Version 1.0, displayed on the top-right of the menu screen.]]
There is a (functionally) having an unused layout called "'''MenuRight'''". It contains a pane named ''''TxtVersion'''<nowiki/>', which is displayed in the top-right corner of the game select screen with the placeholder text "'''Ver.1.0'''.". In 1.0.0 of ''[[Super Mario Odyssey]]'', if the game's version didn't match 1.0.0 (which is impossible without editing the game's metadata), the game would display whatever the version is in this pane, in the format ("'''x.x.x'''"). In 1.0.1, the code was changed so that the pane would not be displayed, no matter what version the game is on

== Unused Area ==
In the Metro Kingdom, there is a room with a 2D section and a music note that (when collected) makes a group of them appear for Mario to collect in both 2D and 3D. This area has a second mirrored copy of the room stored just off-screen, which cannot be seen without hacking and appears to serve no purpose in the final game

== Unused Moon ==
Originally, the tracing game in the Moon Kingdom was going to be in the shape of a star, but in the final it was a circle. It was most likely scrapped because of it's difficultly of getting 90 points almost impossible to obtain.
