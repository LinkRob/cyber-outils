The '''Captain Event Space''' is a type of [[space]] which appears in ''[[Mario Party 9]]''.

==Description==
Landing on a Captain Event Space triggers a [[Captain Event]], which differs between each board. A Captain Event Space is automatically landed on, regardless of how many Spaces the characters have left to move. Most boards have only one Captain Event Space.

In ''[[Mario Party: Island Tour]]'' and ''[[Mario Party 10]]'', the Captain Event Space is replaced with the functionally-identical [[Special Event Space]].

In Bowser Station, Bowser Jr. and Bowser often come, interfering with the players.
