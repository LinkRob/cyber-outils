'''Arrow Blocks''' are an object in ''[[Wario World]]''.

==Description==
Arrow Blocks are gray metal blocks found inside certain [[Trapdoor (Wario World)|trapdoor]] sub-levels. Every side of an Arrow Block has four red arrows, each pointing in one of the cardinal directions. If an Arrow Block is punched by [[Wario]], it moves straightforward until hitting a wall, upon which the Arrow Blocks stops moving. If one Arrow Block hits another, the other Arrow Block begins to move instead, potentially resulting in a chain reaction of several Arrow Blocks. If Wario [[Ground Pound (move)|ground-pounds]] an Arrow Block, it begins to move downward.

Arrow Blocks are generally used as platforms to help Wario reach ledges with [[red diamond]]s and [[Gold Statue]] pieces that he cannot reach otherwise.
