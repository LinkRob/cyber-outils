A '''Challenge Area''' is a type of [[space]] in ''[[Mario Party: Island Tour]]''.

== Description ==
A Challenge Area involves players must stop moving to face a challenge, functioning similarly to a [[Special Event Space|Dead-End Space]] at the end of the board. The type of challenge of a Challenge Area differs depending on which board it is found. A Challenge Area only appears in the [[Perilous Palace Path]] and [[Bowser's Peculiar Peak]] boards.

==In ''Mario Party: Island Tour''==
In Perilous Palace Path, the Challenge Area has a [[Thwomp]] blocking the path, and in front of it are three switches, colored pink, blue, and green respectively. Only one of them lowers the bridge, which is randomized each time the board is played on. Once the character selects a switch, they [[Ground Pound (move)|Ground Pound]] it. If it is the correct switch, the bridge is lowered, but if it is not the correct switch, an animation is shown in which the bridge lowers only partway before moving back to its upright position, then the Thwomp falls down to squish the character. Once a switch is used, it cannot be used again during the current playthrough of the board.

In Bowser's Peculiar Peak, the character has to select either a red fuse or a blue fuse, only one of which breaks the wall obstructing the remaining path to [[Bowser]]. Similarly to the switches of Perilous Palace Path, the function of each fuse is randomized whenever the board is played on, and both fuses can only be used while playing through Bowser's Peculiar Peak.
