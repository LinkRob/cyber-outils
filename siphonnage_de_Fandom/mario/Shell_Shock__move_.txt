'''Shell Shock''' is a [[Captain Command]] in the ''[[Minion Quest: The Search for Bowser]]'' campaign in ''[[Mario & Luigi: Superstar Saga + Bowser's Minions]]''.

== Description ==
If a character uses Shell Shock, then they will attack any enemies that are attacking them. To be able to use Shell Shock, the character must have at least one enemy focused on them. Shell Shock can not be used to hit flying troops.

== Flavor text ==
* In-game description: "Exclusive to Koopa Troopas. A spinning shell attack! Damages all nearby foes.
