The '''Game Boy Camera''', known as '''Pocket Camera''' (ポケットカメラ, ''Poketto Kamera'') in Japan, is an accessory for the [[Game Boy]]. Its main feature is that it allows the user to take up to 30 grainy monochrome pictures, which can be viewed and customized using the built-in software. There is also the option to print the photographs using the [[Game Boy Printer]].

Several regional differences exist between the Game Boy Camera's Japanese and international versions, including the banners and graphics, a lot of which are ''Mario''-related. The Japanese version is compatible with two ''[[Mario (franchise)|Mario]]'' games, ''[[Mario Artist: Paint Studio]]'' and ''[[Mario Artist: Talent Studio]]''.
