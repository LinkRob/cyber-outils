'''Match Faker''', titled '''Hide and Sketch''' in European and Australian releases, is a General [[minigame]] in ''[[Mario Party: Island Tour]]''.

==Layout==
The top screen depicts a wooden board with twelve tiles, and behind it is a forest. Each of the board tiles depicts a different ''[[Mario (franchise)|Mario]]'' enemy or species. The Touch Screen features a light green paper sheet depicting a very faint [[emblem]] of the player's character.

==Gameplay==
For the first fifteen seconds, the characters have to observe the ''Mario'' enemies and species on each and use the Touch Screen to quickly take notes on the order in which they appear. After the fifteen seconds, the tiles flip over. Using the Touch Screen beforehand is optional, but it gives each player the option to write down mnemonics for memorizing what each tile depicts.

The next part of Match Faker features three rounds. A round starts by selecting a random enemy or species, and the characters are instructed to find and select the tile depicting it. Any character who selects the correct tile earns a [[point]] for that round. When the round is completed, the next one begins, following the same procedure as before. After the three rounds are completed, the game determines the winner by whoever has the most points, the highest of which can be three because the minigame has the same number of rounds.

==Controls==
*{{button|3ds|Stylus}}: Draw sketch
*{{button|3ds|Stick}}: Move cursor
*{{button|3ds|A}}: Confirm

==Flavor text==
*'''Rules''' (American English): ''Take notes with the stylus to help remember the order of the tiles. Then select the tile you think matches the selected enemy.''
*'''Rules''' (British English): ''Draw sketches to remind you where each creature is, then try to point them out.''

==Trivia==
*The American name derives from "matchmaker", while the British name is a portmanteau of the game {{w|hide-and-seek}} and "sketch."
