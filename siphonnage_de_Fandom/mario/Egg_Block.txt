'''Egg Blocks''' are a type of object featured in the ''[[Yoshi (franchise)|Yoshi]]'' platforming games. If hit from below, Egg Blocks release [[Yoshi Egg]]s for the [[Yoshi (species)|Yoshis]] to use. Egg Blocks first appear in ''[[Super Mario World 2: Yoshi's Island]]''. Egg Blocks have the same spotted pattern as a Yoshi Egg, with green also being the default color of their spots.

==In ''Super Mario World 2: Yoshi's Island''==
Egg Blocks are usually located before an area requiring the Yoshi to use the eggs. Given that a Yoshi can only carry up to six eggs, the Egg Blocks do not release any more eggs once the Yoshi has six. There are also yellow, red, and flashing Egg Blocks, which are slightly different in that they themselves turn into a single type of egg upon being hit—a [[Yellow Egg]], a [[Red Egg]], and a [[Flashing Egg]], respectively. An Egg Block can be stood on as a platform.

[[Egg Plant]]s serve a similar purpose in that they release eggs for a Yoshi to use, although the main difference is that an Egg Plant shoots out eggs automatically.

==In ''[[Yoshi's Story]]''==
Egg Blocks serve a similar purpose, although their spots are now the same color as the current Yoshi in play.
