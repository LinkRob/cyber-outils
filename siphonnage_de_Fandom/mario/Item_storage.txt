'''Item storage''', also named '''Item Stock''', is a gameplay feature in a few games of the {{series|Super Mario}}. It first appears in ''[[Super Mario World]]''.

== Description ==
The item storage allows [[Mario]], [[Luigi]], or another playable character to keep an extra item in reserve to use within a [[level]].
