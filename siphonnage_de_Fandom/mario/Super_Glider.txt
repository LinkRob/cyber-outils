The '''Super Glider''' is the default [[glide]]r in ''[[Mario Kart 7]]'', ''[[Mario Kart 8]]'' and ''[[Mario Kart 8 Deluxe]]''.

== Description ==
The Super Glider is the standard glider. Hence the name, it does not boost stats, as all stat boosts are set to 0. Its color scheme changes depending on which character is using it.

== ''Mario Kart 7'' ==
The Super Glider debuted in ''[[Mario Kart 7]]''. It has no stat boosts, but its color varies depending on the driver. There are two emblems on each half of the glider.

== ''Mario Kart 8'' and ''Mario Kart 8 Deluxe'' ==
[[File:SuperGliderMK8.png|thumb|150px|right|Mario's Super Glider as it appears in ''Mario Kart 8'' and ''Mario Kart 8 Deluxe''.]]
The Super Glider appears in ''[[Mario Kart 8]]'' and ''[[Mario Kart 8 Deluxe]]''. It does not boost stats, but it changes the color depending on who is using the glider. Instead of the character's emblem, it has the "8" instead.

== ''Mario Kart Tour'' ==
In ''[[Mario Kart Tour]]'', the Super Glider does not have stat boosts. It does not have an emblem, but a blank circle.
