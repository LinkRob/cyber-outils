'''Charge P''' is a [[badge]] which appears in ''[[Paper Mario: The Thousand-Year Door]]''.

==Effects==
Equipping the badge allows [[Mario]]'s partners to use a "charge" attack to give them an extra point to their next attack; this effect is stackable with multiple uses of the "charge" attack. Mario can equip this badge by using one [[Badge Point|BP]].

This badge is found inside of the [[Glitz Pit]]. Inside of the storage room, Mario can use [[Flurrie]] to move the boxes. Behind one of these boxes is this badge.
