A '''Yoshi Cloud''' is an object which only appears in ''[[Super Mario World]]'' and its [[reissue|remake]] ''[[Super Mario World: Super Mario Advance 2]]''. It has a smiling face, similar to a [[Lakitu's Cloud]], although the smile is colored red.

A Yoshi Cloud only appears if [[Yoshi]] eats two [[Pink Berry|Pink Berries]] in the same [[level]]. In doing so, Yoshi lays an [[Yoshi Egg|egg]] from which a Yoshi Cloud appears. It releases ten [[Bonus Coin]]s, one at a time, for [[Mario]] or [[Luigi]] to collect. If either brother has collected each Bonus Coin, the Yoshi Cloud rewards them with a [[1-Up Mushroom]].
