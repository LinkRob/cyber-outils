'''Mario Brothers''' is one of [[9-Volt]]'s [[microgame]]s in ''[[WarioWare: Twisted!]]''. It is set within the game with the similar name, ''[[Mario Bros. (game)|Mario Bros.]]''

== Gameplay ==
The goal of this game is for the player to get the shell to face right side up before [[Mario]]  or [[Luigi]] kicks it. In order to do that, the player needs to tilt the system to get the shell to roll and rise upward. There are three levels, with each featuring a shell of a different enemy.
* '''Level 1''' – This level features a green [[Koopa Troopa]], which is easy to get up.
* '''Level 2''' – This level features a red Koopa Troopa, which is harder to get up.
* '''Level 3''' – This level features a [[Buzzy Beetle]], which is just as hard to get up as the previous one, plus the player must watch [[Luigi]]'s moves.

== Nomenclature ==
* In Portuguese, this game's name is called ''Vire o casco'', meaning "Turn the shell".
