'''Touchstones''', also named '''Touch Screen Platforms''' and '''rainbow-colored blocks''', are a type of object which first appear in ''[[Super Mario 3D World]]''.

==Description==
Touchstones are a type of movable [[platform]] that can be temporarily moved to a set position. The player can do this by using the [[Wii U GamePad]] in the original ''Super Mario 3D World'' and ''[[Captain Toad: Treasure Tracker]]'' releases. For the games' respective [[Nintendo Switch]] versions, Touchstones can be activated using either the Nintendo Switch's touch screen in handheld mode, the {{button|ns|r}} button while using dual Joy-Con or a Pro Controller, or the {{button|ns|SR}} button while using single Joy-Con, as all of these methods summon the touch cursor. A Touchstone returns to its original position after being tapped a second time or after a set period of time.

In ''Super Mario 3D World'', Touchstones are colored purple, but in ''Captain Toad: Treasure Tracker'', they appear in a variety of colors.

==In ''Super Mario 3D World'' / ''[[Super Mario 3D World + Bowser's Fury]]''==
Touchstones only appear in three levels, two of which feature [[Captain Toad]] as the playable character, [[Puffprod Peaks]], [[Captain Toad Plays Peek-a-Boo]] and [[Captain Toad's Fiery Finale]].

==In ''Captain Toad: Treasure Tracker''==
Touchstones appear in more [[level]]s, and they first appear in [[Touchstone Trouble]], where they are the main feature.

==In ''[[WarioWare: Get It Together!]]''==
Touchstones appear in the [[microgame]] [[Captain Toad: Treasure Tracker (microgame)|Captain Toad: Treasure Tracker]], based on the game of the same name. The player's object for the microgame is to push a Touchstone to create a slope for Captain Toad to walk on so that he can get to a [[Power Star]]. If the player pushes the wrong Touchstone, Captain Toad is blocked from being able to get to the Power Star.
