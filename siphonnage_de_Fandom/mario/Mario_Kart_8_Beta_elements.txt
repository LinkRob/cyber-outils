This article pertains the beta elements of ''[[Mario Kart 8]]''.

== Unused Courses ==

=== Test ===
A copy of [[Mario Circuit]] from the Flower Cup, but without music. Additionally, the orange arrow signs are not animated. According to interviews, Mario Circuit was the first track designed for the game, so this is very likely intended for testing (as the name suggests otherwise).<gallery>
File:MK8 Unanimated ArrowSigns 1.png
File:MK8 Unanimated ArrowSigns 2.png
</gallery>

=== ReservedXX ===
Unused tracks (found in IDs '''0x02''' to '''0x0F''') where '''XX''' is a number (starting at '''01''') going upwards. The game crashes upon loading it.

=== UnderConstructionXX ===
More unused tracks (found in IDs '''0x30''' to '''0x4F'''). It is similar to '''ReservedXX''', where the '''XX''' is a number (starting at '''01'''). They also crash upon loading it. If DLC packs 1+2 are downloaded to the game, IDs '''0x30''' to '''0x42''' will load the DLC tracks. However, '''0x43''' to '''0x4F''' will still result in the game crashing.

== Unused/Test Items ==

=== Test Items ===
In the item slot table file ('''ItemSlotTable.byaml'''), there are two test items (Test3 and Test4) which were obviously used for testing purposes. These items were most likely holdovers (serving the same lack of purpose) as the same-name items in ''Mario Kart 7''.

=== Lucky Seven Leftover ===
In the item slot table file ('''ItemSlotTable.byaml'''), there is an item named '''Seven'''. It could just be a leftover for testing the [[Crazy Eight]] during development of the game (as both that and [[Lucky Seven]] at basically the same thing) and they simply forgot to change the name.

=== Fake Item Box and Super Leaf Leftover ===
In the file '''RaceLogData.exbin''', there appears a two text strings called ('''FakeBox''' and '''Tail'''). Since they are only referred into that file, this can assume that they were cut it very early in development of the game.
