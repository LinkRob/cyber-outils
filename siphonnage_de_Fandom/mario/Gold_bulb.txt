'''Gold bulbs''' are an object in ''[[Luigi's Mansion: Dark Moon]]''.

==Description==
A gold bulb functions identically to a regular [[bulb]], except when [[Luigi]] uses a gold bulb, [[coin]]s temporarily appear in a set path, and if Luigi collects every coin in a set time, he earns a reward.
