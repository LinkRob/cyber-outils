A '''Bronze Dice Block''' is a recurring [[Dice Block]] in the {{series|Mario Party}}. It first appears in ''[[Mario Party: Island Tour]]'' and returns in ''[[Mario Party: Star Rush]]'', and Bronze Dice Blocks function differently between both games.

==In {{series|Mario Party}}==
===''Mario Party: Island Tour''===
A Bronze Dice Block is a type of Bonus Dice Block obtained by whoever finishes a minigame for Bonus Dice Blocks in third place in [[Perilous Palace Path]] or second place in [[Bowser's Peculiar Peak]]. When a character uses a Bronze Dice Block, they can to roll the Bronze Dice Block alongside the regular Dice Block, with the Bronze Dice Block adding either one or two to the total number rolled, depending on which side the Bronze Dice Block lands on.

===''Mario Party: Star Rush''===
The Bronze Dice Block only appears when [[amiibo]] are used. If an amiibo has save data from ''[[Mario Party 10]]'' and the game detects a [[Bronze Token]] before starting [[Toad Scramble]], [[Balloon Bash]], or [[Mario Shuffle]], then a Bronze Dice Block is added as an item at the start of the game. The Bronze Dice Block in particular can roll either a 2, 3, 4, 5, 6, or a 7.
