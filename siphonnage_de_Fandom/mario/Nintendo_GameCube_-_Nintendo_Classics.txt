'''Nintendo GameCube - Nintendo Classics''' is an application released for the Nintendo Switch 2. It features a library of Nintendo GameCube games, with some supporting online multiplayer. The application was announced in a Nintendo Direct on April 2, 2025 and released with the launch of the Nintendo Switch 2 on June 5, 2025 for most regions; it was later released on September 9, 2025 in Taiwan, and in Singapore, Malaysia, and Thailand on November 18, 2025. It is exclusive to active Nintendo Switch Online + Expansion Pack subscribers.

== Default button mapping ==
If a Nintendo GameCube controller for the Nintendo Switch 2 is connected, the main menu's sound effects are replaced by those from ''Super Mario Sunshine''. Using an original GameCube controller with the [[Nintendo Switch|GameCube Controller Adapter]] does not enable these sound effects, nor can it suspend the software on its own.

If the player opens the application up with  (or ) held in any direction, the application starts with the GameCube startup logo instead of the main application logo. If  (or ) is held before the GameCube logo shows up, the alternate startup sounds will play depending on if it is held on one or four controllers.

It is impossible to use a single Joy-Con or Joy-Con 2 to play Nintendo GameCube games. Unlike the other Nintendo Classics applications, the rewind function is unavailable.

''Luigi's Mansion'' specifically assigns {{Button|switch|l}} to a half-press of {{Button|gcn|l}} due to Joy-Con 2 and Nintendo Switch 2 Pro Controllers lacking analog triggers.
