The {{Term/Store|Royal Guard Set||Series, BotW}} is a recurring [[Armor Set]] in {{TLoZ|Series}}.<ref>{{Cite Book|quote= |book= CaC |publisher= |page= 190}}</ref>

==Location and Uses==
==={{BotW|-}}===
The {{Term|BotW|Royal Guard Set}} is exclusive to {{Term|BotW|The Champions' Ballad|link}} DLC Pack. It's a set of {{Term|BotW|Armor|link}} originally worn by members of the [[Royal Guard]] that can be found as part of the "{{Term|BotW|EX Royal Guard Rumors|link}}" {{Term|BotW|Side Quest|link}}. It consists of the {{Term|BotW|Royal Guard Cap|link}}, the {{Term|BotW|Royal Guard Uniform|link}} and the {{Term|BotW|Royal Guard Boots|link}}. Wearing the full set says that it only decreases usage {{Term|BotW|Stamina|link}} of {{Term|BotW|Link|link}}'s charge attack but it also reduces the swimming dash stamina cost by 50% and climbing jump stamina cost by 50%. For some reason it does not decrease the rate of stamina usage in bullet time. It can't be [[Dye]]d at the [[Kochi Dye Shop]], nor can it be enhanced by a {{Term|BotW|Great Fairy|link}}.
