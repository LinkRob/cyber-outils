Yunobo's Power Of Fire is a sage abillity  which you can get after defeating Moragia and Marbled Gohma. It allows Link to break Marbled Rock and Rocks. while link is on a moving object yunobo will attach himself onto the object to be use as a cannon. yunobo also lights flammable object on fire which can be used on grass to create an updraft
