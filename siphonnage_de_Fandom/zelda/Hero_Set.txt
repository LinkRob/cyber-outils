The {{Term/Store|Hero Set||Series, BotW}} is an [[Armor Set]] in {{BotW}}.<ref>{{Cite Book|quote= |book= CaC |publisher= |page= 192}}</ref>

==Location and Uses==
The Hero Set is an [[Armor]] set consisting of the [[Cap of the Hero]], [[Tunic of the Hero]], and [[Trousers of the Hero]]. All three pieces can be obtained using the [[Amiibo (Rune)| amiibo Rune]] while scanning the 30th Anniversary 8-Bit Link Amiibo. Each time the figure is scanned, a chest will appear that has a small chance to contain one of the pieces. As the Amiibo can only be scanned once per real-world day, a player must collect the set over three or more real-world days. 

The set can be enhanced by a [[Great Fairy]] but cannot be [[Dye|dyed]] at the [[Kochi Dye Shop]]. When it has been enhaced by two levels, it provides the Master Sword Beam Up [[Set Bonus]] when worn with the full set. It resembles Link's outfit from the original {{TLoZ}}.
