{{Term/Store|Mastering Stasis||HWAoC}} is a Level 13 {{Term|HWAoC|Challenge|link}} in {{HWAoC}}.<ref>{{Cite|Mastering Stasis|Map|HWAoC}}</ref>
==Overview==
{{Term|HWAoC|Mastering Stasis}} is a {{Term|HWAoC|Challenge}} used to introduce to the {{Term|HWAoC|Warrior}} the {{Term|HWAoC|Stasis|link}} rune of the {{Term|HWAoC|Sheikah Slate|link}}. It can be completed using any {{Term|HWAoC|Warrior|link}}, and when completed for the first time, the {{Term|HWAoC|Warrior}} receives a reward of an {{Term|HWAoC|Ethereal Stone|link}}, five {{Plural|HWAoC|Ancient Core|link}}, and ten {{Plural|HWAoC|Hylian Rice|link}}.

At the start of the {{Term|HWAoC|Challenge}}, the {{Term|HWAoC|Warrior}} must capture two {{Plural|HWAoC|Outpost|link}}. The first {{Term|HWAoC|Outpost}} contains normal {{Plural|HWAoC|Bokoblin|link}}, and after it is captured, a gate opens. The gate opens up to a path that leads to the second {{Term|HWAoC|Outpost}}, which contains only {{Plural|HWAoC|Blue Bokoblin|link}}. After both {{Plural|HWAoC|Outpost}} are captured, a {{Term|HWAoC|Moblin}} spawns. The {{Term|HWAoC|Challenge}} ends once the {{Term|HWAoC|Moblin}} is defeated. Since the point of this {{Term|HWAoC|Challenge}} is to teach the {{Term|HWAoC|Warrior}} how to use the {{Term|HWAoC|Stasis}} rune, all of the {{Plural|HWAoC|Boss}} perform attacks that can be countered using {{Term|HWAoC|Stasis}}.
