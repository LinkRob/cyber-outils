"{{Term/Store|Classics!||Series, SSBU}}" is a {{Term|SSBU|Spirit Board|link}} event for {{SSBU}}.<ref>{{Cite Web|quote= {{Big|Event: Classics!}}<br/>01/02/2019 |author= Nintendo |published= January 2, 2019 |retrieved= January 2, 2019 |url= https://www-aaaba-lp1-hac.cdn.nintendo.net/en-US/b807ac90/index.html |title= Event: Classics! - Super Smash Bros. Ultimate |site= Nintendo.net |type= }}</ref>

==Overview==
"{{Term|SSBU|Classics!}}" is an event wherein a greater number of {{Plural|SSBU|Spirit|link}} from games on the [[Famicom]] and the [[Famicom Disk System]] randomly appear on the {{Term|SSBU|Spirit Board|link}}.<ref>{{Cite Web|quote= Spirits from the Famicom and Famicom Disk System have taken over the Spirit Board! Defeat them to get more snacks than usual.<br/><br/>Legend-class spirits Donkey Kong & Lady, Link (The Legend of Zelda), and Sukapon will appear for a limited time.<br/><br/>The more you play, the more spirits you'll get! |author= Nintendo |published= January 2, 2019 |retrieved= January 2, 2019 |url= https://www-aaaba-lp1-hac.cdn.nintendo.net/en-US/b807ac90/index.html |title= Event: Classics! - Super Smash Bros. Ultimate |site= Nintendo.net |type= }}</ref> Additionally, certain Legend-class Spirits befitting this theme are set to appear at set times each day. An increased number of Snacks are earned as rewards for defeating Spirits that are part of this event.
