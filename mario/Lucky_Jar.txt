A '''Lucky Jar''' (also called a '''Magic Jar''') is an object which appears in ''[[Mario Party DS]]''.

==In ''Mario Party DS''==
Lucky Jars only appear in the board [[Kamek's Library]]. Three of them are randomly placed throughout the board at a given time, one of which contains the [[Star (Mario Party series)|Star]], another of which contains five [[Coin]]s, and lastly '''Cursed Jars''', which spit the character back to the start of the board. Throughout the board, the goal for each character is to try and find which Lucky Jar contains the Star. For this board, using a [[Star Pipe]] takes the character to the Lucky Jar containing the Star. Whenever a character finds the Lucky Jar with the Star, three other Lucky Jars appear at a different random space each.

There is a figure of a Lucky Jar that can be unlocked by opening the Lucky Jar with five coins three times. In the figure's description, it is said that only [[Koopa Krag]] knows the contents of each Lucky Jar. There is also a figure of a Cursed Jar, which itself is unlocked if the player's character opens a Cursed Jar three times.
