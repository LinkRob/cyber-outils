}}'''World 3''' is the third set of stages in ''[[Yoshi's New Island]]''. It takes place in a jungle, which is similar to the [[World 2 (Yoshi's New Island)|previous world]], but this world's coloration is more bright. [[Kamek]] and [[King Clawdaddy]] are the bosses of this world. 
==Levels==
*World 3-1: [[Rise of the Nasty Nep-Enuts]] &ndash; This level features [[Nep-Enut]]s.
*World 3-2: [[Ukiki Jammin']] &ndash; This level features [[Grinder (species)|Grinder]]s.
*World 3-3: [[Harry Hedgehog's Labyrinth]] &ndash; This level features [[Harry Hedgehog]]s.
*World 3-4: [[Slime Drop Drama]] &ndash; The third fort of the game.
*World 3-5: [[Don't Fear the Spear]] &ndash; This level features [[Spear Guy]]s.
*World 3-6: [[Ukiki Trouble in Clawdaddy Cove]] &ndash; This level features [[Clawdaddy|Clawdaddies]].
*World 3-7: [[Lose the Lunge Fish]] &ndash; This level features [[Lunge Fish]].
*World 3-8: [[King Clawdaddy's Sewer Castle]] &ndash; The third castle of the game.
*World 3-S: [[Ride the Blarggwich]] &ndash; This special level is centered around a [[Blarggwich]].
