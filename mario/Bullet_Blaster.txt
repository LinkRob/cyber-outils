{{Nihongo|'''Bullet Blaster'''|マグナムカート|Magunamu Kāto|Banzai Kart}} is a kart appearing in the [[Mario Kart (series)|''Mario Kart'']] series.

== Description ==
The kart resembles a [[Banzai Bill]]. This kart is very much like the [[Bullet Bike]] in ''[[Mario Kart Wii]]'', which is also a Light Class kart.

== In ''[[Mario Kart series]]'' ==
=== ''[[Mario Kart: Double Dash!!]]'' ===
[[File:MKDD Bullet Blaster.jpg|thumb|200px|right|The Bullet Blaster.]]
The Bullet Blaster debuts in ''Mario Kart: Double Dash!!'' The kart is associated with [[Bowser Jr.]], but any Light Class character is able to use it. The kart has above average speed and average acceleration, but is the easiest kart to be knocked off course with, due to being the lightest at 1 star acceleration.
