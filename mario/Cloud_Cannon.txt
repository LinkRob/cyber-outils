'''Cloud Cannons''' are an object in ''[[Super Mario 3D World]]'' and its [[reissue|remake]] ''[[Super Mario 3D World + Bowser's Fury]]''.

==Description==
If a character enters a Cloud Cannon, it produces a white [[Pipe Cannon]] that then shoots them upward into a [[Coin Heaven]]. In the ''[[Bowser's Fury]]'' campaign, a Cloud Cannon instead leads to a bonus area where [[Mario]] has to defeat a group of [[Cat Biddybud]]s and [[Cat Para-Biddybud]]s while [[Invincible Mario|invincible]], causing a [[Cat Shine]] to appear at the end.

A Cloud Cannon's face is similar to that of a [[Lakitu's Cloud]]'s.

==In {{series|Super Mario}}==
===''Super Mario 3D World'' / ''Super Mario 3D World + Bowser's Fury''===
A Cloud Cannon first appears in [[Mount Beanpole]], but reaching it requires activating a [[Cat Wheel]]. A Cloud Cannon later appears in [[Puffprod Peaks]], [[Pretty Plaza Panic]], [[Bob-ombs Below]], [[Clear Pipe Cruise]], [[Deepwater Dungeon]], and lastly [[Rainbow Run (level)|Rainbow Run]].
