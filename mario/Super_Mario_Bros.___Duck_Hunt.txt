'''''Super Mario Bros. / Duck Hunt''''' is a 2-in-1 compilation title for the [[Nintendo Entertainment System]] consisting of ''[[Super Mario Bros.]]'' and ''[[w:c:nintendo:Duck Hunt|Duck Hunt]]''. It was released in 1988, exclusively in North America. ''Super Mario Bros. / Duck Hunt'' was a best-seller for the system, in part because it was packaged with the NES Action Set. The set also came bundled with an NES Zapper, an accessory that is required to play ''Duck Hunt''.

A similar compilation titled ''[[Super Mario Bros. / Duck Hunt / World Class Track Meet]]'' was released some time after ''Super Mario Bros. / Duck Hunt''. It is an enhancement of ''Super Mario Bros. / Duck Hunt'' because it retains both games but adds ''[[w:c:nintendo:World Track Class Meet|World Track Class Meet]]'' as a third game.
