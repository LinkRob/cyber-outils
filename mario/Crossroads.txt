The '''Crossroads''' is an area in [[Luigi's Mansion: Dark Moon]] and [[Reissue|it's remake]]: [[Luigi's Mansion 2 HD]]. It is located in the [[Secret Mine]] and it contains a portal which leads to [[Skip Slope]].

== Description ==
The Crossroads is a small area in the [[Secret Mine]] in [[Luigi's Mansion: Dark Moon]] and introduces the E-Gate to the player in which they can get secret items using these portals. It leads to [[Skip Slope]] and contains a single [[Key]] which is used to unlock a nearby door using the aforementioned E-Gate.
