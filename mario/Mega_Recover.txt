|games = ''[[Super Mario RPG: Legend of the Seven Stars]]''}}'''Mega Recover''' is a move used by enemies and bosses in the game ''[[Super Mario RPG: Legend of the Seven Stars]]''. It is also a more potent version of [[Recover]].

==Description==
When Mega Recover is used, yellow starts appear on the user or ally.

==Effects==
With Mega Recover, the user is able to heal a great amount of [[Heart Point|HP]]. The user is also able to use it on any of its allies. Thankfully, only a few enemies and bosses in the game uses this move.
