'''Undercover Agent''' is [[Ashley]]’s microgame in ''[[WarioWare: Smooth Moves]]''. The microgame plays "undercover agent" who is a hired secret agent for getting information from enemies.

==Gameplay==
The player must do this by timing where this is on the red zone. The umbrella will open up when this is done correctly and it will come in various elements like money, lollies and rain. If done incorrectly, the umbrella will snap.

'''Level 1:''' There are four red increments as the highest point.

'''Level 2:''' There are two increments as the highest point.

'''Level 3:''' Just like Level 2, the player has to pick up the umbrella and open it.
