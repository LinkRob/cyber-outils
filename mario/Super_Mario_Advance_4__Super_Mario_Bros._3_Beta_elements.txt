== Unused World-e Level Content ==
World-e is a level extension that is locked behind the game, only accessible through E-Reader Cards. It was also made accessible automatically on the Wii U Virtual Console with no such thing required to access the levels. However, there is a lot more content that went unused than what was stored for the main game itself.

== European World-e ==
In the European versions of the game, World-e is disabled by default and can never be accessed with the e-cards. However, it's not removed from the game's files and was even translated into other languages. It can be unlocked by exploiting a corrupted save. Europe eventually did World-e when the game was re-released onto the Virtual Console (March 10, 2016) along with the language translations getting used during the process.<gallery>
