{{nihongo|'''Windows 95'''|ウィンドウズ95|U~Indōzu 95}} is an object in ''[[Shitamachi Ninjō Gekijō]]''.

==Description==
Windows 95 is represented as a basic blue, rectangular object reading "WINDOW 95" in green text, all uppercase.

==In ''Shitamachi Ninjō Gekijō''==
Windows 95's only appearance is in the fifth broadcast, which took place on February 20, 1996. At first, [[Mario]] and [[Toad (character)|Toad]] think that Windows 95 is a vehicle to ride on, and the two argue heavily over who will be able to ride it. However, [[Bill Gates]] shows up and shows that it is instead something to wear on the head.

==Behind the scenes==
{{w|Windows 95}} is actually a real operating system used by several computers in the mid-1990s.
