'''Bowser Memory ML''' (individually called "Bowser Memory M" and "Bowser Memory L") are the sixteenth bosses in ''[[Mario & Luigi: Bowser's Inside Story]]''. They are encountered in the [[Memory Banks]] inside Bowser's Body around mid-game.

==Appearance==
Bowser Memory ML look like Mario and Luigi, but are made out of "pixels" (cubes) and stand on one blocky "leg".

== History ==
They appear before Mario and Luigi when the Bros. enter the main Memory Banks to retrieve the code that [[Bowser]] needs to access his safe and attempt contact the [[Bowser Memory Neuron]], but the attempt goes horribly wrong when she flies into a range and the Bowser ML duo is summoned. At her behest, they assume that Mario and Luigi are viruses and decide to attack them. After they are defeated,  they transform into [[Bowser Memory P]].

==Combat==
Bowser Memory M and L fight together. Their attacks are as follows:

===Bowser Memory M===
*Starman Rampage: Bowser Memory M grabs the [[Super Star]], then charges forward. This must be avoided entirely. If the Mario brothers are not killed, they just take damage and leave the battle until the move ends. Mario and Luigi have to jump to avoid the low passes, but if a coin appears above their head, the Mario brothers must duck (no input required).
*Brick Bash: Bowser Memory M grabs the [[Super Mushroom]]. He then spawns several bricks above his head and bashes them. Mario and Luigi have to block the debris that is created with this attack with their hammers. How Bowser Memory M jumps determines who his target is. A normal jump means Mario is the target, while a spinning jump means Luigi becomes the target. The attack ends when a Bowser Memory Koopa Troopa bites Bowser Memory M.

===Bowser Memory L===
*Hammer Toss: Bowser Memory L takes out a hammer that has a square head. He then walks forward and then tosses the hammer. Mario and Luigi have to block the hammer with their own, lest it deals damage to them. The target's identity is telegraphed by the path Bowser Memory L takes before tossing his hammer. Due west means Luigi is the target. Northwest means Mario is the target.
*Boo Tag: Bowser Memory L plays tag with the Bowser Memory Boo. Mario and Luigi have to jump to avoid taking damage, but must time their jumps to make sure Bowser Memory L does not kick them with his legs. If their jump is timed so they can destroy the Boo (which has only one hit point) by stomping on it, the attack ends.
*Flee (passive): Damaging Bowser Memory L causes him to skid backward. If this happens twice, Bowser Memory L will be ejected from the battle for a few turns.
*Mushroom: Bowser Memory L can heal Bowser Memory M with [[Mushroom (item)|Mushrooms]]s, healing 40 hit points, If Bowser Memory M is dead, Bowser Memory L will use a 1-UP Mushroom to revive Bowser Memory M.
