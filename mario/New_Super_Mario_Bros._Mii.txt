'''''New Super Mario Bros. Mii''''' was both a game and a tech demo shown at E3 2011 for the [[Wii U]]. It was meant to show how the classic of the Mario brand could fit in the new console. It is based on ''[[New Super Mario Bros. Wii]]'' and contains new levels, as well as the option for players to use their [[Mii]]s. The demo itself eventually evolved into the game ''[[New Super Mario Bros. U]]''.

== Trivia ==
* If the Miis are selected as P1, it will be colored like Mario. If selected as P2, it will be colored like Luigi. If as P3, it will be colored like Wario and if selected as P4, it will be colored like the Blue Mario in Mario Bros., which bears a resemblance to Luigi's light-blue palette swap in the Super Smash Bros. series.
