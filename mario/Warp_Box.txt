The {{Nihongo|'''Warp Box'''|ワープボックス|Wāpu Bokkusu|Warp Box}} is a cubic object that debuted in ''[[Super Mario 3D Land]]''.

==Description==
Warp Boxes are clear boxes that have orange borders. Their interiors contain some colourful confetti. The Warp Box has an exclamation mark on it. The Warp Box functions the same as the [[Warp Pipe]] and [[Launch Star]]. If the player teleports through it, it changes its appearance. It has yellow-and-white-checker pattern around the box gaining its orange borders.

== In [[Super Mario (series)|''Super Mario'' series]] ==
===''[[Super Mario 3D Land]]''===
Warp Boxes debut in ''[[Super Mario 3D Land]]''. In ''3D Land'', Mario/Luigi is teleported to another Warp Box if they run into it.
===''[[Super Mario 3D World]]''===
Warp Boxes appear in ''[[Super Mario 3D World]]'' levels. There are some situations where the player must collect all the five [[Key Coin]]s to be able to access the Warp Box. If one player teleports and the other player is left behind, the player is automatically brought inside it. In their dormant state, Warp Boxes glow grey.

== In ''[[Captain Toad: Treasure Tracker]]'' ==
Warp Boxes return in ''[[Captain Toad: Treasure Tracker]]'' as an object. They are found in [[Clear Pipe Cruise]] for the [[Wii U]]. The Warp Box is found in [[Chaos in the Grand Labyrinth]] for the [[Nintendo Switch]]. It is found in [[Mummy-Me Maze Forever]] in both versions.

== In [[Mario Party (series)|''Mario Party'' series]] ==
[[File:SMP Warp Box.png|Warp Box in ''[[Super Mario Party]]''|thumb|100px]]
The [[Warp Box]] appears as an item in ''[[Mario Party: Star Rush]]'', ''[[Mario Party: The Top 100|The Top 100]]'' and ''[[Super Mario Party]]''. The player can use this item and choose the rival's spot to warp.
