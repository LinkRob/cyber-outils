The '''Return Pipe''' is an [[item]] which first appears in ''[[Super Paper Mario]]'' and returns in ''[[Mario & Luigi: Brothership]]''.

==Description==
Return Pipes are a type of [[Warp Pipe]] allowing [[Mario]] and other playable characters to quickly travel to the hub area or certain other location, and they can be used almost anywhere, with some exceptions. Return Pipes were originally depicted red in ''Super Paper Mario'' with white diagonal stripes on their rim but were changed to gold in ''Mario & Luigi: Brothership'', making them resemble a [[Golden Pipe]].

==In ''Super Paper Mario''==
[[Merlon]] gives the Return Pipe to Mario before he enters the first door of [[Flipside Tower]] to [[Lineland]]. This makes the Return Pipe one of the first important items he receives in ''Super Paper Mario''. The Return Pipe instantly returns Mario to the [[Flipside Tower]]. This can be done from almost any location, but in some areas, like the [[Underwhere Road]], the Return Pipe cannot be used. The pipe can also be used to escape the [[Pit of 100 Trials]].

If the Return Pipe is used in [[Castle Bleck]], Mario will return to the Flopside Tower instead of the Flipside Tower. From there, Mario can use the Return Pipe to go to Flipside Tower, but without the party he has lost during their time in Castle Bleck.

==In ''Mario & Luigi: Brothership''==
Mario and Luigi receive the Return Pipe from [[Willma]] after defeating [[Gorumbla]]. The Return Pipe is usable in most locations by pressing the ZR button, allowing the [[Mario Bros. (group)|Mario Bros.]] to return to [[Shipshape Island]] or any other island linked to it. In locations where the Return Pipe is usable, the player must have enough space first, without being obstructed by additional walls or solid scenery. Return Pipes also cannot be used in the following locations:

* [[Shipshape Island]]
* Disconnected drifting islands
* The [[Great Lighthouse Islands]]
* Inside [[Lottacoins Island]]'s offices
* The [[Offandon Island]] plaza while disguised
* The prison area on Offandon island
* [[Wayaway Island]] (This can cause a [[Softlock]] if the player somehow gets into the main area of Bowser's fortress on the island after the fortress's front door closes.)
* [[Fortress Zokket]]
* The [[Soli-Tree]]
