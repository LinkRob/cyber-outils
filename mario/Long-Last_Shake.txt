== Description ==
Using a Long-Last Shake will allow [[Mario]] and his friends to heal HP over time. However, in order to fully use the Long-Last Shake, the player must tilt the Wii Remote in the direction shown. The more the correct commands are put in, the longer the effects to the Long-Last Shake will last. Long-Last Shakes can be purchased in a number of [[Item Shop]]s throughout the game mainly [[Howzit]]'s shop in the [[Flipside]].

== Trivia ==
* Long-Last Shakes are the only healing item in the game that does not cure poison. Even it's better counterpart, [[Super Shroom Shake]], can cure poison.
