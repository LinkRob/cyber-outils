'''Sand blocks''' are a type of object which first appear in ''[[Donkey Kong (Game Boy)|Donkey Kong]]'' for the [[Game Boy]].

==Description==
Sand blocks are cubes made up of several grains of sand. If [[Mario]] stands on a sand block, it begins to slowly dissolve. In the Game Boy game ''Donkey Kong'' and ''[[Mario vs. Donkey Kong]]'', a sand block does not reappear after dissolving. In the latter, sand blocks serve essentially the same function as in the former game except they collapse faster. In ''[[Super Mario Sunshine]]'', a sand block respawns after a while.

==In ''Donkey Kong'' (Game Boy)==
In [[Stage 8-2]], there is a group of [[Chikuchiku]] underneath the sand blocks, one between each set of walls.

[[Stage 9-7]] is made nearly entirely out of sand blocks.

==In ''Super Mario Sunshine''==
Sand blocks can be found in several of the secret courses.
