== Unused Map ==
Found in the root of the '''RomFS''' is '''Sandbox_Powerups'''. Replacing the files of one of the [[ScreamPark]] minigames (with the files changed around) allows the user to load it into the game. Although it nothing displays, RenderDoc can be used with an emulator to get a view of what the map looks like, which seems to be a test map that was used for testing the game's powerups.
