'''Absorbing Mushroom''' is an item which appears in ''[[Mario Kart Arcade GP]]'' and ''[[Mario Kart Arcade GP DX]]''.

==Description==
An Absorbing Mushroom has a distinct dark blue cap with bright blue round spots.

Whenever a character uses an Absorbing Mushroom, a vortex appears around them for a short time. This vortex allows the user to obtain any projectiles sent after them rather than be affected by it. A disadvantage to using an Absorbing Mushroom is that while it is in effect, the user cannot pick up any items from an [[Item Box]].
