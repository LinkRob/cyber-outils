The '''1-2-3 Slow Dice Block''' is a special item which first appears in the game ''[[Mario Party 10]]''.

== Description ==
The player can obtain the 1-2-3 Slow Dice Block by landing on a [[Dice Block Space]]. The Dice Block resembles the [[Slow Dice Block]] and [[1-2-3 Dice Block]]. The player can use the 1-2-3 Slow Dice Block to roll from 1 to 3 while the number descends slowly.
