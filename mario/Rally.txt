'''Rally''' is a [[Captain Command]] in ''[[Minion Quest: The Search for Bowser]]'' and ''[[Bowser Jr.'s Journey]]''.
== Description ==
If the user uses the Captain Command, the user will cheer for the whole squad which temporarily raises their [[Spirit]] stat.
== In ''[[Minion Quest: The Search for Bowser]]'' ==
{{Q|Cheers on the whole squad and raises their SPIRIT for a limited time.|In-game description}}
It appears as a Captain Command in ''Minion Quest''. It costs 4 CP.

== In ''[[Bowser Jr.'s Journey]]'' ==
Appearing as a Captain Command, it costs 3 CP.
