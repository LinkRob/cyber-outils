The '''Triangular Block''' is an object which first appears in ''[[Super Mario World]]''. It has rarely appeared since.

==Description==
If [[Mario]] or [[Luigi]] are running, the Triangular Block allows them to continue running up the wall or [[Warp Pipe]] it is placed against. If [[Yoshi]] runs onto a Triangular Block, he bounces very high, but cannot run up walls like Mario or Luigi.

In ''[[Super Mario Advance 4: Super Mario Bros. 3]]'', Triangular Blocks appear in a few [[World-e]] levels. They retain their function from ''Super Mario World'', but some are placed between a wall and ceiling, allowing Mario or Luigi to also continue running up a ceiling.
