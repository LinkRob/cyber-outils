'''World 5''' is the fifth set of stages in ''[[Yoshi's New Island]]'', which takes place in a snowy hills area. [[Kamek]] and [[Punkey the Pokey Prince]] are the bosses of this world. 
==Levels ==
*World 5-1: [[Brave the Bumpty Blizzard]] &ndash; This level features [[Bumpty|Bumpties]].
*World 5-2: [[Fine Feathered Friends or Foes?]] &ndash; This level features [[Goonie]]s.
*World 5-3: [[Ski Lift Leap]] &ndash; This level features ski lifts.
*World 5-4: [[Ready, Steady, Go!]] &ndash; The fifth fort of the game.
*World 5-5: [[Cruise the Clouds]] &ndash; This level features tilting cloud platforms.
*World 5-6: [[Fire Watermelon Wonderland]] &ndash; This level features [[fire watermelon|red watermelon]]s.
*World 5-7: [[Eggstraordinary Terrain]] &ndash; This level features [[Raven]]s.
*World 5-8: [[Punkey the Pokey Prince's Castle]] &ndash; The fifth castle of the game.
*World 5-S: [[Snow Go Mountain]] &ndash; This special level is centered around bouncing on enemies.
