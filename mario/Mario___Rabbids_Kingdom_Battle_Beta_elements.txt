== Unused model ==
[[File:Mario+Rabbids-Bwapeach.png|left|thumb|78x78px]]
An early base design for the [[Lava Queen]] (known as '''chr_enm_bwapeach_tpose_01''') can be found the game's files under '''moria\sdf\nx\data\moria\baked\art\animation\01-chr\03-enm\bwapeach'''''.'' The model features different hair. compared to the one used from the final Lava Queen design, and lacks many of the Lava Queen's defining features,. Some of them being her helmet, cape, and gloves.

== Unused music ==
The Phantom's song in this game has three verses in the game's files, but only the first and third are used in the final game. The second one has the [[Phantom (Rabbid)|Phantom]] sing about how Mario and co's attacks are ineffective against him and was presumably going to play before the party figured out his weakness in the boss battle. In a past interview by Grant Kirkhope (the game's composer), the second verse was scrapped because of the developers not having the time to animate it in-game.

== Unused code ==
'''file PVP ./spawnlocations/pvp-spawnlocations.juice'''

Present in the base game is a call loading a spawn location file for PVP, which was later added in a semi-recent update. This could most likely have indicate that Ubisoft was internally working on the PVP mode since Day One.

== Leftover data ==
Many files mention '''rouge''' and '''directories''', which is the internal name for ''Tom Clancy's The Division''. This likely indicates that ''Mario + Rabbids Kingdom Battle'' was built off a build of that game.
