'''''Mario Bros.''''' is a [[Game Boy Advance]] [[reissue|remake]] of the [[arcade]] game of the [[Mario Bros. (video game)|same name]]. It is an extra game included in every ''[[Super Mario Advance (series)|Super Mario Advance]]'' game and as an extra mode that is exclusive to the [[Game Boy Advance]] version of ''[[Mario & Luigi: Superstar Saga]]''.  

== Gameplay ==
The game plays the exact same as the [[Mario Bros. (video game)|original game]] with some minor changes for it to run on the [[Game Boy Advance]]. It includes the same amount of phases and enemies as the original game with an added screen crunch and compressed sound for it to run on the Game Boy Advance. Each of these games can also be connected to each other with the Link Cable to play the 4-Player battle mode. The sprites were reused from ''Mario Bros.'' sample included in ''[[MARIO FACTORY]]''.
