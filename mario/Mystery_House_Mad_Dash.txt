|image = [[File:MysteryHouseMadDash.png|250px]]}}'''Mystery House Mad Dash''' is a level of [[World 4 (Super Mario 3D World)|World 4]] of the game ''[[Super Mario 3D World]]''.

==Features==
The main feature of this Mystery House is that the players must rush through each area. This mainly involves running and jumping across gaps and avoiding enemies. The [[Tanooki Suit]] will make this Mystery House a lot less difficult.

==Green Stars==
*'''Green Star 1''': In section 1, jump on the jump boards to the star within ten seconds.
*'''Green Star 2''': In section 2, run to the star while avoiding the horned ant troopers within ten seconds.
*'''Green Star 3''': In section 3, run away from the banzai bill and get the star within ten seconds.
*'''Green Star 4''': In section 4, run to the star while avoiding the spike's rollers within ten seconds.
*'''Green Star 5''': In section 5, run on the narrow path to the star within ten seconds. Jump above the edges that make the turns to make a shortcut.
*'''Green Star 6''': In section 6, run on the boost pad to run away from the Thwomps and get the star within ten seconds.
*'''Green Star 7''': In section 7, jump on the moving platforms to get the star within ten seconds.
*'''Green Star 8''': In section 8, run to the star while avoiding the Goombas within ten seconds.
*'''Green Star 9''': In section 9, run on the narrow path while avoiding cat bullet bills and getting the star within ten seconds.
*'''Green Star 10''': In section 10, run on the platforms while avoiding Spike's rollers and the platforms that fall to get the star within ten seconds.
