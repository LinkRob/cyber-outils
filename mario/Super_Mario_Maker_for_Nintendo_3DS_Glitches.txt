This page lists all '''glitches''' for ''[[Super Mario Maker for Nintendo 3DS]]''.

==Glitches==
*There is a Data Reset glitch that occurs with the [[Nintendo 3DS|3DS]] release, but not in the Wii U release. To make the glitch work, one must make sure the game cartridge has progressed on the homing 3DS, then insert it into another 3DS and play it on that 3DS. By placing the cartridge back into the original 3DS, all of the progress will be erased. There will be a new save file once the disk is put onto another Wii U Console.
