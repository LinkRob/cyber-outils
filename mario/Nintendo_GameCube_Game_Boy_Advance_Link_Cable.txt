The '''Nintendo GameCube Game Boy Advance Link Cable''' is an accessory utilized between both a [[Nintendo GameCube]] and a [[Game Boy Advance]]. It allows for the latter to connect to the former, similarly to the [[Nintendo 64]]'s [[Transfer Pak]]. The cable is generally used to transfer data or unlock content between a certain Game Boy Advance to a certain Nintendo GameCube game or vice versa. In some cases, notably like in ''[[w:c:zelda:The Legend of Zelda: Four Swords Adventures|The Legend of Zelda: Four Swords Adventures]]'', there is the option to have a gameplay experience of alternating between the Nintendo GameCube and Game Boy Advance to play the game, depending on the area.

Some Nintendo GameCube games have the Game Boy Advance as a controller option from using the Nintendo GameCube Game Boy Advance Link Cable, including the [[Game Boy Player]], which is used to play games from the [[Game Boy]] line of systems itself, taking in either a [[Nintendo GameCube Controller]] or a Game Boy Advance as a controller option.
