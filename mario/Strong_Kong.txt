{{Nihongo|'''Strong Kong'''|ストロングDK|Sutorongu DK|Strong DK}} ('''''Strongum Kongus''''') is a special technique used by [[Donkey Kong]] in the game ''[[Donkey Kong 64]]''. It can be obtained from [[Cranky Kong]] at [[Angry Aztec]] for the price of 5 [[Banana Coin]]s.

== Description ==
With Strong Kong, Donkey Kong is able to turn invincible for as long he has [[Crystal Coconut]]s. As long the Strong Kong ability is active, Donkey Kong cannot be harmed and can run over hazardous substances such as [[quicksand]]. Also, all enemies will run away from Donkey Kong even the stronger ones like [[Krusha]]s. Strong Kong is fairly useful, but it isn't used that much in the game and is mainly used to help obtain [[Golden Banana]]s.
