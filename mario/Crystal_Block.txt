A '''Crystal Block''' is a block which first appears in ''[[Super Mario 3D World]]'' and returns in ''[[Captain Toad: Treasure Tracker]]''. Crystal Blocks are made out of amethyst-shaped crystal related in appearance and function to [[Brick Block]]s. A Crystal Block can be shattered upon being hit, unless it is hit by [[Small Mario]]. However, unlike Brick Blocks, a Crystal Block never contains any item.

Crystal Blocks reappear as course elements in ''[[Super Mario Maker 2]]'', where the blocks return regular Brick Blocks in the underground and forest-world styles of the ''Super Mario 3D World'' style. This block now allows them to have controls. They also emerge in the background of the underground level theme in the ''Super Mario 3D World'' style, which itself is based on [[Koopa Troopa Cave]].
