'''''WarioWare: D.I.Y.''''' is the seventh game in the [[WarioWare (series)|''WarioWare'' franchise]]. It was released March 28, 2010 in North America for the [[Nintendo DS]]. Unlike the previous ''WarioWare'' titles, the game is essentially a video game creation software that allows players to create their own Mega Microgames.

==Gameplay==
''WarioWare: D.I.Y.'' allows budding game artists to make their own ''WarioWare'' style mini-games from a set of basic programming tools. You can only make games that involve merely tapping with the stylus, but the gameplay can be as simple or complicated as you want with this simple control.
