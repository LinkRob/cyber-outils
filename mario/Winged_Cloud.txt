A '''Winged Cloud''' is an object which appears throughout the ''[[Yoshi (franchise)|Yoshi]]'' platforming games. It first appears in ''[[Super Mario World 2: Yoshi's Island]]''.

==Description==
To activate a Winged Cloud, a [[Yoshi (species)|Yoshi]] has to throw a [[Yoshi Egg]] at it. Each Winged Cloud has a specific effect, although every Winged Cloud disappears upon being activated. Popping a Winged Cloud can either cause either an item or an object to appear. Items released by a Winged Cloud can include five [[Star (Yoshi's Island series)|Stars]], a [[Smiley Flower]], or a [[1-Up]]. Objects released by a Winged Cloud can include a platform, such as stairs or bridges, a [[Beanstalk]], or a [[! Switch]]. If the [[Countdown Timer]] is at its maximum number of 30, Winged Clouds that usually contain five Stars instead release five [[coin]]s.

In ''Super Mario World 2: Yoshi's Island'', there is a [[Special Item]] named [[Winged Cloud Maker]] that turns all enemies onscreen into Winged Clouds.
