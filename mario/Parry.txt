'''Parry''' is a [[Captain Command]] in the ''[[Minion Quest: The Search for Bowser]]'' campaign of ''[[Mario & Luigi: Superstar Saga + Bowser's Minions]]''.

== Description ==
If the user uses parry, they block two enemy attacks, which can also allow for a counterattack. 

== Flavor text ==
* '''In-game description:''' "Completely blocks two enemy attacks. Time it perfectly to counterattack!"
