The '''Bowser Memory Neuron''' is a minor character from ''[[Mario & Luigi: Bowser's Inside Story]]'' who acts as the guardian of [[Bowser]]'s [[Memory Banks]].

==Description==
The Bowser Memory Neuron resembles a [[Napse]] in her normal form, with four thunderbolt-esque appendages protruding from her blue body, square yellow eyes, and a mouth with yellow triangular lips. When the Mario Bros. destroy [[Bowser Memory ML|Bowser Memory M and Bowser Memory L]], she turns into a blocky [[Princess Peach]] copy so the two parties can communicate.

== History ==
When the Bowser Memory Neuron is first seen, she is tending to [[Bowser]]'s [[Memory Banks]], which the Bros. visited to gain the combination that Bowser needs to gain access to his safe, which has one of the three [[Star Cure|Star Cures]]. [[Starlow]] asks her for the combination, but this enrages the guardian, who summons Bowser Memory M and Bowser Memory L to attack. After the Bros. destroy them, the Bowser Memory Neuron transforms into a Princess Peach copy so the two parties can communicate more easily. Starlow again asks her for the combination, prompting the Bowser Memory Neuron to revert back to the Napse-esque form and search the brain for the memory. The Bowser Memory Neuron finds the frame, revealing that the memory was destroyed. She then makes the player repair the memory via a puzzle.

After the restoration of the memory, the Bowser Memory Neuron places the restored memory back in Bowser's brain, and he remembers the combination where he gets the second Star Cure. Afterwards, the Bowser Memory Neuron can be seen tending to his brain in the DS version, though she cannot be interacted with. In the 3DS remake, the Bowser Memory Neuron does not return following her tango with the Bros. and Starlow.{{stub}}
